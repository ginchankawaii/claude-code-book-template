## 購入・採寸の段階（〜2026-11-14）

- **電池の容量表記**: 「800mAh」と書かれた品が実質 680mAh 相当だった。出所のはっきりした品を選ぶ。
- **JST コネクタのピッチ違い**: 「1.25mm」のつもりで買ったピグテールが 2.0mm 系で、電池に嵌合しなかった。買い直し。
- **LED のツバ**: ツバ径が窓の穴と同じで引っかからなかった。実測して筒の形を変更。
- **測る場所の取り違え**: 採寸図の誤り（マイクを別の部品として描いた）で、マイク位置を測り直した。

## 印刷・仮組みの段階（2026-11-14〜15）

- **プリンタ**: Creality Ender-3 V3 SE、スライサは Cura。材料は手持ちの PLA（設計の推奨は PETG）。
  設定: 0.2mm 積層、壁 4周、インフィル 30%、200℃ / 60℃、印刷速度 60mm/s、1層目 20mm/s、サポートなし、スカート。
- **台座の傾き**: 自動レベリングの結果、対角で約 1mm の傾き。小さい部品を中央に置けば影響なし。
- **磁石の圧入**: φ6.2 の穴に φ6 の磁石が「取れないほど」きつく入った。接着剤なしで保持できたが、
  向きを確かめる前に入れるとやり直せない。向きは「入れる前に、相手の磁石と引き合う面に印を付ける」で決めた。
- **【設計ミス】XIAO を受ける柱が折れた**: 基板と柱のすきまを 0.15mm にしていたが、FDM は穴の内寸が
  0.2〜0.3mm 小さく出るため基板が入らず、軽く押したら柱 2本が根元から折れた。
  → すきまを 0.50mm に広げ、柱を壁と一体にした（v1.12）。教訓: はめ合いのすきまは印刷の縮みを見込む。
- **細い突起が印刷できなかった**: 厚さ 0.9mm × 幅 2mm の独立した突起が形にならなかった。
  → 隣の壁・柱につなげた（v1.13）。教訓: 細い独立形状は避け、壁から生やす。
- **取り付け方法の変更**: 本体と MagSafe プレートを磁石 2個で付ける設計だったが、「落としてなくしそう」との判断で、
  本体と円板を一体で刷る `mindclip_phonebody.stl` を追加（v1.13）。磁石・接着剤が不要になり、出っ張りも約 18 → 15mm に減った。
- **電池の遊び**: 電池室の長さ方向に約 3mm の遊び（実測 2.9〜3.0mm、計算 3.1mm）。フタの縁が入るすきまで、設計どおり。
  組み立て時は左に突き当てて両面テープで固定する。

- **【設計ミス】フタが 3〜4 回連続で失敗**: 台座を洗っても、のりを塗っても直らなかった。原因はデータの向き。
  フタの STL を組立時の向き（縁が下）で書き出していたため、Cura に読み込むと LED の筒の先（約 11mm²）だけが
  ベッドに触れ、板全体（約 1,950mm²）が宙に浮いていた。サポートなしでは刷れない。
  → STL を印刷の向き（表の平らな面が下、ベッドに付く面積 約 1,830mm²）で書き出すよう修正（v1.14）。
  全部品に「ベッドに付く面積が外形の 40% 以上」の自動検査を追加。
  教訓: 貼り付かないときは、掃除やのりの前に Cura のプレビューで 1層目の形を見る。小さな点や輪だけなら向きが悪い。

- **一体型の本体（phonebody）**: 1回で成功。USB は奥まで挿さり、iPhone 17 Pro のカメラの出っ張りにも当たらない。
  リングの溝はゆるめ（設計どおり。リングは粘着で貼る）。
- **フタ（v1.14）**: 向きを直したデータで 1回で成功。パチッとはまり、サイズもぴったり。

## 書き込みの段階（2026-11-15）

- **XIAO が PC に認識されない**: ランプは光るが、デバイスマネージャーに出ない（出ていた COM3 / COM4 は Bluetooth だった）。
  B ボタンを押しながらの接続、ケーブル交換でも改善せず。途中で「PD（充電用）の口に挿していた」ことも判明。
  最終的に故障と判断し、同じ XIAO ESP32S3 Sense（113991115）を買い直した（マルツ、約 3,000円）。
  教訓: 充電できる＝データが通る、ではない。PC 本体のデータ用の口に挿す。COM ポートが Bluetooth でないか確かめる。

- **買い直しの顛末（〜2026-11-21）**: XIAO ESP32S3 Sense は国内で品薄だった。マルツ・秋月・スイッチサイエンス・千石・楽天（マルツ店）は
  売り切れか入荷待ち。検索結果に出る価格は古いことが多く、実際の画面と食い違った（Amazon は検索では 3,449円、実際は 4,580円）。
  最終的に Amazon で 4,580円（在庫あり・翌日着）を購入。選択肢に「Sense (Pre-Soldered)」「Sense なし」「3PCS」が並ぶので取り違えに注意。
  教訓: 価格と在庫は必ず実際の購入画面で確かめる。安い店ほど在庫切れのことがある。

## はんだ付けの段階（2026-11-23）

- **新しい XIAO の単体テスト**: 書き込み・PSRAM 8MB・microSD・マイク（音の大きさ表示で静か 40〜60 / 声 2,000〜12,000）すべて合格。
  10秒録音のテストは「音がない」となったが、マイクは正常だった（テスト側の問題。本番ファームでは別の方法で録る）。
- **【図解の不足】XIAO の線を部品面から付けてしまった**: 部品面には Sense 拡張ボードが重なるので、線は裏面から差し込み、
  部品面には低いはんだの山だけを残す必要があった。図解に横から見た図を足して付け直し。
- **【図解の不足】裏面で線が交差していた**: XIAO の下のすき間は 1.4mm。3本を重ねずに並べ、USB と反対の端の真ん中から出す。
- **最初に黒を付けた跡が VUSB（5V）の穴に残っていた**: USB を挿す前に、GND と 5V / 3V3 が導通しないことをテスターで確認して回避。
- **LED（D3）とスイッチ（D1）のテスト**: 合格。
