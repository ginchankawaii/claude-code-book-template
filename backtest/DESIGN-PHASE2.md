## 1. 方向性の判定：撤退は早すぎた。ただし「利益が狙える」は条件つき

フェーズ1で否定されたのは「翌営業日の始値で買い、N営業日後の始値で返済」という
**一つの執行形**であって、事象そのものではない。データはこう言っている。

```
実在するもの
  上方修正の TOPIX 超過   +0.229%（N=1・2,297件） 下方修正は +0.031%。符号は正しい
  流動性上位ほど大きい     >500億 +0.313% / ≤300億 +0.091% / 売買代金F落ち −0.408%
  場中開示は大きい         +0.643%（528件）      引け後は +0.106%（1,769件）
  効果は初日で出尽くす     N=1 +0.229% → N=10 +0.222%。延ばしても増えない

消しているもの
  往復スリッページ 0.4%    損益分岐の往復コスト: N=1全体 0.21% / >500億 0.29% / 場中 0.62%
  市場ベータ               粗 +0.809% のうち +0.560%
```

つまり「エッジは実在するが、想定した執行コストより小さい」。
フェーズ2の問いは **「執行コストを超過リターン以下に下げられる執行形があるか」** に変わる。

### 2.1 Tier A：費用ゼロ。手元の5年データで今すぐ判定できる

すべて **事前登録した1セルで判定**し、他のセルは見ない。
3つの検定を同時に走らせるので、有意水準は片側 α = 0.05 / 3。

#### A1. 日計り（翌日始値 → 当日引け）と初日の分解　　実装済み

```
仕組み   翌営業日の寄付で買い、同日の引け成りで返済。持ち越さない
執行     SBI 日計り信用 / 楽天いちにち信用: 手数料0・金利0%（当日返済が条件）
根拠     超過は初日で出尽くす。持ち越しをやめれば金利0・夜間ギャップ0・追証0
主セル   N=0 / 全体 / 上方修正10%以上 / 常習除外 / 売買代金F / 除外あり / 滑り0.4%
判定     初日を「始値→引け」X_oc と「引け→翌始値」X_co に分解する
         X_oc の TOPIX超過 ≥ 0.45%（純 ≥ 0.05%）かつ CI下限 > 0 で通過
打ち切り X_oc 超過 < 0.45% または CI下限 ≤ 0
         X_co を見て「引け→翌始値」側へ乗り換える行為は禁止（両脚を同時に出し、採否は X_oc のみ）
件数     2,297件。σ は夜間分が抜けて 3〜4% と見込む。0.45% なら t=2 に届く
期待     不明。X_oc + X_co ≈ 0.229% なので、X_co が負（夜に戻す）でなければ成立しない
         米国研究ではモメンタム系の超過は夜間に乗るとされ、事前確率は高くない
```

#### A2. 場中開示を開示日の引けで買い、翌始値で返す　　要実装（数十行）

```
仕組み   場中開示（DiscTime が大引けの30分以上前）を、開示日の引け成りで買い、
         翌営業日の寄付で返す。1泊
根拠     場中開示は翌日でも超過 +0.643% 残る。開示日の残り時間で織り込みが終わっていない
         なら、開示日引け→翌朝の「窓」にも同方向のドリフトが残るはず
主セル   場中のみ / 上方修正10%以上 / 常習除外 / 売買代金F / 除外あり / 滑り0.4%
         DiscTime カットオフ = 大引け30分前（延伸前 14:30 / 延伸後 15:00）。動かさない
判定     窓 C(開示日)→O(翌日) の TOPIX超過 − 0.4% − 1泊金利 ≥ 0.05% かつ CI下限 > 0
打ち切り 窓の超過 ≤ 0 なら仮説そのものが死ぬ。副指標への乗り換え禁止
件数     350〜450件（カットオフで528から減る）。σ 4〜5%。純 0.45% 以上でないと検出不能
期待     不明。開示直後の急騰の反動で窓が負になる可能性も同程度にある
実装     simulate_trades に entry_mode='disc_close' を足す（既存の d0 分解と同型）
```

#### A3. 流動性上位層に限定し、コストを一律値から銘柄別に置き換える

```
仕組み   対象を「時価総額500億超 かつ 50万が20日平均売買代金の0.1%以下（ADV≥5億）」に固定
         執行は寄付成行→翌日寄付成行（両端とも板寄せ。スプレッドは存在しない）
根拠     >500億 の超過 +0.313%（1,121件、差分計算で検算済み）。σ も 4.09% と最小
         往復コストの残りは自己インパクトのみ。TOPIX500 構成銘柄は呼値 0.1円
判定     超過の CI下限 > 0。純は「モデルコスト 0.10〜0.15%」控除で ≥ 0.05%
打ち切り CI下限 ≤ 0、またはペーパートレード30約定で実測往復コスト > 0.15%
件数     600〜900件（ADV≥5億で減る）。超過+0.31% は t≈1.6〜2.1 で境界
期待     +0.15〜0.20%（コスト 0.10〜0.15% なら）。ただし件数不足で純の有意性は出ない
         → 判定は「超過のCI下限>0」と「ペーパートレードの実測コスト」の二段構え
```

#### A4. 副次：同一年度内2回目以降の上方修正（確認テスト1回のみ）

```
発見     フェーズ1で事前登録した「常習除外」は、超過の高い群を捨てていた
         常習のみ 679件 超過 +0.518%（差分で検算済み）。方向が事前想定の逆
問題     3年窓が完全になるのは 2024-09 以降なので、後半期間の効果を拾っている可能性
対処     窓に依存しない「年度内の何回目の上方修正か」rev_seq を作り、
         H: rev_seq≥2 の超過 > rev_seq=1 の超過 を1回だけ検定。前半/後半で符号一致を要求
扱い     通っても主条件には入れない。forward の観察指標にとどめる
```

#### A5. 資金枠の選択則の点検（バグか偏りか）

```
発見     主条件 N=5: トレード平均 +0.343% x 506本 = +87万 のはずが、
         ポートフォリオは −141万（1本あたり −0.558%）。独立仮定の 2.4σ
原因候補 枠が足りない日の選択則「修正率降順 → 時価総額昇順」が、
         修正率の極端に大きい小型株（超過が低い層）を優先して拾っている
対処     建てた本 / 見送った本 / 全体 の平均純リターンを出す診断を追加済み
         偏りなら、選択則を「売買代金降順」に事前登録して置き換える（1回だけ）
         バグなら直す。どちらでも、元金別の損益表はこの後の数字で読み直す
```

## 5. 判定の順序と、やめる条件

```

4) OOS も通過 → ペーパートレード3か月
   ・寄付成行 / 引け成行の実約定値と日足 O/C の差を30約定で実測（A3 の往復コスト）

5) 実測往復コストが損益分岐（A1: X_oc超過 / A3: 0.29%）を超えたら終了

各段階で、閾値・フィルタ・セルを探し直すことは禁止。
```
