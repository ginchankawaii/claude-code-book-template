## 0. v0.1 からの訂正（先に読むこと）

v0.1 で私は「撤退は早すぎた」と書いた。反証を通した後の判定は次のとおり。

```
撤退は早すぎた            → 半分だけ正しい。事象に情報があること自体は残る
利益を狙える仕組みがある  → 現時点で「ある」と言える案は残らなかった
```

却下された理由は、案ごとの数字の誤りではない（15案の数字はすべて grid.csv と一致）。
共通するのは次の3つで、どれもフェーズ1の枠組みそのものの限界である。

```
1. 部分集合の差はノイズと区別できない
   >500億 vs ≤500億 の超過差 +0.164% は SE 0.208%（t=0.79）
   >500億 の N=3/5/10 は +0.470/+0.315/+0.370 で単調でない（±0.15% 揺れる）
   「流動性上位ほど大きい」は、4,320セルの隣接層から良く見える層を拾った形

2. 判定基準が「仮説が正しくてもコイン投げで落ちる」設計になっていた
   ADV≥5億で 600〜900件、SE 0.16〜0.19%。超過 +0.313% が真値でも CI下限>0 は 37〜51%
   純 +0.17% を t=2 で言うには 3,100件 = 実際に建てられる本数（年70〜130）で 20〜30年

3. 場中開示セルは 2024-11-05 の取引時間延伸で母集団が途中で変わっている疑い
   延伸前は上場会社の約半数が 15:00〜15:30 に開示し、それは全部「引け後」だった
   延伸後はその時間帯が「場中」に入る。場中 +0.643% は構造か、入れ替わりか、判別していない
   → v0.2 で「延伸前 / 延伸後15:00前 / 延伸後15:00〜」の内訳を出す診断を追加（実装済み）

加えて、私が v0.1 で「事前確率は高くない」と書いた A1（日計り）は、
反証で「成立には引け→翌始値の脚が −0.22% 以下（夜に戻す）でなければならない。
米国の実証は逆（超過は夜間に乗る）」と、より具体的に否定された。
コストを 0.4% から 0.1〜0.2% に下げた根拠も無い（寄付→引けも両端オークションで、
執行の性質は N=1 と同じ）。

**残ったのは「費用ゼロで既存データを1回走らせる診断」と「3,300円の OOS 追試」だけで、
どちらも通る事前確率は低い。** その上で、走らせる価値があるかを §8 で決める。

## 1. 方向性の判定：撤退は早すぎた。ただし「利益が狙える」は条件つき

フェーズ1で否定されたのは「翌営業日の始値で買い、N営業日後の始値で返済」という
**一つの執行形**であって、事象そのものではない。データはこう言っている。

```
実在するもの
  上方修正の TOPIX 超過   +0.229%（N=1・2,297件） 下方修正は +0.031%。符号は正しい
  流動性上位ほど大きい     >500億 +0.313% / ≤300億 +0.091% / 売買代金F落ち −0.408%
  場中開示は大きい         +0.643%（528件）      引け後は +0.106%（1,769件）
  効果は初日で出尽くす     N=1 +0.229% → N=10 +0.222%。延ばしても増えない

消しているもの
  往復スリッページ 0.4%    損益分岐の往復コスト: N=1全体 0.21% / >500億 0.29% / 場中 0.62%
  市場ベータ               粗 +0.809% のうち +0.560%
```

つまり「エッジは実在するが、想定した執行コストより小さい」。
フェーズ2の問いは **「執行コストを超過リターン以下に下げられる執行形があるか」** に変わる。

### 先に金額の現実を書く

5つの独立した視点が同じ上限に収束した。

```
上方修正・売買代金F・常習除外の年間シグナル   約 460本（N=1）
建玉150万・同時3本で建てられる本数           年 100〜230本
1本50万 x 純エッジ 0.2〜0.3%                 年 10〜35万円（購読料 2万円/年 の前）
```

最良ケースでも **年 10〜35万円**。150万に対して 7〜23%。
これを「続ける価値がある」と見るかは §8 で確認する。

```

   事前登録: N=0 / 全体 / +10% / 常習除外 / 売買代金F / 除外あり / 滑り0.4%
   通過条件: 始値→引け の超過 ≥ 0.45% かつ CI下限 > 0（v0.1 と同じ。下げない）
   事前確率: 低い。O→O の超過 +0.229% の CI は [−0.01, +0.46] で0を跨ぐ
             通るには 引け→翌始値 が −0.22% 以下でなければならない

（v0.1 の A2「開示日引けで買う」は、引け→翌始値の脚を副表として出すだけに格下げ。
  根拠だった「N=1→N=10 で超過が増える」は t≈0.6 でノイズだった。
  v0.1 の A3「流動性上位」と A4「常習」は却下。理由は §0 と §2.3）

### 2.2 3,300円で1回だけ：場中 vs 引け後 の構造を未使用期間で追試（T1）

反証パネルで **唯一却下されなかった案**。ただし成立するのは「構造の複製検証」としてであり、
「純エッジ > 0 の証明」としては件数的に不可能（10年集めても t≈1.8 が上限）。

```
条件     D2 で「延伸前の場中」単独でも超過が出ていること（延伸で作られた差でないこと）
内容     J-Quants Standard を1か月契約し 2016-09〜2021-09 を追加取得
         事前登録セル: N=1 / 場中 / +10% / 常習除外 / 売買代金F / 除外あり / 滑り0.4%
         定義・閾値・フィルタは一切触らない
判定     追加5年単独で (a) 場中の超過 > 0.41%（損益分岐） かつ (b) 場中 − 引け後 > 0
         両方通って初めて「構造は複製された」
できないこと 通っても純エッジの有意性は出ない。ペーパートレードの根拠にはなるが実弾の根拠にはならない
未確認   2016〜2021 の fins summary に DiscTime が埋まっているか。無ければ本案は不成立
費用     3,300円
```

## 5. 判定の順序と、やめる条件

```
1) D1〜D3 を1回の再実行で出す（費用0）
2) D1 が通らず、かつ D2 で「延伸前の場中」に超過が残っていない
   → この事象系列の研究を終了。150万は TOPIX 連動 ETF の現物へ。基盤は次の仮説の検定器として残す
3) D2 で延伸前の場中にも超過が残っている → T1（3,300円）で OOS 追試
4) T1 で構造が複製された → ペーパートレード3か月（純エッジの証明ではない、と知ったうえで）
   ・寄付成行 / 引け成行の実約定値と日足 O/C の差を30約定で実測（A3 の往復コスト）
   ・15:25 までに引成を出す運用が回るか（A1）。強制決済1回でも出たら手順を直すまで実弾禁止
   ・増担保規制で建てられなかった頻度
5) 実測往復コストが損益分岐（A1: X_oc超過 / A3: 0.29%）を超えたら終了

各段階で、閾値・フィルタ・セルを探し直すことは禁止。
