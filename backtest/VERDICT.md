## 2. なぜ「終了」か（反証パネルを通って残った論拠だけ）

```
1. 執行できる日の期待値は、どの形でもマイナスか 0
   2晩目で見えた +0.35〜0.56% の夜間超過は、ストップ高で張り付いた日（買えない日）と
   貸借外（売れない日）に全部載っていた。執行できた日の粗リターンは中央値 0。
   フェーズ1の超過 +0.25% は市場ベータを除いた後の数字で、往復 0.4% を超えない。

2. 残る候補（場中・日計り）は、今トレードする市場ではコスト以下
   延伸後（2024-11-05 以降、今の 15:30 大引け）の母集団で純 −0.093%。
   前半 +0.513% → 後半 +0.019% に落ちている。減衰か雑音かは t≈1.4 で区別できない。
   区別するのに必要な件数は数万件で、年 100 件前後の事象では集まらない。

3. T1（3,300円で 2016〜2021 を追試）は、通っても資金判断を変えられない
   追試する期間は 15:00 大引けの旧制度。そこで +0.954% が再現しても、
   今の市場（+0.307% / 純 −0.093%）で取れる根拠にはならない。
   文書自身が「通っても純エッジは証明できない（10年で t≈1.8 が上限）」と書いている。
   費用は小さいが、答えが出ても次に進む条件を満たせない検定にお金を払う理由がない。
   さらに T1 は門として壊れている（監査で判明）:
   ・門 (a) の 0.41% は N=1 の損益分岐の流用。N=0 は金利 0 なので純に直すと +0.01% で、打ち切り線 0.05% より下
   ・前提「契約後に 2018〜2020 の DiscTime を確認し、空なら契約しない」は順序が矛盾（Light では 2018 年を見られない）
   ・主セルを N=1 → N=0 に変えたのは同じ5年を見た後（文書が自認）
   直して走らせれば「結果を見て門を書き直す」行為で §11 に反し、直さずに走らせれば壊れた門で判定することになる。

3b. 今の市場での前向き記録（TDnet 手動・0円）も答えを出せない
   年 100〜130 件では年間の SE が約 0.33%。純 +0.05% を判定できる日は来ない。
   ライブの停止条件「直近60本の純平均 < 0 で全停止」も SE 0.49% で、真の純が +0.27% あっても 29%、
   +0.05% なら 46% の確率で誤停止する。事前登録した規則を正直に運用すると、本当に儲かる系でも数か月で止まる設計。

4. 金額が手間に見合わない
   設計書の最良ケースで年 10〜35万円（150万に対して 7〜23%）。
   それは「純 0.2〜0.3%」を前提にした数字で、執行できるセルでその純を示したものは一つもない。
   実現しうる形（日計り）は毎営業日 9:00 と 15:25 に画面の前にいることを要求する。

5. ユーザー自身が決めた「ギャンブルにしない」規則を適用すると、実弾に至る道が無い
   事前登録した門を正直に当てはめた結果がこれで、門を緩めれば §11 の「同じデータで探し直さない」を破る。
```

「続ける」側で反証に耐えた論拠は次の2つだけで、どちらも上の 3 と 4 で打ち消される。

```
・T1 は 3,300円で「延伸前の構造が再現するか」を 8:1 程度の尤度比で判別できる（統計的には正しい検定）
・続けても 150万は一切リスクに晒さず、上限 8,300円で終わる
```

## 4. 監査で見つかった基盤の欠陥（修正済み・判定は変わらない）

```
1. 貸借区分・信用区分を「最新の銘柄マスタ」で全期間に当てていた（先読み）
   → 開示日時点のスナップショットで判定するように修正
   → short_dn30 の執行可能母集団に影響しうるが、貸借フィルタを外した全日版でも
     純 +0.096% / CI [−0.150,+0.378] で門を通らない。判定は不変
2. 両建てポートフォリオの含み損益が、引け建てとショートで建値と符号を誤っていた
   → 建値をトレード行に持ち、サイドで符号を付けるよう修正
   → 影響は維持率・追証日数・破産日のみ。1本あたりの純エッジと CI は無関係
3. 信頼区間が常に 2.5/97.5 パーセンタイルで、規程の α=0.05/3 が実装されていなかった
   → alpha を引数化。2晩目は片側 0.05/3 を渡す。区間が広がる方向なので判定は不変
   → T1 の「2検定 α=0.05/2」は片側 0.025 = 既定の 2.5 パーセンタイルと一致していた

未確認のまま残るもの
・J-Quants の UL/LL フラグが「触れた」か「引けで張り付いた」か（仕様書に到達できず）。
  どちらでも 2晩目の判定は変わらない（SYSTEM-NIGHT2.md §12）
・往復スリッページ 0.4% は仮定で、実測していない。すべての純エッジがこれと 1:1 で動く
・逆日歩・増担保規制・税は未モデル化。入れれば結果は悪化する方向にしか動かない
```

## 4b. 判断の検算

「続ける」×3視点、「やめる」×3視点の論拠を独立に出させ、各2本の反証と抜け漏れ点検を通したうえで統合した（22エージェント）。
統合判定は「終了」。「続ける」側で反証に耐えたのは §2 末尾の2点と「分解の形は機構と整合している」の3点で、
いずれも「今の市場ではコスト以下」「門を通っても実弾に至る道が無い」に打ち消される。
点検で挙がった未確認事項のうち判断に影響しうるもの:
・ユーザーがシグナル日の 9:00 と 15:25 に画面の前にいられるか（Q4 の回答は「推奨で」で、yes/no ではない）
・J-Quants の当日 fins summary の配信時刻（翌朝の寄付までに当日開示を取れるか）
・150万が今どこにあるか（既存の裁量ルールに戻すなら、そちらには事前登録の門が無いことを自覚する）
いずれも「続ける」側の前提であり、確認できても判定は変わらない。
