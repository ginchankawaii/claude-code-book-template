# 判定：打ち切り

実行日 2026-09-02 / データ J-Quants Light 5年（2021-09-02〜2026-09-01）

---

## 1. 結論

事前登録した主条件で **純エッジ −0.216%**。判定基準の下限 0.05% を下回るため
**打ち切り**。信頼区間も 0 を跨いでいる。

```
主条件: N=5 / 時価総額フィルタなし / 上方修正10%以上 / 常習除外あり
        売買代金フィルタあり / 除外銘柄あり / 往復スリッページ0.4%

  トレード数    2,293
  粗エッジ      +0.809%
  TOPIX超過     +0.250%     市場ベータ分 +0.560%
  純エッジ      -0.216%     滑り0.400% と金利0.054% を控除
  信頼区間      [-0.654%, +0.230%]     0 を跨ぐ
  勝率          52.1%
  1トレードのσ  8.70%
```

## 2. 粗エッジだけを見ていたら実弾に進んでいた

当初仕様の基準は「粗エッジ 0.8% 超 → 少額実弾」だった。
主条件の粗エッジは **+0.809%** で、この基準を満たす。

```
粗エッジ        +0.809%
  うち市場ベータ +0.560%   TOPIXを買うだけで得られる。金利を払う理由がない
  スリッページ   -0.400%
  買方金利       -0.054%
  ────────────────────
  残り           -0.216%
```

粗エッジのほぼ全部が、市場の上昇と取引コストで説明できる。
判定を TOPIX 超過に変えた判断が、そのまま結論を反転させた。

## 3. 保有日数を延ばしても超過リターンは増えない

```
  N     件数      粗      TOPIX超過      純
  1    2,297   +0.391%    +0.229%    -0.190%
  3    2,293   +0.595%    +0.175%    -0.267%
  5    2,293   +0.809%    +0.250%    -0.216%
 10    2,292   +1.255%    +0.222%    -0.302%
```

粗エッジは N に比例して増えるが、TOPIX超過は 0.2〜0.25% で頭打ち。
**増えた分はすべて市場ドリフト**で、イベントの効果は N=1 で出尽くしている。
長く持つほど金利だけが増え、純エッジは悪化する。

## 4. 対照群：イベントに情報はある。ただしコストを超えない

```
  修正率      件数     粗      TOPIX超過     純
  なし     28,490   +0.565%   -0.037%   -0.503%
  ≤ -30%      868   +0.612%   +0.031%   -0.434%
  ≥ +10%    2,293   +0.809%   +0.250%   -0.216%
  ≥ +18%    1,508   +1.053%   +0.505%   +0.039%
  ≥ +36%      680   +1.042%   +0.508%   +0.043%
```

- 下方修正した銘柄を買っても粗 +0.612%。**粗リターンの大半は市場ベータ**
- 超過で見ると上方 +0.250% と下方 +0.031% に分かれ、**符号は期待どおり**
- つまり上方修正には方向性のある情報がある。ただしコストを超える大きさではない

## 5. 閾値を上げると数字は改善するが、統計的に判定できない

+18% / +36% は純エッジがわずかにプラス（+0.039% / +0.043%）。
しかし平均が極小なので、有意と言うには **23万件以上**が必要になる。
5年で集まるのは1,500件程度で、三桁足りない。信頼区間も 0 を跨いでいる。

そして閾値は **+10% と事前登録済み**。良い数字が出た閾値に乗り換える行為
そのものが、仕様の「注意点」に書かれた過剰最適化にあたる。

## 6. 安定性：基準を満たさない

```
対照群を除く本命セル      864
  純エッジがプラス         82 (9.5%)
  うち判定可                0
  うち信頼区間の下限 > 0    0
```

「対照群を除く全セルで純エッジがプラス」という採用条件を満たさない。

## 7. 唯一「判定可」が出たセル（採用しない）

```
N=1 / 上方修正10%以上 / 売買代金フィルタあり / 場中開示のみ / 滑り0.3%
  762件  粗 +0.901%  超過 +0.704%  純 +0.384%  CI下限 +0.059%
```

**4,320セル中の1つ**であり、多重比較そのもの。
しかも最も楽観的なスリッページ0.3%でのみ成立し、0.4%にすると件数不足で
判定不能になる。採用しない。

ただし「場中開示のほうが引け後開示より超過リターンが大きい」という差は、
構造として意味がありうる。

```
  N=1・上方修正10%以上・売買代金フィルタあり
    引け後開示  2,214件   粗 +0.324%
    場中開示      762件   粗 +0.901%
```

引け後の開示は翌朝の寄付に買いが集中して織り込まれるが、場中の開示は
その日の残り時間で織り込みが進むため、翌日始値の位置が違う——という
仮説は立てられる。ただし762件では検証できない。**今回は採用せず、
仮説として記録するにとどめる。**

## 8. 実装の欠陥（結論は変わらない）

最大ドローダウンが -2,889% のような値になっていた。元金50万で建玉150万を
建て、損失が元金を超えてもシミュレーションを続けていたため。
1,440セル中1,192セルが -100% を下回っていた。

破産した時点で退場するよう修正済み。元金別のリスク評価はこの修正後の
数字で見る必要があるが、純エッジがマイナスである以上、結論は変わらない。

## 10. 残った仮説

今回の検証で否定されたのは「決算・業績修正の翌営業日始値で買い、
N営業日後に返済する」という形の戦略である。次が残る。

- 場中開示に限定した場合の挙動（762件では判定不能）
- イベント効果が N=1 で出尽くしている以上、日中の値動きを使う戦略
  （ただし分足データはアドオン月5,500円）
- 上方修正の超過リターン +0.25〜0.5% 自体は実在する。
  コスト構造が違う執行方法があれば成立の余地はある
