MindClip はんだ付け図解

LED・スイッチ・電池の線を作り、XIAO につないで、電池で動くところまで。

できあがりの配線

線長さどこからどこへ
橙60mm抵抗（LED の長い足の先）XIAO の D3
黒60mmLED の短い足スイッチの端の端子
青50mmスイッチの中央の端子XIAO の D1
黒50mmスイッチの端の端子XIAO の GND

線の色が手持ちと違っても構いません。「どこからどこへ」が合っていれば動きます。長さは、両端を剥く分として 5mm 足して切ります。

用意するもの

はんだ付けのコツ：はんだを垂らすのではなく、つなぐ 2つをこてで 1〜2秒温めてから、温めた場所にはんだを当てます。久しぶりなら、余った線どうしで 2〜3回練習してから本番に入ってください。

熱収縮チューブの使い方

熱収縮チューブは、熱を当てると細く縮んで、はんだ付けした金属の部分を覆う絶縁カバーです。どの手順でも、次の 3段階で使います。

  • 長さ：覆いたい金属の部分より、両側に 3mm ずつ長く切ります。
  • 熱の当て方：ライターの炎に入れるのではなく、炎の 1〜2cm 上か横にかざします。炎に入れると焦げて穴が開きます。線を指で回して、全周に熱を当てます。
  • ライターが使いにくいとき：はんだごての軸（先端ではなく、太い金属の部分）をチューブに近づけて、なでるように動かしても縮みます。先端のはんだが付く所は当てません。
  • 縮めすぎ・焦げ：被覆が溶けたり黒く焦げたりしたら、切り取ってやり直します。

ライターを使うときは、電池を机から離す。電池の袋を、火から 1m 以上離れた所に置いてから作業します。

1

LED と抵抗に線を付ける

はんだ 3か所（README の手順3）
  1. 部品の足を短く切る。LED の足は 2本とも根元から 6mm、抵抗の足は両側 3mm を残します。フタの裏の狭い場所に収めるためです。切る前に、LED のどちらが長い足だったか、短い足の側にペンで印を付けておきます。
  2. チューブを切って線に通す。橙の線に φ3 を 20mm。黒の線に φ1.5 を 12mm と φ3 を 20mm。通したら、線の先から 3cm 以上離しておく。
  3. ① 抵抗の片方の足と、橙の線（4mm 剥く）をはんだ付けする。足を線に 1回巻いてから流すと確実です。
  4. ② 抵抗のもう片方の足と、LED の長い足をはんだ付けする。余った足は切る。
  5. ③ LED の短い足と、黒の線をはんだ付けする。
  6. はんだが冷めたら、チューブをずらして縮める（下の図）。橙の線の φ3 は、①・抵抗・②をまとめて覆う位置へ。黒の線の φ1.5 は③へ。縮め方は上の「熱収縮チューブの使い方」のとおりです。
  7. 黒の線の φ3 は、まだ縮めない。次の手順でスイッチに使います。

LED に こてを当てるのは 3秒以内。熱に弱い部品です。足の根元をピンセットではさむと熱が逃げます。
抵抗は必ず入れる。抜くと、LED と XIAO のピンが壊れます。
LED の足は、まだ曲げません。フタに組み込む日に、向きを確認してから曲げます。

2

スイッチに線を付ける

はんだ 2か所（README の手順4）
  1. 端の端子を 1本、ニッパーで根元から切る。
  2. 中央の端子に、青の線（3mm 剥く）をはんだ付けする。端子の小さな穴に通して折り返すと確実です。
  3. 黒の線 2本（LED から来た 60mm と、新しい 50mm）の先を、先にねじり合わせて 1本にし、はんだを少し染み込ませる。
  4. その束を、残った端の端子に 1回ではんだ付けする。
  5. はんだが冷めたら、黒の線に残しておいた φ3 のチューブを、端子の金属とはんだが全部隠れる位置（スイッチ本体に当たるまで）へずらして縮める。スイッチの樹脂に炎を近づけすぎないよう、ここははんだごての軸で縮めるほうが安全です。
  6. 中央の端子（青）は、チューブなしで構いません。隣の端子とすき間があることを目で確かめます。

黒の線を 1本ずつ付けない。2本目を付けるときに 1本目が溶けて外れます。必ずねじってから付けます。
こては 2〜3秒以内。長く当てるとスイッチの樹脂が溶けて動かなくなります。溶かしたら、迷わず新しいスイッチに替えます。

テスターで確認（導通のブザー）

3

電池のコネクタの線を切り、＋を調べる

はんだ なし（README の手順5）

安全の約束は 3つです。
1. 切る・剥くのは、電池につながっていないピグテールだけ。その間、電池は袋の中。
2. 電池を挿している間は、線の先を 2本とも机にテープで留める。
3. 電池のプラグの穴に、テスターの棒や針金を入れない。

  1. ピグテールのオスとメスを電池のプラグと見比べ、指先の軽い力でまっすぐ挿さる側を選ぶ。確かめたらすぐ抜いて、電池を袋に戻す。挿さらなかった側も捨てずに取っておく。
  2. 選んだ側の線を、根元から 60mm と 65mm で切る。先を 2mm 剥き、1本ずつテープで包む。
  3. 図のように机へテープで留める。引っ張っても動かないことを確かめる。
  4. テスターを直流電圧（20V）にする。電池を挿し、先端のテープを外して、棒を 1本ずつ当てる。
  5. ＋3.5〜4.2V と出たら、赤い棒を当てている線が「＋」。マイナスの数字なら、黒い棒の側が「＋」。
  6. 「＋」の線に、テープで「＋」の印を 2か所（コネクタの近くと先端の近く）付ける。
  7. 電池を抜いて袋に戻す。そのあとで、先端をもう一度テープで包む。

線の色（赤・黒）は信用しない。赤と黒が逆の品があります。＋かどうかは、測った結果と自分で付けた印だけで決めます。
途中で線が外れて動いたら、何より先に電池を抜く。

4

XIAO に線を 3本付ける

はんだ 3か所（README の手順6）
  1. USB ケーブルを抜く。microSD カードも抜いておくと安心です。
  2. D1・D3・GND の 3つの穴に、こてを当ててはんだを少しだけ流す（下準備）。
  3. 線の先を 3mm 剥いてねじり、はんだを少し染み込ませる。
  4. 線を裏面から穴に差し込み、部品面側からこてを当ててはんだを流す。青 → D1、橙 → D3、黒 → GND の順に。
  5. 部品面に突き出た線の先を、ニッパーで根元から切る。部品面に残るのは、はんだの低い山だけにします。
  6. 線は裏面に沿わせ、下の図のように3本を重ねずに並べて、USB と反対の端の真ん中から外へ出す。部品面の上を横切らせない。基板の長い辺から外へ出さない。

つなぐ前にテスターで確認（導通のブザー）

GND が 5V や 3V3 とくっつくと、電源がショートします。ここは特に念入りに確かめてから USB を挿してください。くっついたら、吸い取り線で取ってやり直します。

5

電池をつなぐ

はんだ 2か所（README の手順8）。＋と−を逆にすると XIAO が壊れます

流れは「付ける → 確かめる → つなぐ」の 3段階。はんだ付けの間は電池をつながないので、ここで壊れることはありません。壊れるのは、間違えたまま電池を挿した瞬間だけです。だから B の確認を飛ばさないでください。

A　電池の線を XIAO に付ける（電池はつながない）

  1. USB を抜く。電池は袋の中。XIAO のコネクタには何も挿さっていないこと。
  2. BAT＋ と BAT− のパッドに、はんだを少しだけ乗せる（盛り上げない）。フラックスを塗ると楽です。＋と−は基板の文字で確かめる。読めなければ進まない。
  3. 「＋」の印を付けた線を BAT＋、もう一方を BAT− にはんだ付けする。こては 3秒以内。
  4. 2本は裏面に沿わせて平らに置く。ほかの線と重ねない、交差させない。

B　電池をつなぐ前の確認（テスター）

1つでも合わなければ、電池をつながない。④が合わないときは、電池が外れていることを確かめてから、A の 2本を入れ替えて付け直し、①〜④をやり直します。②が鳴らないときは、そこで止めて連絡してください。

C　電池をつなぐ

  1. USB は抜いたまま、電池を XIAO のコネクタに指先の軽い力でまっすぐ、ツメが掛かるまで挿す。
  2. スイッチを ON にする。LED が点けば、電池で動いています。
  3. USB を挿す。XIAO の充電ランプが点くか点滅し、満充電で消えれば、充電も正常です。
