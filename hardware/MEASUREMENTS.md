# 実測チェックシート（印刷前に必ず埋める）

> **2026-11-14: 全項目の実測が済みました（M7 はカバンに付けないので対象外）。**
> 実測値はすべて CAD（v1.11）に反映済みで、**`stl/allday/` の v1.11 データが、そのまま印刷してよいデータです**（slim も同じ実測値で再生成済み）。
> 別の部品（電池・ピグテール・スイッチ・LED）を使う人は、下の表で測り直してください。

筐体CADには **Web で裏が取れなかった仮定値** が残っている（README §9.1）。
3Dプリントは「時間もフィラメントも戻ってこない」ので、**印刷前にこの9項目（M7 はカバンに付ける場合のみ）を実測し、
CAD のパラメータを確定させてから** `cad/mindclip_case.py` を再実行すること。

**2026-11-03 と 2026-11-14 に実測済み（下表の実測値列）。** **図解ページ（測る場所の図・入力欄・その場で判定）**: https://claude.ai/artifact/MfafZtwUKvnNrV9dCX7xjX （ソースは [`measure-guide.html`](measure-guide.html)。入力した値は保存され、Claude が読み取って CAD に反映する）

記入したら数値を `cad/mindclip_case.py` に反映 → **実行できる 2構成（allday/none・slim/none）**を再実行 → STL を再生成する。
（基板構成 `sense` / `carrier` は、基板の再設計が済むまで CAD が理由を表示して終了する。MECHANICAL.md §11）

**実物でまだ確かめていない項目（2026-11-14 時点。どれもノギスの表の外・印刷は止めない）**:
- **XIAO 基板の角の丸み** — 未実測。角が丸くても直角でも入るように筐体を逃がしてあるので、どちらでも安全。
- **アンテナフィルムの寸法** — 未実測。貼る前に仮置きしてフタが閉まるか確かめる（README 手順10-4）。
- **USB-C ケーブルのプラグ根元（樹脂）と座ぐり 13×8×深0.8mm** — 未確認。太いケーブルは奥まで挿さらない可能性。
- **重さ** — 電池（11g）以外は見積値。組み上がった状態の総重量は未実測。

## 補助チェック（ノギス不要）

- [ ] **電池: 黄色テープの下に保護基板（PCM）があるか目視**。無ければ使わない（XIAO 側に過放電保護は無い）
- [ ] **電池: 極性と電圧の確認は README 手順5-4 の方法で**（ピグテールを挿し、机に固定した線の先で測る。3.5〜4.2V の範囲か）。
      **電池のプラグの穴にテスターの棒や針金を直接当てない**（1.25mm ピッチではショートする）。線の色（赤 = ＋）は信用しない
- [ ] **磁石: φ6 × 厚 2.0 mm か**（厚 2.5 / 3.0 mm はポケットに入らない）
- [ ] **USB-C ケーブル: データ線が生きているか**（充電専用ケーブルでは書き込みできない）
- [ ] **USB-C ケーブル: プラグ根元の樹脂（オーバーモールド）が 幅 13 × 厚 8 mm 以下か**（筐体の座ぐり 13×8×深0.8 に入るか。未実測）
- [ ] **アンテナフィルム: 縦・横の寸法を控える**（貼る場所は README 手順10-4。未実測）
- [ ] **XIAO 基板の角の丸み**: 角が丸いか・ほぼ直角かを目視（CAD は直角でも入るように右上の角を逃がしてある。未実測）

## 実測値が設計値とズレたときの手順

1. `cad/mindclip_case.py` の該当変数を実測値に書き換える
2. `GOLDEN_OUTER` が外形の回帰テストとして効いているので、**外形が変わると assert で止まる**。
   これは正常な挙動。変わった外形を `MECHANICAL.md` §1・§11.1 と `README.md` §3 に反映してから
   `GOLDEN_OUTER` を新しい値に更新する
3. 実行できる 2構成（allday/none・slim/none）を再実行し、干渉チェックが通ることを確認
   （`sense` / `carrier` は基板の再設計待ちで、CAD が理由を表示して終了する）
4. STL を再生成してから印刷する
