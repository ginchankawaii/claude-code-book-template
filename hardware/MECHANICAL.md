# MindClip DIY — 筐体メカ設計仕様 (v1.11)

v1.11 での設計変更 (2026-11-14 の最終実測を反映。**body と lid が形状変更**、backplate / strapplate / magsafeplate は不変):

- **JST 嵌合体を実測値に** (M4): `HARNESS_JST_XYZ` = 幅 4.2 × 長さ 9.2 × 厚み 3.3 (旧仮値 5.8 × 11.0 × 4.5)。
  採用ピグテール (楽天「JST 1.25mm 15cm 2ピン オス＆メス 20ペア」) は採用電池に嵌合することを現物で確認した。
  箱は **x1.60–5.80 / y28.60–37.80 / z1.60–4.90**。
- **ピグテールの継ぎ足しを廃止** (`HARNESS_SPLICE = False`)。線の外径は実測 **0.90mm** (M5) で、XIAO 下
  (通せる外径 1.3mm まで) をそのまま通せる。**はんだは 12 → 10 点に戻った** (線が太いピグテールで継ぎ足す場合のみ +2)。
  `harness_splice` の箱は確保しない。嵌合体の幅が 4.2 に狭まったので、旧来の「嵌合体の真上に継ぎ目 2 本」は
  **LED と干渉する** (`HARNESS_SPLICE = True` にすると `INTERFERENCE: led <-> harness_splice` で止まる)。
  太い線のピグテールに替えて継ぎ足すなら、置き場所から設計し直すこと。
- **LED 窓が 1.6mm 左へ** (中心 x9.8 → **x8.2**。窓の x は嵌合体の幅に追従する)。LED 本体 x6.60–9.80、
  リード帯 x6.60–10.20、スリーブ x5.70–10.70。電線の通り道は x10.20–14.40 に広がった。
- **LED の実測** (M8): ツバ φ3.4 × **0.6**、ツバ上面〜先端 **4.4** (全長 5.0 − 0.6)。`LED_PROTRUDE_STD` 2.7 → 2.6、
  **沈め量 (スリーブ長) 2.9 → 2.8mm**。ドーム先端は両バリアントとも外面の 0.2mm 内側のまま。
- **XIAO スタック 8.2 → 8.3mm** (M1 再測。大きいほうを採用)。allday の外形は不変、**slim は奥行き 13.6 → 13.7mm**
  (内寸 10.2 → 10.3)。XIAO 上面とマイク穴の中心が 0.1mm 上がった (穴 z9.65–11.15)。
- **マイク穴の位置** (M9): `MIC_X_ON_BOARD` = 5.1 / 8.6 / 12.1 (旧仮定 6.6 / 10.1 / 13.6)。**穴は x22.5 / 26.0 / 29.5**
  (1.9mm 左へ)。写真と実測から、マイク中心は基板の USB と反対の端から 8.2mm。穴 3 つで ±3.5mm をカバーする。
- **スイッチのレバー幅 1.4mm** (M6。旧仮定 2.0)。スロット長 5.0 に対する必要長は 3.8mm。形状変更なし。
- 嵌合体が低くなり (z≤4.9)、旧座標 y31–42 に置いてもスイッチ端子 (z≥5.6) の下に入るようになったため、
  「旧配置は必ずスイッチ端子と当たる」回帰テストは撤去した。
- 出力の変化: `mindclip_body.stl` と `mindclip_lid.stl` (allday / slim とも)。**v1.10 以前に印刷した body / lid は使えない。**
- **この文書の v1.8 rev2 以前の変更履歴 (下) にある座標・点数は当時の値**である。現在の値は §1 以降と §7.1 を見ること。

v1.8 rev2 での設計変更 (レビュー指摘の修正。外形は v1.8 と同一、**body のみ形状変更**):

- **実行できる構成は `allday/none` と `slim/none` の 2 つだけ**になった。`carrier` (MC-CARRIER-A) は
  基板が左アンカーの固定外形 (XIAO フットプリント右端 x36.4) のままで、筐体側の XIAO (x17.4–38.4) と
  2.0mm 食い違い、USB-C レセプタクルが座ぐりの約 1.5mm 奥に引っ込む STL を出していた。
  `sense` と同じく **CAD が読み込み時に理由を出して停止**する。古い `*_carrier` の STL・レンダは削除し、
  `GOLDEN_OUTER` からも外した。**基板オプションは 2 つとも再設計待ち** (§11)。
- **ピグテールの継ぎ足しを標準手順にした** (README 手順5)。購入した 1.25mm ピグテールの線は
  XIAO 下 (リフト 1.4mm、通せる外径 1.3mm まで) を通せない可能性があるため、コネクタ根元から
  約 10 / 15mm で切って AWG28 に継ぐ。**はんだは 10 → 12 点**。継ぎ目 2 本 (φ2.5×10) の置き場所を
  `harness_splice` (JST 嵌合体の真上 x1.90–6.90 / y28.90–39.30 / z6.40–8.90) として CAD に追加し、
  全部品と 0.3mm 以上のクリアランスを毎回検査する (§7.1)。
- **マイク穴の x を XIAO 基準の相対値に** (`MIC_X_ON_BOARD` = 基板左端から 6.6 / 10.1 / 13.6)。
  旧版は絶対値 22.0 / 25.5 / 29.0 の直書きで、v1.6〜v1.8 の幅拡大で XIAO が右へ 2.0mm 動いても
  穴だけ取り残されていた。**穴は x24.0 / 27.5 / 31.0 へ +2.0mm 移動**。マイクの実位置は未実測 (M9)。
- **XIAO 右上コーナーの逃げ**。XIAO は右内壁密着・上内壁から 0.6mm なので、基板の右上の角が
  キャビティのコーナー R2.5 の肉に食い込んでいた (四角い箱でブーリアンすると 4.17 mm³。AABB 検査では
  見えない)。基板のコーナー R (`XIAO_CORNER_R` = 1.9、**未実測**) に頼らず、**R=0 の四角い基板でも
  上側に 0.15mm 残る**ように基板輪郭 +0.15 を切り欠いた。`check_xiao_fit()` がソリッド同士の
  ブーリアン (陽性対照つき) で毎回検査する。**その角だけ外壁の最薄部が 0.91mm になる** (§5 の表)。
- **スイッチ右端の挟みリブを追加** (`sw_ribs[1]` x13.0–13.8)。旧版の「右端は XIAO ストップリブが兼ねる」は
  誤りで (リブは x14.4〜 / y40–44、スイッチ右端は x12.7 / y44.5〜)、実際は上壁の凹みだけが位置決めしていた。
- **`check_layout()` の空検査を実効化**: レバー突出 (外面から 1.5–3.0mm。実値 2.10) とスロット長
  (レバー幅 `SW_LEVER_W`=2.0 **assumption** + スライド量 2.0 + 0.4 ≤ 5.0)、スイッチ本体が凹みに全軸で
  収まること、凹み上の残り肉厚、USB レセプタクル先端が外面と座ぐり底の間にあること、マイク穴が XIAO の上に
  あること。恒真式だった `sw[3] <= …` / `WALL - SW_RECESS >= 0.8` / `USB_PROTRUDE <= WALL` は置き換えた。
- **strapplate の USB 切り欠きの保証内容を訂正**。v1.8 で開口が下がり、座ぐり下端 (本体 z1.9) は
  リム上端 (z2.5) より低い。成立しているのは「リムを座ぐりの前で**全高**切り欠いているから」で、
  切り欠きが座ぐりを y で両側 0.5mm 以上・z でリム全高を覆うことを assert し、座ぐりの前にリムの肉が
  無いことをブーリアンで検査する。**strapplate の STL は v1.8 とバイト一致** (検査の追加のみ)。
- `LED_FLANGE_R/T` を実測の 1.7 / 0.5 に (検査のみに使う値で lid の形状は不変。**lid は v1.8 とバイト一致**)。
- 出力の変化: `stl/allday/mindclip_body.stl` と `stl/slim/mindclip_body.stl` の 2 ファイルのみ。

v1.8 での設計変更 (部品の実測値を反映。MEASUREMENTS.md):

- **電池 32.0 × 25.0 × 8.0** (実測。仕様表の 31 より 1mm 長い) → `BAT_W` 31→32、内寸幅 35.8→36.8、
  **外形幅 39.0 → 40.0 mm**。電池両脇の隙間 (BAT_TOL) は従来と同一。
- **XIAO スタック 8.2 mm** (旧仮定 7.5) → allday は外形不変 (9.2 まで余裕)、**slim は奥行き 12.9 → 13.6 mm**。
- **USB-C 中心はスタック下面 (BAT パッド面) から 2.9 mm** (A4.50 − B3.20/2。旧仮定 3.2) → 開口を 0.3mm 下げた
  (`USB_CENTER_ABOVE_STACK`)。
- **スイッチ SS-12D00G3 は本体 4.0 / レバー 3.0 mm** (G3 = レバー 3mm 品。旧仮定 3.5 / 2.0)。
  これに伴いスイッチ挟みリブが 0.5mm 下がり、**`sense` 構成 (MC-SENSE-A, v2 検討用・発注禁止) はポケット高さが
  15.9 < 16.4mm で不成立**になった。CAD は理由を出して停止し、古い `allday_sense` / `slim_sense` の STL・レンダは削除した。
  基板を作る段階でスイッチ位置か基板外形と一緒に再設計する。
- **LED (OSR5JA3Z74A) はツバ φ3.4 × 0.5、ツバ上〜先端 4.5mm** (実測)。沈め量は設計どおりで CAD 変更なし。
  ツバが窓径と同じでスリーブ端で止まらない個体があるため、**フタを伏せて LED 先端を机に当てて接着**する組立に変更。
- **JST ピグテール (SONONIA B076SSLHHL) は嵌合 15.0 × 8.0 × 2.8・線径 1.5mm で 2.0mm 系だった** →
  電池 (1.25mm ピッチ 2P) と嵌合せず不採用。**買い直し品は「JST 1.25mm 15cm 2ピン オス＆メス 20ペア」**
  (楽天・Coolotic 系)。電池との嵌合と M4 は**未実測**で、測るまで `HARNESS_JST_XYZ` は据え置き
  (5.8 × 11.0 × 4.5)。線径 (M5) は継ぎ足しが標準になったため合否に関係しなくなった (v1.8 rev2)。

v1.7 での設計変更 (目立たない装着・カバン対応):

- **LED を沈めてリッド面とほぼ面一に**。リッド内面からスリーブ (外径 φ5.0 / 内径 φ3.4) を降ろし、
  LED のツバを LED_RECESS だけ下げて受ける。allday は 2.9mm 沈めてドーム先端が外面の 0.2mm 内側、
  slim は奥行きが浅く 2.2mm で打ち切り (0.5mm 突出)。打ち切り条件は「90度曲げのリード帯の下端が
  床から 0.3mm 以上残ること」で、`check_layout` が assert する。ツバ (φ3.9×1.0) を `led_flange` として
  新たに干渉検査に加えた。基板構成 (sense/carrier) は LED 直下に J1 / 0805 があり沈められないため
  従来形状のまま。**body / backplate は v1.6 とバイト一致** (lid のみ変更、PCB 構成の lid も一致)。
- **カバンのショルダーストラップ用マウント `strapplate` を追加** (外形 42.0 × 52.4 × 5.1 + リム 2.5)。
  ストラップは 2 本のスロットに編み込み (トライグライド原理) 、本体はリムに嵌めて磁石で直接吸着する
  (布を挟まないので磁石間 1.0mm)。ストラップ寸法は `MINDCLIP_STRAP_W` / `MINDCLIP_STRAP_T`
  (既定 38 / 2.5mm)。本体との実形状ブーリアンで「載せて干渉 0」と「0.6mm 横ずれでリムに当たる」
  (陽性対照) を毎回検査する。開発中、リム上端のフィレットを USB 切り欠き後に掛けたところ OCC が
  不正ソリッドを返し、union でリムが黙って消えた (陰性対照だけでは検出できなかった) ため、
  フィレット順序の修正と陽性対照・有効性 assert を恒久化した。

v1.6 での設計変更 (採用電池の実仕様反映):

- **採用電池を HXJNLDC 802530 (680mAh・メーカー仕様表 31×25×8.0mm・11g) に確定**
  (bom.md #2)。公称型番の 30.0mm でなく仕様表の 31.0mm を CAD の正とし、
  **内寸幅 34.8 → 35.8 / 外形幅 38.0 → 39.0** に拡大。電池両脇の隙間
  (左1.25 / 右lip 1.25 / 右壁2.4) は v1.4 と同一を維持。
- 内寸拡大により **X置きJSTも幾何的には成立する**ようになった (隙間約0.6mm)。
  Y置きは「唯一の可能解」から「採用した慣例」に変わったため、X置き不成立を
  主張する負のテストは撤去しログ出力に変更 (組立ガイドと CAD ガイド形状は
  Y置き前提のまま)。
- 基板オプションの **PCB 外形をポケット導出から定数へ変更** (基板は固定物のため、
  筐体幅の変更で「基板が育つ」バグを排除)。sense は右ガタ止めナブを追加。
- X置きJSTの負のテストをクリアランス基準 (<0.3mm) に更新。

CADモデル: [`cad/mindclip_case.py`](cad/mindclip_case.py) (CadQuery 2.8 パラメトリック)
実行すると `stl/<tag>/` に3パーツのSTL、`renders/<tag>/` にレンダ5枚を生成し、
内部レイアウトの干渉チェック (assert) と STL の watertight 検証を行う。

**バリアントは環境変数 `MINDCLIP_VARIANT`、基板構成は `MINDCLIP_PCB` で切り替える**
(既定 `allday` / `none`。出力タグ `<tag>` は `allday` と `slim` の 2 つ):

```
python3 hardware/cad/mindclip_case.py                        # allday / 基板なし (採用構成)
MINDCLIP_VARIANT=slim python3 hardware/cad/mindclip_case.py  # slim   (LiPo 502530 / 500mAh)
```

**いま実行できるのはこの 2 構成だけ。** `MINDCLIP_PCB=sense` と `MINDCLIP_PCB=carrier` は
どちらも「基板の再設計が必要」というメッセージを出して終了する (v2 の検討用。§11)。

> **v1.5 の採用構成は「基板を作らない」= 案A-1**
> （回路の正本は [`pcb/SCHEMATIC.md`](pcb/SCHEMATIC.md)、判断の経緯は
> [`pcb/LAYOUT.md`](pcb/LAYOUT.md) §0）。基板側の対応 (`sense` / `carrier`) は
> 「発注前に筐体が本当に受けられるか」を先に固めるためのもので、**§11** にまとめた。
>
> **v1.5 rev2 で lid だけ形状が変わった（再印刷が必要）。**
> `body` と `backplate` は v1.4 と**バイト一致**（回帰確認済み）だが、`lid` は
> **LED 窓を x6.9 → 9.8 へ移し、径を φ3.2 → φ3.4 に広げた**ため v1.4 と別物になる。
> v1.4 の lid を印刷済みでも、**必ず新しい lid を刷り直すこと**（約4.7g / 20〜30分）。
> 理由は §7 と §11.4（旧 LED 位置は JST 嵌合体の真上で、90°に曲げた LED リードが
> slim で 1.0〜2.0mm 干渉していた）。

**既定は allday**。省電力実装なしの worst case (54.4mA) で slim は約7.8時間しか持たず
「起床〜就寝」を走り切れないため (ELECTRICAL.md §2.2)。電池はフットプリント
が近く (allday 32×25 / slim 30×25mm) 厚みが違うが、**筐体奥行きの差は 0.9mm だけ**
(14.6 / 13.7。slim の奥行きを支配しているのは実測 8.3mm の XIAO スタック側のため)。
初心者向け組立ガイドは [`README.md`](README.md)。

v1.5 rev2 での設計変更 (採用構成 A-1 を実際に組める形にするための修正):

- **「箱にならない部品」を CAD に追加した**。旧版はスイッチを本体 8.7×3.7×3.5 の
  箱、LED を φ3 の円柱としてしか持っておらず、**-y に出る端子3本**も
  **90°に曲げた LED リード**も存在しなかった。このため左ポケットの部品を
  どこに置いても `check_layout()` が通ってしまっていた。
  - `sw_terms` = スイッチ端子 (3.5mm) + はんだ + φ3 熱収縮の包絡
    (x4.21–9.95 / y40.50–45.00 / z は本体中心 ±1.6)
  - `led_leads` = 曲げリード (本体下面から 3.0mm) + 220Ω + 継ぎ目 + 熱収縮の包絡
    (x8.20–11.80 / y28.60–37.60 / z は LED 下面 −3.0)
- **JST 嵌合体の置き場所を変更**: x3.0–8.8 / y31.0–42.0 →
  **x1.60–7.40 / y28.60–39.60 / z1.60–6.10**（左内壁に密着、Y方向に寝かせる）。
  旧位置はスイッチ端子との分離が slim で **0.00mm**（熱収縮込みで −1.35mm の実干渉）だった。
- **LED 窓を x6.9 → 9.8 へ移動**（+2.9mm）。旧位置は JST 嵌合体の真上で、
  曲げた LED リード (allday z5.8 / slim z4.1) が嵌合体上端 z6.10 と
  **slim で 1.0〜2.0mm、allday でも 3mm 曲げで 0.3mm 干渉**していた。
  左ポケットの y 方向には LED 帯の上下どちらにも 11.0mm の嵌合体が入らないため、
  **逃げられる方向は x しかない**（JST を左壁に密着 + LED を右へ = 隙間 0.8mm）。
- **LED 窓 φ3.2 → φ3.4** (`LED_WIN_FIT`)。FDM の穴は 0.1〜0.3mm 小さく出る (§5) ため、
  φ3.2 では実効 2.9〜3.1mm となり φ3.0 の LED が入らない個体が出る。
- **既定パラメータでの外形を直接 assert する** (`GOLDEN_OUTER`)。従来は
  `XIAO_STACK_T` / `BAT_T` / `J1_BODY_Z` などの assumption を書き換えると
  **assert を一つも出さずに外形だけが育った**（§11.4 の「負のテスト」が
  自己充足的だった原因）。公開値と食い違ったら必ず落ちる。
- **`harness_jst` の検査を実効化**: 旧版は6部品に対し `clearance >= 0.0`
  （＝接触を合格とする）だけで実質デッドコードだった。全部品との総当たり
  **0.3mm 以上**に変え、キャビティ収容と天井余裕 (嵌合体 + 電線曲げ代 2.4mm) も要求する。
- **XIAO 裏面はんだ逃げの assert を 1.2 → 1.4mm** （実装値 `XIAO_LIFT` と同値）。
  旧 1.2 は実装値より緩く、リフトを下げても発火しない空の検査だった。

v1.5 での主な設計変更 (基板化の受け入れ + CAD の潜在バグ修正):

- **基板オプション `MINDCLIP_PCB` を追加** (`none` / `sense` / `carrier`)。§11。
  `none` は v1.4 と同一形状 (STL バイト一致で回帰確認)。
- **`MC-SENSE-A` (10.0×15.6×0.8t) を左ポケット床に受ける保持機構を実装**:
  上ガイド壁2片 + 抜け止め爪2個 + ストップナブ2個 + J1 の THT ピン逃げ座ぐり。
  **allday は外形 38.0×49.4×14.6 mm のまま変わらない**。
- **`MC-CARRIER-A` (34.2×21.0×0.8t) 対応**: `GAP_BX` 1.2→1.8 / `M_TOP` 0.6→1.8 /
  `XIAO_LIFT` 1.4→1.6、XIAO 位置決めリブ一式 (座面4/左ストップ2/上下ナブ4/スイッチ挟み1)
  を **基板シェルフ7枚 + 取付ボス2本 (φ1.8)** に置換。外形 **38.0×51.2×14.9 mm**。

    - 貼付後に**マイク穴 3 つが塞がれていないこと**を外から目視する (README 手順10-4 のチェック)。
    - フィルム実寸は未実測 (assumption) なので、**貼る前に現物を仮置きして
      リッドが閉まることを確認**する (§7 の仮組み手順に含める)。
  - SDカードはリッドを開ければ抜き差しできる想定だが、右壁密着側のため
    **実機確認までは assumption** (スタックを持ち上げる必要があるかもしれない。
    運用は WiFi 同期なので挿抜は稀)。
- **バッテリー**: 下段。磁石ボス (h1.4) と支持リブ2本の上に載せる。
  **x 方向は「左端ストップリブに突き当てる」= 左突き当てで位置決めする**
  (v1.3→v1.4 で変更。電池右端と右内壁の間には **2.4 mm の隙間が残る** (allday。slim は 4.4 mm)
  が、これは**リッド右 lip の通り道なので埋めない**こと。旧版の「右詰め」は誤りのため撤回)。
  - **リード線は左端面から出る** (802530 / 502530 のタブは長さ30mm方向の端面=25mm幅の
    面から出射)。左側の **2.4 mm リード曲げチャネル** を上へ回し、電池上の 1.2 mm ギャップ
    から XIAO 下の逃げ空間 (1.4 mm) を通って裏面 BAT パッドへ。
    リード・LED余長は **電池上面より下** (allday z≤11.0 / slim z≤8.0、lip 挿入帯を避ける)
    に収めること。
  - **位置決め**: 左端ストップリブ2本 (中央 y9〜22 はリード用に開放) + 下端ストップ
    リブ2本 + 上端ナブ (XIAO 下端ナブと兼用) で x/y を拘束。
    **x+ (右) 方向には物理ストップが無い**ので、両面テープでの固定が位置決めを兼ねる
    (allday では右 lip までの隙間が 1.25 mm。それだけ右へずれるとリッドが閉まらなくなる)。
    z はリッド内面の **押さえリブ2本** (電池上面と 1.0 mm ギャップ、電池厚に自動追従) +
    **1mm 薄スポンジ** (必須、bom.md #9a) でラトルとリード疲労を防ぐ。
  - **リッド lip 帯とのz関係はバリアントで異なる**:
    - slim: lip 帯 z9.7〜11.9 に対し電池上面 z8.0 (厚め 5.3mm 個体でも z8.3) → z方向で
      逃げている。**5.5 mm を超える個体は使わない**こと。
    - allday: lip 帯 z10.6〜12.8 に対し電池上面 **z11.0** → **z方向では重なる**。
      よって非干渉は**水平方向の隙間で担保する**。内寸幅 36.8 mm・電池 32.0 mm で
      左右とも **1.25 mm** の隙間があり、LiPo の寸法公差 (±0.5 mm) と PCM 端の
      膨らみを吸収できる。**厚み 8.5 mm を超える個体は使わない**こと。
      - **v1.4 の修正**: 旧版 (内寸幅 34.0) では右隙間が **0.45 mm** しかなく、
        公差次第で干渉し得た。さらに z 方向の assert が電池厚 5.3 mm 固定値で
        書かれており、**allday では常に成立する空の検査になっていた**。
        現在は実際の電池厚から z クリアランスを計算し、z で逃げられない場合は
        左右の水平隙間が公差代 `BAT_TOL` (1.0 mm) 以上あることを assert で要求する。
        旧値 34.0 に戻すと assert が発火することを回帰確認済み。
- **スイッチ**: 上壁内面の浅い凹み (深さ0.7) にはめ、左右の挟みリブ (片側 0.3mm。右側は
  v1.8 rev2 で追加) で横ずれを抑えて接着 (ホットボンド可)。レバーは上面のスロット 5.0×2.2
  から **2.1 mm** 突出し、手探りで操作できる (レバー幅は実測 1.4mm。スロット長は幅 2.6mm まで可)。
- **LED**: リッドの **φ3.4** 窓 (中心 x8.2 / y36.0) に内側から挿し、**リッドを伏せてドーム先端を机に当てて止め** (実測のツバ φ3.4 は窓と同径でスリーブ端では止まらない。窓の外面はマスキングテープで塞いでおく)、ドームをほぼ面一にして**エポキシで接着**
  (瞬着は白化ガスでレンズが曇るため LED 近傍では不可、ELECTRICAL.md §5.4)。
  足は 90° に曲げてリード線を XIAO へ。**配線余長 allday 60 mm / slim 45 mm** (リッド開閉分。slim で 60mm にすると充填率が上限に張り付きフタが閉まらない。§7.1 / SCHEMATIC §5.6)。
- 内部干渉チェックはスクリプト内の `check_layout()` が AABB ベースで assert する
  (バッテリー/XIAO/スイッチ/LED/lip/磁石ボス/全リブ類のペア + キャビティ収容 +
  磁石ウェブ + はんだ逃げ 1.2mm 以上 + lip-電池クリアランス)。

## 4. リッドの嵌め合い (スナップフィット、工具不要)

- リッドは lip (スカート、深さ2.2・厚さ1.0) を内寸に差し込む方式。
  片側クリアランス **0.15 mm** (FDM公差 0.2–0.3 を実測で吸収する前提の初期値)。
- **スナップ**: lip 外面の丸リッジ (**突出0.3**、左辺2 + 下辺2) が、本体内壁の
  水平溝 (深さ~0.3) にパチンと入る。半円断面が進入テーパを兼ねる。
  受け溝は内壁の水平半円溝 = 内部オーバーハングのため印刷面が荒れやすく、
  **初回は嵌合調整前提** (溝を軽く針ヤスリでさらう)。
- **保持構成**: 左辺 (全高) + 下辺 + 右辺下部 + **上辺左コーナーのスタブ lip** の
  4箇所で位置決め・保持。上辺右側 (XIAO 上端) と右辺上部 (XIAO/USB) は切り欠き。
- **開け方**: 底面中央の**こじ開けノッチ**に爪を掛けて手前に起こす。
- lip のたわみ代: 左 lip 内面と電池の間に 1.25 mm (必要たわみ 0.35 mm に対し余裕)。
- きつい/緩い場合: `mindclip_case.py` の `CLR` を ±0.05 単位、リッジ突出
  `SNAP_PROTRUDE` を 0.1 単位で調整して再出力。
  応急処置なら lip 外面を軽くヤスリ掛け (きつい場合)。

- **壁厚 1.6 mm 設計則の例外** (強度上は許容、意図的な局所薄肉):

  | 箇所 | 残し厚 |
  |---|---|
  | スイッチ凹み上の上壁 | 0.9 mm |
  | USB-C 座ぐり底の右壁 | 0.8 mm |
  | スナップ受け溝の背後 | ~1.3 mm |
  | 磁石ポケットのウェブ | 0.8 mm (磁力を通すため意図的) |
  | **XIAO 右上コーナーの逃げの最深部** (v1.8 rev2) | **0.91 mm** (切り欠きの角 1 点。そこから離れるとすぐ 1.6 に戻る) |

  XIAO 右上の逃げについて: 基板の右上の角 (x38.4, y47.2) から外形コーナー R4 の円弧までは
  もともと 1.00 mm しかなく、**四角い基板を入れる前提では 1.2 mm (壁 3 周) を残せない**
  (逃げ 0.15 mm を取ると 0.91 mm)。1.2 mm を守るには外形 R を小さくするか XIAO を 0.7 mm 下げる
  必要があり、どちらも外形・リッド・strapplate に波及するため採らなかった。基板のコーナー R を
  実測して 0.9 mm 以上あると分かれば、逃げを円弧に変えて 1.2 mm を確保できる。

- 公差の考え方: 「穴・ポケットは公称+0.2、嵌め合いは片側0.15」を初期値にしている。
  FDMの穴は 0.1〜0.3 mm 小さく出るため、磁石ポケット φ6.2 が**圧入不能の場合は
  `MAG_FIT` を +0.1 して再出力** (まず端材でテスト印刷推奨)。
  **LED 窓も同じ理由で v1.5 rev2 に φ3.2 → φ3.4 (`LED_WIN_FIT` = 0.4) に広げた。**
  それでもきつい場合は 3.0mm ドリルまたはリーマで軽くさらう
  (窓は化粧面なので、削るのは内側から)。

## 6. 磁石の組み付け (φ6×2 ネオジム ×4)

1. **極性確認が最重要**。先に4個を「本体用2個」「裏板用2個」に分け、
   布 (またはリッド) を挟んで **引き合う向き** をマスキングテープ等でマーキングする。
   左右2箇所とも同じ向きに揃えること (片方逆だと反発して固定できない)。
2. ポケットは φ6.2 × 深さ2.2 (磁石2.0 + 接着剤しろ0.2)。指で押し込める程度の
   軽圧入になる想定。緩い場合も接着で保持するので問題ない。
3. 接着は **エポキシ (2液) を推奨** (LED窓と同じ理由で瞬着の白化ガスを筐体内に
   出さない)。ポケット底に少量塗り、磁石がポケット面より沈む (面一以下になる)
   ことを確認して硬化待ち。
   - 本体側: ポケットはバッテリー室の床 (ボス上面) に開口。**バッテリーを入れる前に**接着。
   - 裏板側: ポケットは布側の面に開口 (= 吸引方向に開口するため、**ポケット底面への
     接着を厳守**。接着が甘いと取り外し時のピール荷重で磁石が抜ける)。
     肌側は無加工の完全フラット。
4. 磁石と布の間は本体側 0.8 mm ウェブ + 裏板側 0.8 mm ウェブのみ。
   保持力概算 (N35): ギャップ計 ~2.1 mm で法線力 ≈ 2〜2.5 N/ペア × 2 → 布摩擦込みの
   滑り保持 ≈ 120〜150 gf、装着側 (body + 中身) **30〜31 g** (§1 の重量表)
   に対し **余裕約4倍**。シャツ〜薄手ジャケットは保持可。
   厚手 (2mm級) の生地でずり落ちる場合は **φ6×3 に変更** (`MAG_T` を変えてポケット
   深さを再生成) するフォールバックを維持。

## 7. 組立手順 (案A-1。はんだ付けは **10点**。線が太いピグテールで継ぎ足す場合のみ +2)

> **正本の順序**: 回路と配線は [`pcb/SCHEMATIC.md`](pcb/SCHEMATIC.md)（§1.4 のはんだ点表が正）、
> 作業手順は [`README.md`](README.md) §7、機構の座標と干渉はこの §7。
> ELECTRICAL.md §1/§3/§4/§5 も（JST コネクタ化 + GND デイジーチェーン化 = 10点。v1.11 でピグテール継ぎ足しの 2点を廃止）に
> 更新済み。旧版の「電池コネクタは付けない」という決定は撤回された。

**はんだ付けは合計10点** (電池側ピグテール→BAT パッド 2 +
XIAO信号3 + スイッチ2 + 抵抗1 + LED1 + 抵抗↔LED のリード継ぎ1。線が太いピグテールで継ぎ足す場合のみ +2)。
v1 にあった**空中3端子スプライス (黒線3本のより合わせ) は廃止**し、
GND は「XIAO GND → スイッチ片端端子 → LED カソード」のデイジーチェーンにした。
**ピンヘッダ/ピンソケットは使わない** (高さが増えて筐体に入らない。XIAO のスルーホール
へ直はんだする方針が確定。詳細と難易度は ELECTRICAL.md §3)。

1. 磁石を body / backplate にエポキシ接着 (§6)。硬化を待つ。
2. **電気サブアセンブリを筐体外で完成させる** (SCHEMATIC.md §1.4 / README §7 の順序に従う):
   1. スイッチ+青線、LED+220Ω+橙線、および**スイッチ片端端子 → LED カソード**の
      黒線 (GND デイジーチェーン) を作り熱収縮チューブで絶縁
      (LED 側の配線余長は allday 60 / **slim 45mm**)。
   2. XIAO に D1/D3/GND の3本を直はんだ → **電池を繋ぐ前に** USB-C 給電で
      ファーム書込みと動作確認。
   3. **JST ピグテール (1.25mm 2P。線を根元から約 60 / 65mm の長さ違いに切り、そのまま使う。
      README 手順5) を XIAO 裏面 BAT+/− パッドへ
      はんだ付け** → **嵌合前テスタゲート (README §7 手順8-B) を全項目通す** →
      通ってから電池を嵌合する。はんだ部をカプトンテープで覆い、電池と基板裏面の
      間にも1枚貼る (ELECTRICAL.md §5.3)。
      **裏面で2本の電線を重ねない** (逃げ空間 1.40mm を超えると基板が浮き、
      USB-C が開口とずれて充電不能になる)。
3. スイッチを上壁凹みに (左右の挟みリブの間へ) はめて接着 (**未使用の右端子は事前に切り落とす**)。
   LED をリッド窓 (φ3.4) にエポキシ接着し、**リードは −y 側 (電池側) へ 90° に曲げる**
   (+x へ曲げると `xiao_stops[0]` に当たる)。
4. バッテリーを**左端ストップリブに突き当てて**磁石ボス+リブの上に置く
   (両面テープ+リッド側は薄スポンジ)。**右壁との 2.4 mm はリッド右 lip の通り道なので
   何も入れない**。リードは左端チャネル→上→XIAO 下の逃げ空間へ。
   **リード・テープ・スポンジは電池上面より上に出さない** (allday z≤11.0 / slim z≤8.0)。
5. XIAO スタックをコーナーシートの上へ**両面テープで固定** (必須)。右壁に当てて
   USB-C を右開口に合わせ、左端ストップリブとの間に収める。
   アンテナフィルムは左内壁の指定の帯に貼る (§2。**上壁内面は不可 = マイク穴を塞ぐ**)。
6. **JST 嵌合体を左内壁 (x=1.6) に密着させて y28.6–37.8 の位置に寝かせ**、
   ホットボンドを1点だけ付けて固定する (§7.1 の表)。**嵌合体の上には何も載せない**
   (すぐ右に LED が降りてくる)。XIAO の下とストップリブの切れ目 y35–40 には電線以外を絶対に入れない。
   **ケーブル側も別途固定して、嵌合部に引張が伝わらないようにする**
   (装着デバイスは常時振動しており、嵌合部の瞬断 = リセット/録音ファイル破損になる)。
7. LED 配線の余長を電池脇の空間に収納しながら (**電池室では電池上面より下**、
   左ポケットでは左 lip 帯 x1.75–2.75 を避ける)、リッドを
   「上辺左コーナーのスタブを掛ける → 左辺を差し込む → 下辺をパチン」で閉める。

- 手順 2-3 の電池直はんだは **JST ピグテール化**され、
  **嵌合前テスタゲート (SCHEMATIC.md §5.4 / README §7 手順8-B) が必須**になる。
- **ピグテールの線は根元から約 60mm / 65mm の長さ違いに切り、そのまま XIAO 裏の BAT パッドへ付ける**
  (v1.11。採用品の線は外径 0.90mm で XIAO の下を通せる。v1.8 rev2〜v1.10 の「AWG28 への継ぎ足し」は廃止。
  外径 1.3mm を超える線のピグテールを使う場合は継ぎ足しが要るが、継ぎ目の置き場所が無いので
  `HARNESS_SPLICE = True` にして CAD から見直すこと)。
  ピグテールは**電池のプラグ (1.25mm 2P) と同じ系統**であること。「1.25mm」表記でも嵌合しない
  別系統があるので、**並べて見比べ、指先の軽い力で嵌合すること**を受入条件にする (bom.md #A1)。
- **JST 嵌合体は Y方向に寝かせる。** v1.6 以降の内寸幅では X方向も `xiao_stops[0]` には当たらない
  (CAD ログ: クリアランス 3.60mm) が、X方向だと LED のリード帯と重なり、電線の通り道も塞ぐ。
  CAD の `harness_jst` は Y置きを assert で要求する (旧座標 y31–42 の回帰テストは v1.11 で撤去)。
  配置は `renders/<tag>/pcb_pocket.png` の左図と `internal.png` で確認できる。
- **JST 嵌合体は実測済み (M4: 長さ 9.2 × 幅 4.2 × 厚み 3.3mm) で CAD に反映済み。**
  継ぎ目を載せなくなったので `[harness] M4 limits` 行は出力されない (`HARNESS_SPLICE = True` のときだけ出る)。
  CAD ログの床置き高さ上限は allday 8.8 / slim 7.9mm、現在の最小クリアランスは
  スイッチ端子 2.20 / LED リード帯 0.80 / 電池 0.40mm。**別のピグテールを使う場合は 3 軸を測り直し、
  どれかが +0.3mm を超えたら `HARNESS_JST_XYZ` を書き換えて再実行する** (幅を変えると LED 窓が動き lid が変わる)。
  配線前に**嵌合体を仮置きしてリッドを1回閉める**確認は引き続き行う
  (電線の取り回しは CAD の assert では守れず、実機でしか判定できない)。
- **スイッチの右端 (XIAO 側) の端子は根元から切り落とす。** 使うのは中央 (青) と
  左端 (黒2本) だけで、右端を残すと熱収縮の包絡が x12.5 まで広がり、右の挟みリブ (x13.0) まで
  0.5mm しか残らず、電線の通り道 (x10.2–14.4) も狭くなる。
- 基板を入れる場合の手順差分は §11.2 / §11.3。

**取付手順** (工具不要):

1. 基板裏に薄手両面テープを貼る (J1 のピン座ぐりに掛からない位置)。
2. 基板の**上端を爪の下へ差し込む** (y+ 側へ 0.4 mm 押し込む)。
3. 下端を落として押し下げる。**ストップナブに当たって止まり、爪の掛かりしろは

4. 左内壁との隙間にホットボンドを点付けして最終固定 (テープが剥がれても爪が効く)。

| 基板 ↔ 電池 | 0.60 mm | ≥ 0.2 |
| 基板 ↔ 磁石ボス | 8.30 mm | ≥ 0.5 |
| 基板 ↔ 左 lip | 8.20 mm | ≥ 0.3 |
| J1 嵌合体 ↔ 左 lip | 0.70 mm (slim では 0.30) | ≥ 0.3 |
| J1 嵌合体 ↔ LED 本体 | 0.20 mm | ≥ 0.15 |

### 11.4 追加した assert (既存の検査は一切弱めていない・追加のみ)

`check_layout()` に以下を追加した。既存の検査 (リブ総当たり / キャビティ収容 /
磁石ウェブ / はんだ逃げ 1.2 mm / lip↔電池 / スナップ機構) はそのまま残してある。
唯一 `XIAO left stop gap` の assert だけ `if xiao_stops:` で分岐したが、
**`none` / `sense` では従来どおり実行**され、`carrier` では
「取付ボス2本 + 基板が存在すること」を代わりに要求する (弱化ではなく置換)。

1. 基板がキャビティ内に収まること / 外形が `pcb/LAYOUT.md` の値 (10.0×15.6, 34.2×21.0)
   と厚み 0.8 に一致すること。
2. 基板 ↔ 電池 / 磁石ボス左右 / lip 4辺 / リッド電池押さえリブ のクリアランス下限。
3. 背の高い実装部品 (J1 嵌合体 / 0805列 / ワイヤランド) ↔ 電池 / LED / スイッチ /
   lip / XIAO のクリアランス下限と、**天井 (リッド内面) を超えないこと**。
4. **J1 嵌合体 + 電線曲げ代 ≤ リッド内面** (超えるときは必要な ID 増分を表示)。
5. THT ピン逃げ座ぐりを引いた後の床残し肉厚 ≥ 0.8 mm (磁石ウェブと同値)、
   かつ座ぐりが床面より上に出ないこと。
6. `sense`: ポケット片側クリアランスが 0.3–0.5 mm / ガイド壁が基板厚 +0.4 以上 /
   爪の下面が基板上面より上かつ +0.4 以内 / **爪の掛かりしろ ≥ 0.2 mm** /
   **差し込み代 ≥ 0.3 mm**。
7. `carrier`: XIAO が基板上面に載ること / `XIAO_LIFT` = シェルフ+基板厚 /
   ボス穴クリアランス ≥ 0.2 mm / ボス頭が基板面 +0.4 以上 / 基板左端↔内壁 ≤ 0.5 mm /
