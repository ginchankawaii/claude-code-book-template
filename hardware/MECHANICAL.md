# MindClip DIY — 筐体メカ設計仕様 (v1.5)

CADモデル: [`cad/mindclip_case.py`](cad/mindclip_case.py) (CadQuery 2.8 パラメトリック)
実行すると `stl/<tag>/` に3パーツのSTL、`renders/<tag>/` にレンダ5枚を生成し、
内部レイアウトの干渉チェック (assert) と STL の watertight 検証を行う。

**バリアントは環境変数 `MINDCLIP_VARIANT`、基板構成は `MINDCLIP_PCB` で切り替える**
(既定 `allday` / `none`。出力タグ `<tag>` は `allday` `slim` `allday_sense` … と分かれる):

```
python3 hardware/cad/mindclip_case.py                        # allday / 基板なし (v1.5 採用構成)
MINDCLIP_VARIANT=slim python3 hardware/cad/mindclip_case.py  # slim   (LiPo 502530 / 500mAh)
MINDCLIP_PCB=sense   python3 hardware/cad/mindclip_case.py   # + MC-SENSE-A (サテライト基板)
MINDCLIP_PCB=carrier python3 hardware/cad/mindclip_case.py   # + MC-CARRIER-A (キャリア基板)
```

> **v1.5 の採用構成は「基板を作らない」= 案A-1**
> （回路の正本は [`pcb/SCHEMATIC.md`](pcb/SCHEMATIC.md)、判断の経緯は
> [`pcb/LAYOUT.md`](pcb/LAYOUT.md) §0）。基板側の対応 (`sense` / `carrier`) は
> 「発注前に筐体が本当に受けられるか」を先に固めるためのもので、**§11** にまとめた。
>
> **v1.5 rev2 で lid だけ形状が変わった（再印刷が必要）。**
> `body` と `backplate` は v1.4 と**バイト一致**（回帰確認済み）だが、`lid` は
> **LED 窓を x6.9 → 9.8 へ移し、径を φ3.2 → φ3.4 に広げた**ため v1.4 と別物になる。
> v1.4 の lid を印刷済みでも、**必ず新しい lid を刷り直すこと**（約4.7g / 20〜30分）。
> 理由は §7 と §11.4（旧 LED 位置は JST 嵌合体の真上で、90°に曲げた LED リードが
> slim で 1.0〜2.0mm 干渉していた）。

**既定は allday**。省電力実装なしの worst case (54.4mA) で slim は約7.8時間しか持たず
「起床〜就寝」を走り切れないため (ELECTRICAL.md §2.2)。電池はフットプリント
(30×25mm) が共通で厚みだけが違うため、**筐体奥行きの差は 1.7mm だけ**
(奥行きを支配しているのは XIAO スタック側のため)。
初心者向け組立ガイドは [`README.md`](README.md)。

v1.5 rev2 での設計変更 (採用構成 A-1 を実際に組める形にするための修正):

- **「箱にならない部品」を CAD に追加した**。旧版はスイッチを本体 8.7×3.7×3.5 の
  箱、LED を φ3 の円柱としてしか持っておらず、**-y に出る端子3本**も
  **90°に曲げた LED リード**も存在しなかった。このため左ポケットの部品を
  どこに置いても `check_layout()` が通ってしまっていた。
  - `sw_terms` = スイッチ端子 (3.5mm) + はんだ + φ3 熱収縮の包絡
    (x4.21–9.95 / y40.50–45.00 / z は本体中心 ±1.6)
  - `led_leads` = 曲げリード (本体下面から 3.0mm) + 220Ω + 継ぎ目 + 熱収縮の包絡
    (x8.20–11.80 / y28.60–37.60 / z は LED 下面 −3.0)
- **JST-PH2.0 嵌合体の置き場所を変更**: x3.0–8.8 / y31.0–42.0 →
  **x1.60–7.40 / y28.60–39.60 / z1.60–6.10**（左内壁に密着、Y方向に寝かせる）。
  旧位置はスイッチ端子との分離が slim で **0.00mm**（熱収縮込みで −1.35mm の実干渉）だった。
- **LED 窓を x6.9 → 9.8 へ移動**（+2.9mm）。旧位置は JST 嵌合体の真上で、
  曲げた LED リード (allday z5.8 / slim z4.1) が嵌合体上端 z6.10 と
  **slim で 1.0〜2.0mm、allday でも 3mm 曲げで 0.3mm 干渉**していた。
  左ポケットの y 方向には LED 帯の上下どちらにも 11.0mm の嵌合体が入らないため、
  **逃げられる方向は x しかない**（JST を左壁に密着 + LED を右へ = 隙間 0.8mm）。
- **LED 窓 φ3.2 → φ3.4** (`LED_WIN_FIT`)。FDM の穴は 0.1〜0.3mm 小さく出る (§5) ため、
  φ3.2 では実効 2.9〜3.1mm となり φ3.0 の LED が入らない個体が出る。
- **既定パラメータでの外形を直接 assert する** (`GOLDEN_OUTER`)。従来は
  `XIAO_STACK_T` / `BAT_T` / `J1_BODY_Z` などの assumption を書き換えると
  **assert を一つも出さずに外形だけが育った**（§11.4 の「負のテスト」が
  自己充足的だった原因）。公開値と食い違ったら必ず落ちる。
- **`harness_jst` の検査を実効化**: 旧版は6部品に対し `clearance >= 0.0`
  （＝接触を合格とする）だけで実質デッドコードだった。全部品との総当たり
  **0.3mm 以上**に変え、キャビティ収容と天井余裕 (嵌合体 + 電線曲げ代 2.4mm) も要求する。
- **XIAO 裏面はんだ逃げの assert を 1.2 → 1.4mm** （実装値 `XIAO_LIFT` と同値）。
  旧 1.2 は実装値より緩く、リフトを下げても発火しない空の検査だった。

v1.5 での主な設計変更 (基板化の受け入れ + CAD の潜在バグ修正):

- **基板オプション `MINDCLIP_PCB` を追加** (`none` / `sense` / `carrier`)。§11。
  `none` は v1.4 と同一形状 (STL バイト一致で回帰確認)。
- **`MC-SENSE-A` (10.0×15.6×0.8t) を左ポケット床に受ける保持機構を実装**:

  **allday は外形 38.0×49.4×14.6 mm のまま変わらない**。
- **`MC-CARRIER-A` (34.2×21.0×0.8t) 対応**: `GAP_BX` 1.2→1.8 / `M_TOP` 0.6→1.8 /
  `XIAO_LIFT` 1.4→1.6、XIAO 位置決めリブ一式 (座面4/左ストップ2/上下ナブ4/スイッチ挟み1)
  を **基板シェルフ7枚 + 取付ボス2本 (φ1.8)** に置換。外形 **38.0×51.2×14.9 mm**。
- **CAD の潜在バグを修正** (基板を採らなくても必要な修正):
  `xiao_seats` の y、`sw_rib` の y0、`LED_POS` が絶対値直書きで `xiao[1]`/`xiao[3]` に
  追従せず、`GAP_BX` / `M_TOP` を変えた瞬間に `INTERFERENCE: seat0 <-> xnub_b0` で

- **`harness_jst` の追加**: 基板なし構成 (v1.5 本番) で使う JST-PH2.0 嵌合体の置き場所
  (SCHEMATIC.md §5.5 が確定した x3.0–8.8 / y31.0–42.0 / z1.6–6.1、**Y方向に寝かせる**)
  を CAD に持ち込み、**X方向に寝かせると `xiao_stops[0]` に当たること**を
  回帰 assert で毎回再現確認するようにした。
- レンダに **`pcb_pocket.png`** (左ポケット平面 + 高さ予算断面) を追加。

v1.3 での主な設計変更 (電池バリアント化):

- **allday / slim の2バリアント化** (上記)。内寸奥行きは「XIAOスタック側」と
  「磁石ボス+電池+押さえリブ逃げ側」の厚い方から自動計算する。
- **内寸幅 32.6 → 34.8 mm**。allday では電池上面がリッド lip の降下域まで届くため、
  電池右端と右 lip 内面の間に隙間が必要になった。**外形幅は 35.8 → 38.0 mm**。
- **電池の x 位置決めを「右詰め」から「左端ストップリブへ突き当て」に変更** (§2/§7)。
- 内部リブ座標を `xiao[0]` / `CX` 基準の相対値に改め、寸法変更でリブ同士が
  衝突しないようにした。リッド側電池押さえリブは電池厚に自動追従。

v1.1 での主な設計変更 (レビュー反映):

- **XIAO裏面はんだの逃げ空間**: 内寸奥行きを 8.0 → 9.5 に拡大し、XIAO をコーナー
  シート4個で床から **1.4mm リフト**。裏面の BAT+/− はんだ盛り + AWG28 リード +
  カプトンテープ + スルーホール裏フィレット (約1.0〜1.5mm 突出、ELECTRICAL.md §5.3)
  が床と干渉しない。
- **XIAO の横方向拘束**: 左端ストップリブ + 上下当てナブを追加。USB-C 挿入力
  (規格5〜20N) をリブ→筐体壁で受け、基板が内側へ逃げない。
- **電池の位置決め**: 右詰め配置 (→ v1.3 で左突き当てに変更) + 左端リード曲げチャネル 2.4mm + x/y ストップリブ +
  リッド側押さえリブ。リッド lip は短縮 (2.5→2.2) して電池上面と非干渉に。
- **スナップリッジ突出 0.5 → 0.3** (PETG のたわみ歪みを低減)。
- USB-C 座ぐりを 13×8×深0.8 に拡大 (ケーブルのオーバーモールド対応)。

## 1. 寸法諸元

| 項目 | allday (既定) | slim |
|---|---|---|
| 本体外形 (body + lid) | **38.0 × 49.4 × 14.6 mm** | **38.0 × 49.4 × 12.9 mm** |
| 内寸 | 34.8 × 46.2 × 11.2 mm | 34.8 × 46.2 × 9.5 mm |
| 電池 | LiPo 802530 (30×25×8.0) | LiPo 502530 (30×25×5.0) |
| 外形 (+ `MINDCLIP_PCB=sense`) | **38.0 × 49.4 × 14.6 mm** (変化なし) | 38.0 × 49.4 × **14.2 mm** (+1.3 / 非推奨) |
| 外形 (+ `MINDCLIP_PCB=carrier`) | **38.0 × 51.2 × 14.9 mm** | 38.0 × 51.2 × 14.9 mm (slim の意味が消える) |

共通諸元:

| 項目 | 値 |
|---|---|
| 裏板 (backplate) | 32 × 26 × 3.0 mm (肌側は完全フラット) |
| 壁厚 | 側面/背面/上下面 1.6 mm、リッド板厚 1.8 mm (例外は §5 の表) |
| コーナーR | 外形 R4 / 内側 R2.5、背面周縁 R1.0 (服・肌への当たり) |
| 磁石ポケット | φ6.2 × 深さ2.2 (φ6×2 ネオジム用)、**残し肉厚 0.8 mm**、中心間 18 mm |

内寸幅は 32.6 → **34.8 mm** に拡大した (v1.3→v1.4)。allday では電池上面がリッド lip の
降下域まで届くため、電池右端と右 lip 内面の間に 0.4 mm 以上の隙間が必要になったため。
幅は両バリアント共通 (STL の body 断面は奥行きだけが違う)。

### 重量見積 (スクリプトの実測出力)

| 要素 | allday | slim |
|---|---|---|
| body (PETG 中実換算) | 7.9 g (6.21 cm³) | 7.3 g (5.76 cm³) |
| lid | 4.6 g (3.61 cm³) | 4.7 g (3.67 cm³) |
| backplate | 2.9 g (2.27 cm³) | 2.9 g (2.27 cm³) |
| **印刷部品 合計** | **15.3 g** | **14.9 g** |
| LiPo | ~10 g※ | ~10 g |
| XIAO ESP32S3 Sense スタック + microSD | ~5 g | ~5 g |
| 磁石 φ6×2 × 4 | ~1.8 g | ~1.8 g |
| スイッチ・LED・配線 | ~1 g | ~1 g |
| **総計 (裏板込み・スクリプト推定)** | **~33 g** | **~32 g** |

(v1.5 でスクリプト実測値に更新した。旧表の 15.1 / 14.7 g は v1.2 時点の値で、
内寸幅を 34.8 mm に広げた v1.4 以降の実測と 0.2 g ずれていた。基板を足した場合は
`allday_sense` 15.4 g / `allday_carrier` 15.7 g。)

※ スクリプトの `comp_mass` は電池を **10 g 固定**で見積もっている。802530 (800mAh) の
実物は **13〜15 g 程度**と見込まれ、その場合 allday の総重量は **36 g 前後**になる
(**未実測**)。装着側 (body 側) の重量は磁石保持力の余裕に直結するため §6 も参照。

本家 (16.8 g) より重いが、バッテリーを磁石クランプ直上に配置して
重心をクランプ点に寄せてあるため、襟元での「お辞儀」は起きにくい。
軽量化したい場合は infill を下げても剛性上問題ない (壁は元々 1.6 mm ソリッド)。

## 2. 内部レイアウト (`renders/<variant>/internal.png` 参照)

```
 上面: [スイッチレバー]  [マイク開口 φ1.5×3]
 ┌───────────────────────────────┐
 │ SS-12D00 ‖  XIAO ESP32S3       │→ 右側面: USB-C 開口
 │ (挟みリブ+‖← 左端ストップリブ    │   (基板端を右内壁に当てて
 │  接着)    ‖  Sense スタック      │    コネクタを面一に)
 │ ○LED(正面窓 x9.8) 21×17.8×7.5   │
 ├─┬─────────────────────────┬─┤
 │リ│ LiPo 30×25 (左突き当て)   │右│
 │｜│  (磁石ボス2個+リブの上に載る)│lip│← 背面壁内: 磁石 φ6×2 ×2
 │ド│                          │1.6│
 └─┴─────────────────────────┴─┘
  ↑左端2.4mm: 電池リード曲げチャネル   下面: こじ開けノッチ
  左ポケット床 x1.6-7.4 / y28.6-39.6: JST-PH2.0 嵌合体 (Y方向・左内壁密着)
  その右 x8.2-11.8: LED の曲げリード + 220Ω の帯 (隙間 0.8mm)
```

- **XIAO スタック**: メイン基板を背面側 (下)、Sense拡張ボード (マイク/SD) をリッド側に
  向けて右詰めで置く。装着方向注意: **拡張ボードは部品面 (USB-C側) に B2B 装着**され、
  BAT+/− パッドのある面が裏面 (背面側) になる。
  - **⚠ この装着面は assumption であり、USB-C 開口の成否を直接決める。**
    公式wiki と実装記録はいずれも「BAT+/− と B2B コネクタは**メイン基板の裏面**」と
    しており、もし実際の積層が「拡張ボード(下) + XIAO(上)」なら USB-C コネクタ中心は
    スタック下面から約 5.1mm となり、本設計の想定 (3.2mm) より **約1.9mm 高い**。
    USB 開口 (10.5×4.8, z3.80–8.60) の許容ずれは **±0.80mm しかない**ので、
    **開口を外して充電できなくなる**。マイクと microSD の向きも §2/§3 の前提から外れる。
    **印刷前に「スタック下面から USB-C コネクタ中心までの高さ」をノギスで実測し、
    `USB_Z0 = 2.4 + XIAO_LIFT` を実測値基準に書き換えること** (§8・README §9.1)。
  - **z方向**: 基板4隅の**コーナーシート (h1.4)** の上に載る。基板下面〜床の 1.4 mm が
    裏面はんだ盛り・AWG28 リード・カプトンテープの逃げ空間 (ELECTRICAL.md §5.3 の
    機構要求)。シートはピン列のカステレーション部を避けて4隅のみに当たる
    (BAT パッド位置は assumption のため、現物でシートと干渉したらシートを削る)。
  - **x/y方向**: 右壁 + **左端ストップリブ2本** (アンテナ/U.FL ケーブル通しに中央開放) +
    上下の当てナブで拘束。USB-C を挿す力はリブが受ける。
  - **固定**: **基板下面の薄手両面テープ固定は必須手順** (任意ではない。bom.md #9a)。
    **アンテナフィルムの貼付位置 (v1.5 rev2 で確定)**:
    - `none` (採用構成): **左内壁 (x=1.6 の面) の上側 y39.8–47.0**、または
      **上壁内面 (y=47.8 の面) の x12.7–34.0 帯**。左内壁の下側 (y28.6–39.6) は
      JST 嵌合体をホットボンドで点付けする面なので使わない。
      フィルム実寸は未実測 (assumption) なので、**貼る前に現物を仮置きして
      リッドが閉まることを確認**する (§7 の仮組み手順に含める)。
    - `sense`/`carrier`: 床が基板に占有されるので**左内壁の内側**へ (§11.2)。
  - SDカードはリッドを開ければ抜き差しできる想定だが、右壁密着側のため
    **実機確認までは assumption** (スタックを持ち上げる必要があるかもしれない。
    運用は WiFi 同期なので挿抜は稀)。
- **バッテリー**: 下段。磁石ボス (h1.4) と支持リブ2本の上に載せる。
  **x 方向は「左端ストップリブに突き当てる」= 左突き当てで位置決めする**
  (内寸幅を 34.8 に広げた v1.3→v1.4 で変更。電池右端と右内壁の間には **2.4 mm の隙間が残る**
  が、これは**リッド右 lip の通り道なので埋めない**こと。旧版の「右詰め」は誤りのため撤回)。
  - **リード線は左端面から出る** (802530 / 502530 のタブは長さ30mm方向の端面=25mm幅の
    面から出射)。左側の **2.4 mm リード曲げチャネル** を上へ回し、電池上の 1.2 mm ギャップ
    から XIAO 下の逃げ空間 (1.4 mm) を通って裏面 BAT パッドへ。
    リード・LED余長は **電池上面より下** (allday z≤11.0 / slim z≤8.0、lip 挿入帯を避ける)
    に収めること。
  - **位置決め**: 左端ストップリブ2本 (中央 y9〜22 はリード用に開放) + 下端ストップ
    リブ2本 + 上端ナブ (XIAO 下端ナブと兼用) で x/y を拘束。
    **x+ (右) 方向には物理ストップが無い**ので、両面テープでの固定が位置決めを兼ねる
    (右へ 0.5 mm 以上ずれると allday ではリッドが閉まらなくなる)。
    z はリッド内面の **押さえリブ2本** (電池上面と 1.0 mm ギャップ、電池厚に自動追従) +
    **1mm 薄スポンジ** (必須、bom.md #9a) でラトルとリード疲労を防ぐ。
  - **リッド lip 帯とのz関係はバリアントで異なる**:
    - slim: lip 帯 z8.9〜11.1 に対し電池上面 z8.0 (厚め 5.3mm 個体でも z8.3) → z方向で
      逃げている。**5.5 mm を超える個体は使わない**こと。
    - allday: lip 帯 z10.6〜12.8 に対し電池上面 **z11.0** → **z方向では重なる**。
      よって非干渉は**水平方向の隙間で担保する**。内寸幅を 34.8 mm としたことで
      左右とも **1.25 mm** の隙間があり、LiPo の寸法公差 (±0.5 mm) と PCM 端の
      膨らみを吸収できる。**厚み 8.5 mm を超える個体は使わない**こと。
      - **v1.4 の修正**: 旧版 (内寸幅 34.0) では右隙間が **0.45 mm** しかなく、
        公差次第で干渉し得た。さらに z 方向の assert が電池厚 5.3 mm 固定値で
        書かれており、**allday では常に成立する空の検査になっていた**。
        現在は実際の電池厚から z クリアランスを計算し、z で逃げられない場合は
        左右の水平隙間が公差代 `BAT_TOL` (1.0 mm) 以上あることを assert で要求する。
        旧値 34.0 に戻すと assert が発火することを回帰確認済み。
- **スイッチ**: 上壁内面の浅い凹み (深さ0.7) にはめ、左端の挟みリブと右の XIAO
  ストップリブで横ずれを抑えて接着 (ホットボンド可)。レバーは上面のスロット 5.0×2.2
  から突出し、手探りで操作できる。
- **LED**: リッドの **φ3.4** 窓 (中心 x9.8 / y36.0) に内側から挿し、ドームを外に覗かせて**エポキシで接着**
  (瞬着は白化ガスでレンズが曇るため LED 近傍では不可、ELECTRICAL.md §5.4)。
  足は 90° に曲げてリード線を XIAO へ。**配線余長 allday 60 mm / slim 45 mm** (リッド開閉分。slim で 60mm にすると充填率が上限に張り付きフタが閉まらない。§7.1 / SCHEMATIC §5.6)。
- 内部干渉チェックはスクリプト内の `check_layout()` が AABB ベースで assert する
  (バッテリー/XIAO/スイッチ/LED/lip/磁石ボス/全リブ類のペア + キャビティ収容 +
  磁石ウェブ + はんだ逃げ 1.2mm 以上 + lip-電池クリアランス)。

## 4. リッドの嵌め合い (スナップフィット、工具不要)

- リッドは lip (スカート、深さ2.2・厚さ1.0) を内寸に差し込む方式。
  片側クリアランス **0.15 mm** (FDM公差 0.2–0.3 を実測で吸収する前提の初期値)。
- **スナップ**: lip 外面の丸リッジ (**突出0.3**、左辺2 + 下辺2) が、本体内壁の
  水平溝 (深さ~0.3) にパチンと入る。半円断面が進入テーパを兼ねる。
  受け溝は内壁の水平半円溝 = 内部オーバーハングのため印刷面が荒れやすく、
  **初回は嵌合調整前提** (溝を軽く針ヤスリでさらう)。
- **保持構成**: 左辺 (全高) + 下辺 + 右辺下部 + **上辺左コーナーのスタブ lip** の
  4箇所で位置決め・保持。上辺右側 (XIAO 上端) と右辺上部 (XIAO/USB) は切り欠き。
- **開け方**: 底面中央の**こじ開けノッチ**に爪を掛けて手前に起こす。
- lip のたわみ代: 左 lip 内面と電池の間に 1.25 mm (必要たわみ 0.35 mm に対し余裕)。
- きつい/緩い場合: `mindclip_case.py` の `CLR` を ±0.05 単位、リッジ突出
  `SNAP_PROTRUDE` を 0.1 単位で調整して再出力。
  応急処置なら lip 外面を軽くヤスリ掛け (きつい場合)。

## 5. 3Dプリント条件 (FDM / PETG / ノズル0.4 / 積層0.2)

| パーツ | 印刷向き | サポート | 備考 |
|---|---|---|---|
| body | **背面をベッドに** (開口面を上) | 不要 | USB開口の上辺 ~10 mm はブリッジ (PETGで問題ない長さ)。磁石ポケットの残し肉0.8 = 4層。内部リブは全て床から立ち上がる形状で自己支持 |
| lid | **外面 (化粧面) をベッドに** | 不要 | lip・スナップリッジ・電池押さえリブが上向きになる。リッジは半円断面で自己支持 |
| backplate | **肌側フラット面をベッドに** | 不要 | ベッド面がそのまま肌当たり面になり最も滑らか |

- 推奨: **壁 4周 (1.6 mm) / infill 30% / 積層 0.2 mm** (最低でも壁3周=1.2mm)。
  シーム位置は背面側に。STL は `stl/allday/` または `stl/slim/` から取る。
- **壁厚 1.6 mm 設計則の例外** (強度上は許容、意図的な局所薄肉):

  | 箇所 | 残し厚 |
  |---|---|
  | スイッチ凹み上の上壁 | 0.9 mm |
  | USB-C 座ぐり底の右壁 | 0.8 mm |
  | スナップ受け溝の背後 | ~1.3 mm |
  | 磁石ポケットのウェブ | 0.8 mm (磁力を通すため意図的) |

- 公差の考え方: 「穴・ポケットは公称+0.2、嵌め合いは片側0.15」を初期値にしている。
  FDMの穴は 0.1〜0.3 mm 小さく出るため、磁石ポケット φ6.2 が**圧入不能の場合は
  `MAG_FIT` を +0.1 して再出力** (まず端材でテスト印刷推奨)。
  **LED 窓も同じ理由で v1.5 rev2 に φ3.2 → φ3.4 (`LED_WIN_FIT` = 0.4) に広げた。**
  それでもきつい場合は 3.0mm ドリルまたはリーマで軽くさらう
  (窓は化粧面なので、削るのは内側から)。

## 6. 磁石の組み付け (φ6×2 ネオジム ×4)

1. **極性確認が最重要**。先に4個を「本体用2個」「裏板用2個」に分け、
   布 (またはリッド) を挟んで **引き合う向き** をマスキングテープ等でマーキングする。
   左右2箇所とも同じ向きに揃えること (片方逆だと反発して固定できない)。
2. ポケットは φ6.2 × 深さ2.2 (磁石2.0 + 接着剤しろ0.2)。指で押し込める程度の
   軽圧入になる想定。緩い場合も接着で保持するので問題ない。
3. 接着は **エポキシ (2液) を推奨** (LED窓と同じ理由で瞬着の白化ガスを筐体内に
   出さない)。ポケット底に少量塗り、磁石がポケット面より沈む (面一以下になる)
   ことを確認して硬化待ち。
   - 本体側: ポケットはバッテリー室の床 (ボス上面) に開口。**バッテリーを入れる前に**接着。
   - 裏板側: ポケットは布側の面に開口 (= 吸引方向に開口するため、**ポケット底面への
     接着を厳守**。接着が甘いと取り外し時のピール荷重で磁石が抜ける)。
     肌側は無加工の完全フラット。
4. 磁石と布の間は本体側 0.8 mm ウェブ + 裏板側 0.8 mm ウェブのみ。
   保持力概算 (N35): ギャップ計 ~2.1 mm で法線力 ≈ 2〜2.5 N/ペア × 2 → 布摩擦込みの
   滑り保持 ≈ 120〜150 gf、装着側 (body + 中身) **29〜33 g** (電池実重量による。§1 の注記)
   に対し **余裕約4倍**。シャツ〜薄手ジャケットは保持可。
   厚手 (2mm級) の生地でずり落ちる場合は **φ6×3 に変更** (`MAG_T` を変えてポケット
   深さを再生成) するフォールバックを維持。

## 7. 組立手順 (v1.5 = 案A-1。はんだ付けは **10点**)

> **正本の順序**: 回路と配線は [`pcb/SCHEMATIC.md`](pcb/SCHEMATIC.md)（§1.4 のはんだ点表が正）、
> 作業手順は [`README.md`](README.md) §7、機構の座標と干渉はこの §7。
> ELECTRICAL.md §1/§3/§4/§5 も v1.5（JST-PH2.0 化 + GND デイジーチェーン化 + 10点）に
> 更新済み。旧版の「電池コネクタは付けない」という決定は撤回された。

**はんだ付けは合計10点** (電池側ピグテール2 + XIAO信号3 + スイッチ2 + 抵抗1 + LED1 +
抵抗↔LED のリード継ぎ1)。v1 にあった**空中3端子スプライス (黒線3本のより合わせ) は廃止**し、
GND は「XIAO GND → スイッチ片端端子 → LED カソード」のデイジーチェーンにした。
**ピンヘッダ/ピンソケットは使わない** (高さが増えて筐体に入らない。XIAO のスルーホール
へ直はんだする方針が確定。詳細と難易度は ELECTRICAL.md §3)。

1. 磁石を body / backplate にエポキシ接着 (§6)。硬化を待つ。
2. **電気サブアセンブリを筐体外で完成させる** (SCHEMATIC.md §1.4 / README §7 の順序に従う):
   1. スイッチ+青線、LED+220Ω+橙線、および**スイッチ片端端子 → LED カソード**の
      黒線 (GND デイジーチェーン) を作り熱収縮チューブで絶縁
      (LED 側の配線余長は allday 60 / **slim 45mm**)。
   2. XIAO に D1/D3/GND の3本を直はんだ → **電池を繋ぐ前に** USB-C 給電で
      ファーム書込みと動作確認。
   3. **JST-PH2.0 ピグテール (電線 40mm に切る) を XIAO 裏面 BAT+/− パッドへ
      はんだ付け** → **嵌合前テスタゲート (README §7 手順8-B) を全項目通す** →
      通ってから電池を嵌合する。はんだ部をカプトンテープで覆い、電池と基板裏面の
      間にも1枚貼る (ELECTRICAL.md §5.3)。
      **裏面で2本の電線を重ねない** (逃げ空間 1.40mm を超えると基板が浮き、
      USB-C が開口とずれて充電不能になる)。
3. スイッチを上壁凹みに (挟みリブの間へ) はめて接着 (**未使用の右端子は事前に切り落とす**)。
   LED をリッド窓 (φ3.4) にエポキシ接着し、**リードは −y 側 (電池側) へ 90° に曲げる**
   (+x へ曲げると `xiao_stops[0]` に当たる)。
4. バッテリーを**左端ストップリブに突き当てて**磁石ボス+リブの上に置く
   (両面テープ+リッド側は薄スポンジ)。**右壁との 2.4 mm はリッド右 lip の通り道なので
   何も入れない**。リードは左端チャネル→上→XIAO 下の逃げ空間へ。
   **リード・テープ・スポンジは電池上面より上に出さない** (allday z≤11.0 / slim z≤8.0)。
5. XIAO スタックをコーナーシートの上へ**両面テープで固定** (必須)。右壁に当てて
   USB-C を右開口に合わせ、左端ストップリブとの間に収める。
   アンテナフィルムは左の空間に貼る。
6. **JST 嵌合体を左内壁 (x=1.6) に密着させて y28.6–39.6 の位置に寝かせ**、
   ホットボンドを1点だけ付けて固定する (§7.1 の表)。
   **ケーブル側も別途固定して、嵌合部に引張が伝わらないようにする**
   (装着デバイスは常時振動しており、嵌合部の瞬断 = リセット/録音ファイル破損になる)。
7. LED 配線の余長を電池脇の空間に収納しながら (**電池室では電池上面より下**、
   左ポケットでは左 lip 帯 x1.75–2.75 を避ける)、リッドを
   「上辺左コーナーのスタブを掛ける → 左辺を差し込む → 下辺をパチン」で閉める。

### 7.1 v1.5 (基板なし = 採用構成) の左ポケット占有 — 座標で固定する

左ポケット (x1.60–12.40 / y28.20–44.60 / z1.60–天井) の中身は**置き場所を座標で決めてある**。
「なんとなく左に押し込む」と最終工程でフタが閉まらない。数値は `cad/mindclip_case.py` の
実行値、体積は 0.1 mm ボクセルの実測。

| 中身 | 座標 (mm) | 備考 |
|---|---|---|
| **JST-PH2.0 嵌合体** | **x1.60–7.40 / y28.60–39.60 / z1.60–6.10** | **Y方向に寝かせる**。左内壁 (x=1.6) に密着させてホットボンド点付け。断面 5.8×4.5 のうち **4.5 を高さ (z)、5.8 を幅 (x) にして寝かせる**（ロールを間違えると z が 5.8 になる） |
| **LED 本体** (リッド側) | x8.20–11.40 / y34.40–37.60 / z8.80–12.80 (slim 7.10–11.10) | 窓中心 (9.8, 36.0) |
| **LED の曲げリード + 220Ω + 熱収縮** | x8.20–11.80 / y28.60–37.60 / **リードは −y (電池側) へ曲げる** | LED 本体下面から 3.0mm 下がる帯。JST とは x で 0.80mm 離す |
| **スイッチ端子 + はんだ + 熱収縮** | x4.21–9.95 / y40.50–45.00 / z は本体中心 ±1.6 | JST 上端との分離 **0.90mm** |
| 電池リード (ピグテール) | 左端チャネル x1.6–4.0 を上へ → 電池上のギャップ → XIAO 裏 | 各 **40mm** |

- **自由体積 (上記をすべて差し引いた実測)**: **allday 1.45 cm³ / slim 1.15 cm³**。
  ここに入る配線は AWG28 (φ1.2) が allday 300mm / slim 270mm = 素の体積 0.34 / 0.31 cm³ で、
  **充填率 50% 換算で allday 47% / slim 53%**。実用上限 (50〜60%) の内側に収まる。
- **「リード・余長は電池上面より下」(下の手順4) は電池室 (x≥4.0) のルール**である。
  左ポケットにリッド側から降りてくるのは**左 lip (x1.75–2.75, z≥10.6 / slim z≥8.9) だけ**
  なので、**左ポケットの配線は lip 帯の x1.75–2.75 を避ければ天井まで使ってよい**
  (この区別を書かずに全域へ適用すると、slim の枠が 0.67 cm³ になり 92% で破綻する)。
- **slim では LED 側の配線余長を 60 → 45 mm に詰める** (リッドの開き角は狭くなる)。
  60mm のままだと充填率が 59% に上がり実用上限に張り付く。allday は 60mm でよい。

**v1.5 での手順差分 (基板なし = 採用構成)**:

- 手順 2-3 の電池直はんだは **JST-PH2.0 ピグテール化**され、
  **嵌合前テスタゲート (SCHEMATIC.md §5.4 / README §7 手順8-B) が必須**になる。
- **ピグテールの電線は 40mm に切ってから** XIAO にはんだ付けする
  (市販品の 100〜150mm のままだと slim で入らない)。
  **被覆込み外径 1.3mm 以下**の品を買うこと (bom.md #A1)。
- **X方向に寝かせると `xiao_stops[0]` に 1.5 mm 食い込む。**
  CAD の `harness_jst` が毎回この配置を検算しており、X方向に寝かせた場合・
  旧座標 (y31–42) に戻した場合の**どちらでも assert が発火する**ことを回帰テスト済み。
  配置は `renders/<tag>/pcb_pocket.png` の左図と `internal.png` で確認できる。
- **JST 嵌合体の高さ上限は allday 8.7mm / slim 7.0mm、長さ上限は 11.6mm**
  (それぞれ左 lip とスイッチ端子で決まる)。**現物を3軸ノギスで実測してから印刷する。**
  部品到着後・配線前に**嵌合体を仮置きしてリッドを1回閉める**確認を必ず行う
  (CAD の assert では守れず、実機でしか判定できない)。
- **スイッチの右端 (XIAO 側) の端子は根元から切り落とす。** 使うのは中央 (青) と
  左端 (黒2本) だけで、右端を残すと熱収縮の包絡が `xiao_stops[1]` まで 0.01mm になる。
- 基板を入れる場合の手順差分は §11.2 / §11.3。

| 0805 の実装高さ 0.95 mm / ワイヤランド上の盛り 1.5 mm | **assumption** (`PCB_SMD_Z` / `PCB_WIRE_Z`) |
| 基板外形公差 ±0.2 mm / FDM ポケットは 0.1〜0.3 mm 小さく出る | ポケット片側クリアランス 0.40 mm の根拠 (`PCB_CLR`) |

**実測の順序 (印刷の前にやること・この順で)**:

1. **XIAO スタック総厚**をノギスで測り `XIAO_STACK_T` を更新する。
   slim ではキャビティ奥行き 9.5 = リフト 1.4 + 7.5 + 0.6 が**これだけで決まる**
   (allday は電池側 11.2 が支配するため 1.7 mm の無料枠がある)。
   7.5 を超えていた場合、slim の外形は 12.9 mm では収まらない。
2. **スタック下面から USB-C コネクタ中心までの高さ**を測り、`USB_Z0 = 2.4 + XIAO_LIFT`
   と整合するか確認する (許容ずれ ±0.80 mm。§2 の警告)。
3. **JST-PH2.0 嵌合体の3軸**を測る (上限: 高さ allday 8.7 / slim 7.0 mm、長さ 11.6 mm)。
4. 1〜3 で値が変わったら `mindclip_case.py` を更新して再実行する。
   **`GOLDEN_OUTER` の assert が落ちるので、公開寸法 (§1 / §11.1 / README §6) を
   更新するまで STL は出せない**。これは仕様であって不具合ではない。

**組んでから確認する項目**: ⑤ USB-C ケーブルの嵌合 (座ぐり 13×8×0.8 で足りるか)、
⑥ マイク開口の集音性 (不足なら φ2×3 に拡大)、⑦ スナップの保持力
(`CLR` / `SNAP_PROTRUDE` 調整)、⑧ **JST 嵌合体を仮置きしてリッドが閉まること**
(CAD の assert では守れない・実機のみ)。

## 10. v2 への申し送り

## 11. v1.5 — 基板 (`MINDCLIP_PCB`) を入れる場合の筐体対応

**この節は「基板を作る」という決定ではない。** v1.5 の採用構成は
[`pcb/LAYOUT.md`](pcb/LAYOUT.md) §0 のとおり **案A-1 = 基板なし**であり、
既定の `MINDCLIP_PCB=none` は v1.4 と同一形状 (STL バイト一致)。
ここに書くのは **「基板を焼く前に、筐体が本当にそれを受けられるのか」を
CAD 側で先に確定させた結果**である。基板は
[`pcb/SCHEMATIC.md`](pcb/SCHEMATIC.md) §9.4 の離脱ゲートと
**XIAO スタック総厚の実測**を通してからでなければ発注してはならない。

### 11.2 `sense` — MC-SENSE-A の受け方 (位置決め=ポケット / 保持=爪 + 両面テープ)

**取付穴は無い** (`pcb/LAYOUT.md` §6: 10.0×15.6 mm に φ2.2 のキープアウトを取れる
場所が残らない)。したがって **ボス+ネジは使わず**、次の3つで持たせる。

| 役割 | 実装 | 座標 (筐体座標 mm) |
|---|---|---|
| ポケット (既存の空き) | 内壁 / `xiao_stops[0]` 側面 / 電池上端 / `sw_rib` が作る | x 1.60–12.40 × y 28.20–44.60 |
| 基板 | MC-SENSE-A 10.0 × 15.6 × 0.8t を**床置き** | x 2.00–12.00 / y 28.60–44.20 / z **1.60–2.40** |
| 位置決め (x) | 左=内壁 (x1.60) / 右=`xiao_stops[0]` の側面 (x12.40) | 片側 0.40 mm |
| 位置決め (y+) | **上ガイド壁 2片** (`sw_rib` を挟んで左右に分割) | x1.60–2.90 / x3.70–12.40, y 44.60–45.60, z 1.60–3.00 |
| 抜け止め (z) | **爪 2個** (ガイド壁から 0.6 mm 張り出す庇) | x4.50–7.50 / x9.00–12.00, y 44.00–44.60, z **2.65–3.00** |
| 位置決め (y−) | **ストップナブ 2個** (電池の下 z<3.0 に隠す) | x2.00–5.00 / x9.00–12.00, y 27.60–28.60, z 1.60–3.00 |
| J1 の THT ピン逃げ | 床の**座ぐり** (残し肉厚 0.8 mm = 磁石ウェブと同じ) | x4.80–9.20 / y30.20–33.00 / z **0.80–1.60** |

**取付手順** (工具不要):

1. 基板裏に薄手両面テープを貼る (J1 のピン座ぐりに掛からない位置)。
2. 基板の**上端を爪の下へ差し込む** (y+ 側へ 0.4 mm 押し込む)。
3. 下端を落として押し下げる。**ストップナブに当たって止まり、爪の掛かりしろは
   0.2〜0.6 mm** (CAD で `_engage_min ≥ 0.2` / 差し込み代 `≥ 0.3` を assert)。
4. 左内壁との隙間にホットボンドを点付けして最終固定 (テープが剥がれても爪が効く)。

**クリアランス実測値** (`clearance()` = AABB の軸方向分離距離の最大値 = 真の最小距離の下界):

| 対象 | 値 | 要求 |
|---|---|---|
| 基板 ↔ 電池 | 0.60 mm | ≥ 0.2 |
| 基板 ↔ 磁石ボス | 8.30 mm | ≥ 0.5 |
| 基板 ↔ 左 lip | 8.20 mm | ≥ 0.3 |
| J1 嵌合体 ↔ 左 lip | 0.70 mm (slim では 0.30) | ≥ 0.3 |
| J1 嵌合体 ↔ LED 本体 | 0.20 mm | ≥ 0.15 |

- **スイッチと LED は基板に載らない** (MC-SENSE-A にはランドが無い)。よって
  **上面スイッチスロット・上壁凹み・リッドの LED 窓・挟みリブは v1 から一切変えていない**。
  変わるのは「配線の行き先が XIAO 直はんだ → 基板の J2 ランド (6本)」だけ。
- **J2 の6本は +x 側 (XIAO 側) へ引き出す**。爪の下 (y+ 側) を通すと挟み込む。
- **アンテナフィルムの貼付位置を変更する** (§2 は「XIAO 左の空間」としていた)。
  基板が床面の約半分を占めるため、**左内壁 (x=1.6 の面, y28–45) の内側**へ移すこと。

### 11.3 `carrier` — MC-CARRIER-A の受け方 (シェルフ + 取付ボス2本)

外形が **38.0 × 51.2 × 14.9 mm** になり、**body / lid の再印刷が必須**
(backplate は流用可)。CAD 側の差分:

| 項目 | v1.4 | `carrier` | 理由 |

| `GAP_BX` / `M_TOP` | 1.2 / 0.6 | **1.8 / 1.8** | カステレーション受けランドを XIAO 長辺の外に出す |

| `ID` → 外形 D | 11.2 → 14.6 | **11.5 → 14.9** | 基板上面 3.20 + 嵌合体 7.5 + 曲げ代 2.4 = 13.10 |
| `XIAO_LIFT` | 1.4 | **1.6** (シェルフ0.8 + 基板0.8) | USB-C 開口 z は `2.4 + XIAO_LIFT` で自動追従 (z4.0–8.8) |

**この構成の弱点を明記する**:

- **J1 の天井余裕が 0.00 mm** (曲げ代 2.4 mm をちょうど使い切る)。
  嵌合高さの assumption が 0.5 mm 悪化しただけで成立しない。
- **電池の y+ ストップが消える**。v1 では `xiao_nubs_bot` が電池上端を押さえていたが、

### 11.4 追加した assert (既存の検査は一切弱めていない・追加のみ)

`check_layout()` に以下を追加した。既存の検査 (リブ総当たり / キャビティ収容 /
磁石ウェブ / はんだ逃げ 1.2 mm / lip↔電池 / スナップ機構) はそのまま残してある。
唯一 `XIAO left stop gap` の assert だけ `if xiao_stops:` で分岐したが、
**`none` / `sense` では従来どおり実行**され、`carrier` では
「取付ボス2本 + 基板が存在すること」を代わりに要求する (弱化ではなく置換)。

1. 基板がキャビティ内に収まること / 外形が `pcb/LAYOUT.md` の値 (10.0×15.6, 34.2×21.0)
   と厚み 0.8 に一致すること。
2. 基板 ↔ 電池 / 磁石ボス左右 / lip 4辺 / リッド電池押さえリブ のクリアランス下限。
3. 背の高い実装部品 (J1 嵌合体 / 0805列 / ワイヤランド) ↔ 電池 / LED / スイッチ /
   lip / XIAO のクリアランス下限と、**天井 (リッド内面) を超えないこと**。
4. **J1 嵌合体 + 電線曲げ代 ≤ リッド内面** (超えるときは必要な ID 増分を表示)。
5. THT ピン逃げ座ぐりを引いた後の床残し肉厚 ≥ 0.8 mm (磁石ウェブと同値)、
   かつ座ぐりが床面より上に出ないこと。
6. `sense`: ポケット片側クリアランスが 0.3–0.5 mm / ガイド壁が基板厚 +0.4 以上 /
   爪の下面が基板上面より上かつ +0.4 以内 / **爪の掛かりしろ ≥ 0.2 mm** /
   **差し込み代 ≥ 0.3 mm**。
7. `carrier`: XIAO が基板上面に載ること / `XIAO_LIFT` = シェルフ+基板厚 /
   ボス穴クリアランス ≥ 0.2 mm / ボス頭が基板面 +0.4 以上 / 基板左端↔内壁 ≤ 0.5 mm /
   全シェルフが基板の外へはみ出さないこと。
8. `none`: **`harness_jst` が Y方向であること**、`xiao_stops[0]` に当たらないこと、
   および **X方向に寝かせた箱は必ず `xiao_stops[0]` と干渉すること** (逆向き回帰テスト)。

**負のテスト** (assert が実際に発火することを毎回実行して確認した結果。
v1.5 rev2 で「発火しない負のテスト」を実測し直して差し替えた):

| 壊し方 | 実際の結果 |
|---|---|
| JST を X方向に寝かせる | 発火 `INTERFERENCE: led_leads <-> harness_jst` (旧版の `xstop0` より先にリード帯に当たる) |
| JST を旧座標 y31.0–42.0 に戻す | 発火 `INTERFERENCE: sw_terms <-> harness_jst` (**v1.5 rev2 で新設。旧 CAD は端子を持たず素通りしていた**) |
| LED を旧位置 x6.9 に戻す | 発火 `INTERFERENCE: led_leads <-> harness_jst` (同上) |
| JST 嵌合体の高さを 9.0 mm にする | 発火 `harness_jst clearance to lip_left = -0.00mm < 0.3mm` (allday)。slim は 7.5 mm で発火 |
| 基板を 0.5 mm 電池側へずらす | 発火 `PCB pocket clearance -0.10mm out of 0.3-0.5` (旧記述の `INTERFERENCE: pcb <-> pcb_stop0` は誤り) |
| `XIAO_LIFT` を 1.4 → 1.2 に下げる | 発火 `INTERFERENCE: xiao <-> seat0` |
| `XIAO_STACK_T` / `BAT_T` / `J1_BODY_Z` を変える | **`GOLDEN_OUTER` が発火**。旧版はこれらを変えても assert が一つも出ずに外形だけが育った (公開値 38.0×49.4×14.6/12.9 を固定する検査が無かった) |
| ~~J1 を 0.6 mm 高くする~~ | **発火しない (旧記述は誤り)**。`ID` が `J1_BODY_Z` から計算されるため外形が育つだけで、`lip_left` との関係は原理的に変わらない。この自己充足性は `GOLDEN_OUTER` で塞いだ |

### 11.5 未検証 (この節の結論を壊し得る assumption)

| 項目 | 影響 |
