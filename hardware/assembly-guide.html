MindClip 組み込み図解

配線の済んだ部品を、一体型の本体に収めてフタを閉めるまで。手順ごとの図は、プラモデルの説明書と同じく、その手順で入れる部品に色を付け、入れ済みの部品を灰色で描いています。

できあがりの配置

入れてはいけない場所理由
電池の右（USB 側の壁との間）フタの縁が入ってくる。何か入るとフタが閉まらない
XIAO の下に、線以外のものすき間は 1.4mm。テープの束や余った線が入ると基板が浮き、USB が挿さらなくなる
JST コネクタの上すぐ上にフタの LED が下りてくる
電池の上面より高い所（電池の上）フタの押さえが当たる
マイク穴のある壁の内側穴をふさぐと録音できない
0

準備

電池は外したまま進めます
  1. 電池を JST から抜く。つなぐのは手順4です。
  2. アンテナを XIAO に付ける。XIAO の部品面にある金色の小さな丸いコネクタに、アンテナの線の先を真上から押し当てて、パチッと鳴るまで押す。拡張ボードを付ける前のほうが押しやすいです。
  3. 拡張ボード（マイクと SD の板）を付ける。カメラが付いていたら外す。microSD カードを挿す。
  4. 裏面の BAT＋／BAT− のはんだの上に、カプトンテープを 1枚貼る。線が重なる所には貼らない（厚みが増えて基板が浮く）。
  5. はんだの継ぎ目が、すべて熱収縮チューブで隠れているか見る。
1

LED をフタに付ける

接着剤が固まるまで時間がかかるので、最初にやる
  1. フタの表の LED の穴を、外からマスキングテープでふさぐ。しっかり密着させる。
  2. フタを表を下にして平らな机に伏せ、内側の短い筒に LED を差し込み、先端がテープ越しに机に当たるまで押す。
  3. その姿勢のまま、筒の口と LED の根元の境目にだけ、つまようじの先で少しだけ接着剤を付ける。流し込まない。
  4. 固まったらフタを起こしてテープをはがす。LED の足は、根元から 2〜3mm で直角に曲げ、フタを本体に載せたとき電池のほうへ倒れる向きにする（JST のほうへ倒さない）。

瞬間接着剤は使わない。LED が白く曇ります。2液エポキシか、多用途接着剤（セメダインのスーパーX など）を使います。
穴に入らないときは、内側から丸ヤスリで軽く広げます。表側は削りません。

2

仮置きで確かめる（接着しない）

ここで合わなければ、固定する前に直せます
  1. スイッチを、上の壁の内側の浅いくぼみにはめる。レバーが上の壁の穴から出て、左右に動くこと。黒い線 2本の端子が左（壁側）に来る向きにする。逆なら、スイッチを前後に裏返す。
  2. XIAO の裏の 5本の線を 1列に並べ、緑の入口を通して、XIAO を USB 側から入れて四隅の台に載せる。
  3. 確かめる：XIAO が押さなくても平らに座る。外から USB ケーブルが奥まで挿さる。

XIAO が浮く・傾くときは、線が入口で噛んでいます。入口の上側の柱（マイク穴の壁につながっている柱）の下の端を、ニッパーで 2mm ほど切り取って入口を広げてください。今の印刷データ（v1.15）は、最初から入口を広げてあります。

3

固定する

スイッチ → XIAO → 電池の順
  1. スイッチ：スイッチの金属ケースと、左右の細い柱が触れる所に、接着剤を少しだけ付ける。レバーと穴のまわりには付けない（レバーが固まって動かなくなる）。
  2. XIAO：四隅の台の上に、薄い両面テープを小さく切って貼り、XIAO を載せて押さえる。USB の口が右の穴の真ん中に来ること。
  3. 電池：床の丸い台と細い台の上に薄い両面テープを貼り、電池を左の柱に突き当てて置く。右の壁との間に約 2.4mm のすき間が残るのが正解。すき間を詰めない。
  4. 電池の線は、電池の左の端から出し、左の壁ぞいの溝を上へ通す。途中の小さな柱は上を越えてよい。電池の上面より高くしない。余った線は溝の中で折りたたむ。
4

電池をつないで JST を置く

ここで初めて電池をつなぐ
  1. 電池のプラグを、XIAO の JST に指先の軽い力でまっすぐ挿す。
  2. つないだ JST を、左の壁にぴったり寄せて縦に寝かせる。電池側の口が下、XIAO 側の口が上。
  3. 左の壁との間に、ホットボンドか接着剤を1点だけ付けて固定する。JST を埋めない（電池を外せなくなる）。
  4. XIAO へ行く 2本の線は、すぐ右へ曲げて「通り道」へ。余った線は通り道でたるませる（XIAO の下に押し込まない）。
5

アンテナと残りの線を収める

  1. アンテナのフィルムを、左の壁の内側（JST とスイッチがある区画）に貼る。高さは、床から 5mm より上で、壁の上の縁から 2.5mm より下。
  2. 入らなければ、スイッチの下の床に貼る。マイク穴のある壁と、右の壁には貼らない。
  3. LED とスイッチの線の余りは、JST の右側の空いた所（通り道を含む左の区画）に収める。左の壁の上の縁ぞい（フタの縁が下りてくる所）は空ける。
  4. 外から上の壁を見て、マイクの穴 3つが向こうまで見通せること。
6

フタを閉める前の動作確認

フタは横に置いたまま
7

フタを閉める

順番があります
  1. ① 左上の角の出っ張りを引っかける → ② 左の辺を差し込む → ③ 下の辺を押してパチンと入れる。
  2. 無理に押さない。硬いときは、線を噛んでいないか、電池が右にずれていないか、JST の上や LED のまわりに線が入っていないかを先に見る。
  3. 開けるときは、下の辺の真ん中の小さな切り欠きに爪を掛けて起こす。
