MindClip サーバ設置（Surface）

Surface の Docker に、文字起こしと日記まとめのサーバを立てます。この回は、Surface で録った試しの音声が Obsidian の日記に入るところまで。MindClip 本体とつなぐのは次の回です。

できあがりの形

Surface では、ほかのシステムも Docker で動いています。手順2で Docker を一度止めるので、ほかのシステムも数分止まります。止めてよい時間にやってください。

用意するもの

1

Obsidian の保管庫の場所を調べる

  1. Obsidian を開き、左のファイル一覧で、どれかのノートを右クリック →「エクスプローラーで表示」。
  2. 開いたエクスプローラーのアドレス欄をクリックすると、C:\Users\○○\Documents\MyVault のような場所が出ます。保管庫のいちばん上のフォルダまでをメモします（ノートがフォルダの中にあれば、その一つ上）。
  3. 日記（デイリーノート）を入れているフォルダ名も見ておきます。このサーバは Daily Notes というフォルダに書きます。違う名前なら、手順4で合わせます。
2

Docker に使わせるメモリを増やす

ほかのシステムも一度止まります

文字起こしと AI で、合わせて約 10GB 使います。Windows の初期設定では Docker（WSL）は 8GB までしか使えないので、12GB に増やします。

  1. スタートボタンを右クリック →「ターミナル」（または PowerShell）を開く。
  2. 次を貼り付けて Enter。メモ帳が開きます。
    notepad $env:USERPROFILE\.wslconfig
  3. すでに中身がある場合（ほかのシステム用の設定）：memory= の行だけ memory=12GB に直し、ほかは消さない。空の場合：次を貼り付ける。
    [wsl2]
memory=12GB
swap=4GB
  4. 保存してメモ帳を閉じる。ターミナルで次を実行（ここで Docker がいったん止まります）。
    wsl --shutdown
  5. Docker Desktop を開き直し、左下が緑（Engine running）になるまで待つ。ほかのシステムが自動で起き上がったかも確かめます。
3

プログラムを Surface に置く

  1. ブラウザで GitHub にログインした状態で、次を開くと ZIP がダウンロードされます。
    https://github.com/ginchankawaii/claude-code-book-template/archive/refs/heads/claude/local-llm-voice-device-0hcvx9.zip
  2. ZIP を右クリック →「すべて展開」。展開先は C:\mindclip にします（日本語や空白を含まない場所）。
  3. 中の voice-logger フォルダをエクスプローラーで開き、アドレス欄をコピーしておく。
    例：C:\mindclip\claude-code-book-template-claude-local-llm-voice-device-0hcvx9\voice-logger
4

設定を書き換える

  1. ターミナルで、さっきコピーした場所へ移動する（cd のあとに貼り付け。例）。
    cd "C:\mindclip\claude-code-book-template-claude-local-llm-voice-device-0hcvx9\voice-logger"
  2. 設定ファイルと作業用フォルダを作る。
    Copy-Item config.container.toml config.toml
mkdir data\inbox, data\archive, data\state, data\failed, data\test
  3. 保管庫の場所を書き込む。次でメモ帳を開き、C:/Users/you/Documents/Obsidian/MyVault の部分を、手順1で調べた場所に置き換える。区切りは \ ではなく / にします。
    notepad docker-compose.yml

    例：- C:/Users/taro/Documents/MyVault:/vault（最後の :/vault は消さない）

  4. 日記のフォルダ名が Daily Notes でない場合だけ、notepad config.toml で daily_notes_dir = "Daily Notes" を自分のフォルダ名に直す。
5

起動して、AI のモデルを取ってくる

ここだけインターネットを使います（合わせて 20〜40分）
  1. サーバを組み立てて起動する（初回は 5〜10分）。
    docker compose up -d --build
  2. 要約用の AI（約 2.5GB）を取ってくる。
    docker compose exec ollama ollama pull qwen3:4b
  3. 動いているか見る。ollama と voice-logger の 2つが running（または Up）なら成功です。
    docker compose ps

Docker Desktop の画面にも voice-logger というまとまりで表示されます。ほかのシステムとは別の名前なので、混ざりません。

6

試しの音声で確かめる

日記には書かずに、結果だけ見る
  1. Windows の「サウンド レコーダー」アプリで、30秒ほど話して録音する。保存された音声（.m4a）は、録音一覧で右クリック →「ファイルの場所を開く」で見つかります。
  2. その音声を voice-logger\data\test にコピーし、名前を test.m4a に変える。
  3. 試しに処理する（初回は文字起こしのモデル 約 1.6GB をダウンロードするので、10分ほどかかります）。
    docker compose run --rm voice-logger process --dry-run /data/test/test.m4a
  4. 最後に、文字起こしと要約が画面に出れば成功です。

試しの音声は Surface の中だけで処理されます。スマホから送ると途中で外のサービスを通ることがあるので、この確認は Surface で録った音声で行います。

7

本番：日記に書き込ませる

  1. test.m4a を data\inbox にコピーする。
  2. 1〜数分待つ。サーバが自動で見つけて処理し、終わると音声は data\archive へ移ります。様子は次で見られます（止めるときは Ctrl+C）。
    docker compose logs -f voice-logger
  3. Obsidian の Daily Notes の今日のノートに、「🎙️ 会話ログ（自動生成）」が追記されていれば完成です。
