# MindClip DIY — 電気設計書（配線設計 v1）

対象: 自作ウェアラブル音声ロガー「MindClip DIY」
前提: Seeed Studio XIAO ESP32S3 Sense（Sense拡張ボード装着、カメラモジュールは取り外し）、
LiPo（保護回路付き）、電子工作初心者がはんだ付け最小限で組める構成。

| **allday（既定・推奨）** | LiPo **802530** 800mAh | 680mAh | **約12.5時間** |
| slim | LiPo 502530 500mAh | 425mAh | 約7.8時間 |

## 1. 配線リスト（外部配線）

外付け部品は **電池・スライドスイッチ・LED(+抵抗) の3系統だけ**。配線図は `wiring.svg` を参照。

| # | XIAO側 | GPIO | 接続先 | 線色 | 備考 |
|---|--------|------|--------|------|------|
| 1 | **BAT+**（基板裏面パッド） | — | 電池 赤リード(+) | 赤 | 内蔵充電ICに接続。極性厳守（§5） |
| 2 | **BAT−**（基板裏面パッド） | — | 電池 黒リード(−) | 黒 | |
| 3 | **D1** ピン | GPIO2 | スライドスイッチ **中央端子** | 青 | 入力・内部プルアップ。**ON=GNDに短絡=LOW=録音** |
| 4 | **GND** ピン | — | 共通GND線 → スイッチ**片端端子** と LED**カソード** に分岐 | 黒 | GNDはXIAO側1点に集約（はんだ箇所削減） |
| 5 | **D3** ピン | GPIO4 | 220Ω抵抗 → LED **アノード(長い足)** | 橙 | 録音中インジケータ（正面配置） |

- スイッチの3端子のうち使うのは **中央 + どちらか片端の2本のみ**。残り1本は未接続（切り落としてよい）。
- GPIO2・GPIO4 はともに **RTC GPIO（ESP32-S3はGPIO0〜21）** なので、deep sleep からの
  EXT0ウェイクアップに使用可能。ストラッピングピン（GPIO0/3/45/46）は回避済み。
- D1/D3 を選んだ理由: XIAOの外部ピンのうち Sense拡張ボードが使わない D0〜D7 の中から、
  ストラッピングピンでなく、基板の同じ側（配線図で左列）に並ぶピンを選定。
- **ピン割当はWeb検証済み**（espboards.dev / Seeed公式wiki）: D1=GPIO2、D3=GPIO4、
  D0/D1/D3/D4 はセーフピン、microSD CS=GPIO21 の内蔵ユーザーLED共用も実在を確認。

### 1.1 内部接続（Sense拡張ボード経由・配線作業は不要）

拡張ボードはB2Bコネクタで押し込むだけ。以下はファームウェア開発用のピン番号メモ。

| 機能 | GPIO | 備考 |
|------|------|------|
| PDMマイク CLK | GPIO42 | I2S PDMモード 16kHz/16bit/mono |
| PDMマイク DATA | GPIO41 | |
| microSD SCK | GPIO7 | SPI接続 |
| microSD MISO | GPIO8 | |
| microSD MOSI | GPIO9 | |
| microSD CS | GPIO21 | **内蔵ユーザーLEDと共用** → SD使用時は内蔵LEDを状態表示に使えない。外付けLED採用の電気的根拠 |
| カメラ関連 | GPIO10〜18, 38〜40, 47, 48 ほか | カメラは取り外して未使用 |

### 1.2 LED 電流制限抵抗の計算

- GPIO出力電圧 3.3V、赤色LED順方向電圧 Vf ≈ 2.0V（OSR5JA3Z74A 625nm、typ 2.1V）
- I = (3.3 − 2.0) / 220Ω ≈ **5.9mA**（GPIO許容±40mA・LED定格に対し十分余裕）
- 「微灯」要件はハードを変えず **ファームのLEDC(PWM)でデューティ10〜20%** に落として実現
  （平均 0.6〜1.2mA）。抵抗を1kΩにする方法もあるが、部品を1種類（220Ω）で済ませ、
  明るさをソフトで追い込める方式を採る。
- 抵抗の定格は **1/4W（小型・長さ約6.3mm×φ2.3mm）を指定**。消費は最大でも
  (3.3−2.0)V × 5.9mA ≈ 7.7mW で 1/4W に対し余裕30倍以上。1/2W品（6.3mm級より大型）は
  狭い筐体内の空中配線・リッド裏LEDサブアセンブリの取り回しを悪くするため使わない。

## 2. 電源設計

### 2.1 充電（USB-C直挿し）

- XIAO ESP32S3 は LiPo 充電IC **TI BQ25101** を内蔵（Seeedフォーラム・Seeed配布のTI
  データシートで確認済み）。
- **充電電流は 50mA (Fast) / 3.8mA (Trickle)**（**Seeed公式スペック表で確認済み**:
  wiki.seeedstudio.com/xiao_esp32s3_getting_started、GitHub原文 Seeed-Studio/wiki-documents。
  「100mA」は別製品 XIAO ESP32S3 **Plus** の値であり本機には適用されない。旧版本書の
  「約100mA・0.2C・5〜6時間」は誤りだったため本版で訂正）。
- 充電電流が50mA固定であるため、**満充電までの時間は容量に比例する**:
  slim(500mAh) で約11〜12時間、**allday(800mAh) で約16〜18時間**（CC + CVテーパ込み）。
  **どちらのバリアントでも、就寝中だけ（8〜10時間）の充電では空から満充電にはならない。**
- **v1のエネルギー収支は「電池容量」ではなく「一晩に戻せる充電量」で決まる（重要）**:
  帰宅後すぐUSB-Cに挿して翌朝まで10時間充電しても、戻るのは **50mA × 10h = 500mAh** まで。
  装着15時間で使ってよい平均電流は **500mAh / 15h ≈ 33mA** が上限になる。
  **allday の 800mAh は「1日の消費上限を上げるもの」ではなく、
  ①省電力実装が間に合わない期間のマージン ②充電を忘れた日の余力 ③経年劣化代**として効く。
  したがって §2.2 の省電力実装（平均 ≤28mA 目標）は allday でも省略できない。
  実測で充電電流が50mAを有意に上回る個体が確認できた場合のみ計画を緩和してよい（反証は実測で）。
- 充電状態LEDは**赤**（公式記載。旧版の「黄」は誤り）。挙動も公式記載あり:
  電池未接続でケーブル接続→点灯後30秒で消灯 / 充電中→点滅 / 満充電→消灯。
  筐体内で見えない前提は変わらない（v2でライトパイプを設ければ満充電確認に流用可能）。
  ファームで電池電圧を読む回路はXIAOに無いため、残量表示はv1では非対応。
- **v1制約（明記）**: v1配線には **VBUS(USB挿入)検出手段が無い**ため、全体設計書§5の
  「充電検出時に同期」トリガは v1 では実装不可。**v1の同期トリガはスライドスイッチOFFのみ**。
  v2では 5Vピン→高抵抗分圧→空きRTC GPIO（例 D0/GPIO1）でVBUS検出回路を追加する方針（申し送り）。
- **v2申し送り**: 15時間走破が実測で不足する場合の判断材料として、A0へ高抵抗分圧
  （例 220kΩ×2、常時消費約9µA）を追加すれば電池電圧監視・残量警告が可能。

### 2.2 消費電流と連続録音時間の試算

| 状態 | 電流 | 根拠 |
|------|-----|------|
| 録音中・素の状態（WiFi/BLEオフ、PDM取得+SD連続書込） | **平均 54.4mA / ピーク 108mA**（Battery 3.8V） | **Seeed公式スペック表の実測値**「Microphone recording & SD card writing」。本機の使い方そのもの。予算の基準はこのworst caseに置く（旧版に「64.5mA / 109.3mA」と記載していたが、採用値は 54.4mA / 108mA。差は出典の読み取り差で、**どちらも実測で確定させるべき数値**） |
| 録音中・省電力実装後の**目標** | **平均 ≤28mA**（LED PWM ≈1mA 込み） | 下記ファーム省電力要件による数値予算（実測ゲートで担保） |
| WiFi同期中 | 平均約100mA、**送信バーストは瞬時300mA超**あり得る | ESP32-S3 WiFi送信時の一般値（assumption）。電池PCMの放電定格要求の根拠（bom.md #2） |
| deep sleep（スイッチOFF時） | **3mA (typ)** | **Seeed公式スペック表のSense列に明記**（Deep Sleep Mode: 3mA typ。素のXIAO 14µAはSense非装着時の値） |

- **連続録音時間（素の状態・省電力実装なし）**: 実効容量 = 公称 × 0.85
  （保護回路カットオフ・経年を見込む）を 54.4mA で割る。
  - **allday(800mAh)**: 680mAh / 54.4mA ≈ **12.5時間**
  - slim(500mAh): 425mAh / 54.4mA ≈ **7.8時間**
  → **slim は省電力実装なしでは「起床〜就寝」を走り切れない。これが allday を既定に
  した理由。** allday でも 15時間要件には届かないため省電力実装は必須だが、
  未達分が「あと2.5時間」で済むか「あと7時間」かの差は大きい。
  旧版の採用値 30〜40mA（全体設計書4.2節由来）は公式実測の約1/1.4〜1/1.8で過小であり、
  本版で公式worst caseベースに訂正（設計書4.2節にもこの前提を併記すること）。
- **ファーム省電力要件（「見込み」ではなく数値予算として課す）**:
  1. **CPUクロック 80MHz化**（デフォルト240MHz→80MHz。録音+SD書込に十分）
  2. **SDバッファリング書込**: RAMに30〜60秒分バッファしてまとめて書込み、
     SDのアイドル時間を最大化（書込中以外はSDをアイドルに落とす）
  3. **VADゲート**: エネルギー閾値VADで無音時のSD書込を停止。
     **SD書込デューティ目標 ≤35%**（会話時間は1日の一部という前提を数値化）
  4. **合格条件（実測ゲート・必須）**: 装着日相当の混合プロファイル（会話/無音混在）で
     **実測平均電流 ≤ 28mA**（allday: 680mAh / 28mA ≈ 24h、slim: 425 / 28 ≈ 15.2h）。
     **28mA は「一晩10時間の充電で戻せる 500mAh を15時間で使い切らない」上限 33mA
     （§2.1）に対する安全代込みの目標値**であり、バリアントによらず変わらない。
     **筐体確定・印刷前にUSB電流計等でこのゲートを実測通過すること**（測定手順は
     [`README.md`](README.md) §8）。
- **ゲート不通過時のフォールバック**: バリアントを **slim → allday（802530 / 800mAh）**
  に切り替える。電池はフットプリント（30×25mm）が同じで厚みだけが 5.0→8.0mm 変わるため、
  `MINDCLIP_VARIANT=allday` で筐体を再生成すれば奥行きが 12.9→14.6mm になるだけで済む
  （**筐体の再印刷は必要**）。
  それでも足りない場合は 703040（800mAh、30×40×7mm）等へ格上げすることになるが、
  高さ40mmは筐体高さ(49.4mm)に収まらず**全面的な再設計**になる。
  「筐体に予備空間を要求済み」という旧版の記述は誤りのため撤回（MECHANICAL.md と整合）。
- **WiFi同期の消費**: 1日分 ≈ 15h × 29MB/h(ADPCM) ≈ 440MB。実効20Mbpsで約3分、
  余裕を見て10分としても 100mA × (10/60)h ≈ **17mAh（容量の約3.4%）** → 影響軽微。
- **deep sleepの持ち**: 公式typ 3mA では allday 680mAh / 3mA ≈ **約9日**
  （slim 425mAh なら約6日）（旧版「1mA worstでも17日」
  は素のXIAO寄りの過小仮定だったため公式値で置換）。就寝8時間の待機は 24mAh（約5.6%）で、
  毎晩充電運用（§2.1）なら運用上の実害なし。
  **ファーム要件**: deep sleep 移行前に **SD CS(GPIO21)をHIGH固定し SPIバスを解放**する。
  ただし通常GPIOの出力状態はdeep sleep中に失われるため、
  **`gpio_hold_en(GPIO_NUM_21)` + `gpio_deep_sleep_hold_en()` でCSのHIGHをホールドする**こと
  （ホールドなしではCSがフロートしSDの待機電流がかえって増え得る。§2.3の
  `rtc_gpio_pullup_en(GPIO_NUM_2)` と同じ粒度の仕様として明記）。

### 2.3 スライドスイッチの役割（電源断ではない理由）

スイッチは電池ラインに入れず **GPIO2の入力**とする。OFF = GPIO2オープン(内部プルアップでHIGH)
→ ファームが同期処理後に deep sleep へ。ON = GPIO2をGNDへ(LOW) → EXT0ウェイクで復帰し録音開始。

- 電池ラインを物理的に切ると **USB-Cを挿しても充電できなくなる**（充電ICが電池から切り離される）
  ため不採用（確定済み設計判断）。
- ON中は内部プルアップ(約45kΩ)経由で 3.3V/45kΩ ≈ 73µA が流れるが、録音中30mA超に対し無視できる。
  OFF(deep sleep)中はスイッチ開放なのでプルアップ電流はゼロ。
- **ファーム要件**: EXT0ウェイク(GPIO2, LOW検出)では、通常のGPIOプルアップがdeep sleep中に
  無効化されるため、**RTCドメインの内部プルアップを明示的に有効化**すること
  （`rtc_gpio_pullup_en(GPIO_NUM_2)` 相当をsleep移行前に実行）。

最小化のためにやったこと / やらないこと:

- **Sense拡張ボードははんだ不要**（B2Bコネクタに押し込むだけ）。カメラはコネクタから外すだけ。
- **ピンヘッダを使わない**: XIAOのスルーホールに直接ワイヤをはんだ付け（部品高さも減る）。
- **GNDをXIAO側1点に集約**し、分岐はワイヤのより合わせ1点で処理。
- **電池コネクタ(JST-PH等)は付けない**: XIAO側に受けコネクタが無く、追加すると圧着工具か

- 抵抗はLEDリードに直接継ぐ「空中配線+熱収縮チューブ」でユニバーサル基板を不要にした。

## 4. 組立順序（推奨）

1. スイッチ・LED・抵抗のサブアセンブリを先に作り、熱収縮チューブで絶縁。
   **LEDはリッド側に接着され配線で本体と繋がるため、LED配線（橙・黒）は余長60mm以上**
   確保すること（リッド開閉のたびに配線が引かれるため。閉め込み時は電池脇の空間へ収納）。
   **スイッチ配線（青・黒）は推奨50mm**。短く切りすぎると
   「筐体外でハーネス完成→順次設置」の組立順が破綻するため、長め→組込後に整線とする。
2. XIAOに D1/D3/GND の3本をはんだ付けし、**電池を繋ぐ前に** USB-C給電でファーム書込み・
   スイッチとLEDの動作確認。
3. 最後に電池をBAT+/−へ（§5の手順厳守）。導通・ショートチェック後、筐体へ組み込み。
4. 筐体組み込み時、**XIAOスタックと電池は薄手両面テープで筐体に固定する（必須手順）**。
   USB-C挿入力（5〜20N）で基板が動くと充電できなくなるため「任意」ではない。
   電池側は薄スポンジ併用でラトル・リード疲労を防ぐ（bom.md #9a）。

## 5. 安全設計

### 5.1 LiPo保護回路 — **必須**

- XIAO ESP32S3 の内蔵ICは「充電制御」であり、**過放電・過電流・短絡保護ICは非搭載**
  （assumption: Seeed回路図の一般理解。原典要確認）。よって **保護回路(PCM)内蔵の
  セルを必ず使う**（allday=802530 / slim=502530。bom.md #2 の指定品）。
  過放電は保護回路のUVLO(約2.4〜3.0V)で遮断。
- 電池電圧監視回路が無いため、運用ルール「毎晩充電」を前提とする（ゼロタッチ運用と整合）。

### 5.2 極性ミス防止

- 中華系LiPoは**赤黒が逆の個体が実在**する。リード色を信用せず、接続前にテスターで
  **赤リードが+（対黒で +3.5〜4.2V）** であることを確認する。
- **基板側パッドの向きも確認する**: XIAO裏面のBATパッドは、公式wikiに
  **負極(−)がUSB-Cコネクタに近い側、正極(+)が遠い側**と明記されている（wiring.svg にも記載）。
  電池リード側の極性確認だけでは基板側の逆接続を防げないため、両方を確認してからはんだ付けする。
- 手順: ①電池リードを1本ずつ処理（両方同時に被覆を剥かない） ②先にBAT−(黒)、次にBAT+(赤)
  ③リード同士・工具でのショートに注意（保護回路付きでも火花・発熱リスクあり）。
- はんだ付け後、BAT+↔BAT−間の短絡がないことをテスター導通レンジで確認してから通電。

### 5.3 絶縁・機械的保護

- XIAO裏面のBATパッドはんだ部は**ポリイミド(カプトン)テープ**で覆う。電池本体と基板裏面の
  間にも1枚貼り、突起はんだによるパウチ穿孔を防ぐ。
- **機構設計への要求（重要）**: 上記のはんだ盛り + AWG28リード（外径約1.2mm）+ カプトン
  テープ、および D1/D3/GND スルーホールの裏面フィレットにより、**XIAO基板裏面には
  約1.0〜1.5mmの突出が必ず生じる**。筐体はこれを見込んだ逃げポケット（BATパッド直下）と
  配線チャネルを備え、基板裏面を壁面に密着させない構造とすること。
- **電池リードの出射方向**: 502530 / 802530 のリード/タブは**長さ30mm方向の端面
  （25mm幅の面）から出る**（命名規則: 厚5.0または8.0 ×幅25×長30。2バリアントは
  厚みだけが違い、フットプリントとリード出射方向は共通）。
  筐体側はリード出射端に曲げ代・逃げ溝を確保すること。
- 電池リードのはんだ継ぎ目・抵抗の空中配線は**熱収縮チューブ**で個別に絶縁。
- 電池は角のあるはんだ面・スイッチ足と接触しない配置とし、筐体側でリブ固定
  （機構設計へ要求: 電池室に金属エッジなし、リード線の噛み込み防止溝）。
- 発熱源(ESP32-S3本体)と電池を筐体内で直接密着させない。充電はUSB-C直挿しのため
  充電中は装着していない前提（体温+充電発熱の重畳なし）。

### 5.4 その他

- 磁石(ネオジムφ6×2mm×4)は電気回路から独立。PDMマイク・ESP32への磁気影響は実用上なし。
  ただし**microSDやクレジットカード類と密着携行しない**注意書きをREADME側に入れること。
- 静電気: 組立時はESP32基板の端子に直接触れない。冬場は金属に触れて放電してから作業。
- **LED窓の接着はエポキシ系を推奨**（瞬間接着剤は白化ガスがLEDレンズ・窓内面を曇らせる
  恐れがあるため、LED近傍では使わない）。
