# MindClip DIY — 基板（PCB）設計

**結論から: v1 では基板を作らない。** 4案を設計・比較し、3人の審査員が独立採点した結果、
**「基板を起こさず、空中配線を改良する」案が採用**された。ただし検討は無駄にならず、
v1 の設計が **はんだ11点 → 10点** に減り、**電池の極性事故リスクが下がった**（JSTコネクタ化）。
将来 v2 で基板が必要になったときのために、**発注可能な基板データも作って置いてある**。

- 採用構成の詳細 → [`SCHEMATIC.md`](SCHEMATIC.md)（回路・ネットリスト・テスタゲート）
- v2用の基板データ → [`LAYOUT.md`](LAYOUT.md) §0 を**必ず先に読むこと**
- 組み立て手順 → [`../README.md`](../README.md)

## 1. なぜ基板を作らないのか

### 1.1 高さ予算が足りない

筐体CAD（`../cad/mindclip_case.py`）を実行して実測した、基板を入れられる余地:

| バリアント | 高さ予算 | 1.6mm厚基板 | 0.8mm厚基板 |
|---|---|---|---|
| allday | **2.30 mm** | 入る（ただし余裕0.7mm） | 入る |
| slim | **0.60 mm** | **入らない** | **入らない**（はんだフィレット+固定材で超過） |

**slim バリアントは、どんな基板を入れても原理的に成立しない。** 基板を採用すると
2バリアント体制を捨てるか、筐体を作り直すことになる。

### 1.2 寸法がまだ実測されていない

より本質的な理由。`../README.md` §9.1 に列挙した**未検証の寸法が1つも実測されていない**:

- XIAOスタックの総厚 **7.5mm（assumption）** ← slim の内寸9.5mmはこの値に直接依存
- マイクの基板上の位置、XIAO裏面BATパッドの正確な位置
- 802530電池の実寸、USB-Cケーブルの嵌合

もし実測でスタック厚が 8.3mm だったら、slim の内寸は即破綻する。
**基板は「寸法が固まった後の最適化」であって、「寸法を固める手段」ではない。**
この状態で基板を焼くと、失敗コストが「2週間の納期 + ¥4,700 + XIAO ¥2,660」になる。

### 1.3 反復コストの差

| | 設計ミスに気づいてから直るまで |
|---|---|
| 空中配線 | **その晩**（線を1本付け替える） |
| 基板 | **2週間**（再発注） |

ファームウェアがまだ存在せず、VBUS検出のGPIO選定・分圧比・ADC校正を
「回路を触りながら詰める」段階では、この差が決定的に効く。

## 2. 4案の比較

| | 案A **採用** | 案B | 案C | 案D |
|---|---|---|---|---|
| 構成 | 基板なし・空中配線改良 | キャリア基板（直はんだ） | キャリア基板＋ソケット | ユニバーサル基板手組み |
| 追加高さ | **0 mm** | +1.0 mm | **+7.1 mm** | 0 mm |
| 手はんだ | **10点** | 20点 | **54点** | 36点 |
| 費用 | ¥1,100 | ¥4,700 | ¥1,400 | ¥310 |
| 納期 | **即日** | 2週間 | 3週間 | 即日 |
| VBUS検出 | ✗ | ✓ | ✓ | ✓ |
| 電池監視 | ✗ | ✓ | ✓ | ✓ |
| 採点合計 | **174** | 132 | 42 | 79 |

審査員の推し: 組立性→**案A** / 機構→**案A** / 電気→**案B**

### 不採用の理由

- **案B（キャリア基板）**: 設計としては最も筋が良く、**v2 で作るならこれ**。
  ただし今作ると 1.2 の「寸法未実測」に直撃する。また目的の一つだった
  「電池直はんだの排除」は達成できない（BATパッドが基板裏面にあるため窓＋ジャンパが残る）。
  手はんだも 11→20点と**増える**。
- **案C（ソケット式）**: 却下。外形が +4.6mm（14.6→19.2mm）、手はんだ54点、slim消滅。
  「XIAOを壊しても差し替えられる」という唯一の価値も、BAT+/−がヘッダに出ていないため
  成立しない。**予備のXIAOを1枚買う（¥2,660・即日）ほうが安くて確実。**
- **案D（ユニバーサル基板）**: 「まず1台試す」段階の現実解ではあるが、
  再現性とドキュメント化に耐えない（24穴中19穴に詰め込み、手はんだ36点）。

## 3. 検討の結果、v1 に反映されたこと

基板を作らないと決めた一方で、**案Aの改良（A-1）は v1 に取り込んだ**:

| | 変更前 (v1) | 変更後 (v1.5) |
|---|---|---|
| 電池の接続 | BATパッドに**直はんだ** | **JST-PH2.0 ピグテール**（コネクタ嵌合） |
| GND配線 | 空中で3本より合わせ（スプライス） | **デイジーチェーン**（スプライス廃止） |
| はんだ点数 | 11点 | **10点** |
| 電池リード長 | 未指定 | **40mm 指定**（slim の収まりに必須） |

**JSTコネクタ化の効果**: 電池を「挿す」作業に変わるので、はんだごてを持ったまま
極性を間違える事故が減る。加えて、電池だけ後から外せるので保管・輸送も安全になる。

> **ただし極性リスクはゼロにならない。** JSTの極性キーは「上下逆挿し」しか防がず、
> **ハウジング内のコンタクト位置が逆に配線された電池（中華セルに実在）は防げない**。
> `SCHEMATIC.md` §5.4 の**嵌合前テスタゲートは必須のまま**。組立ガイドの手順8に
> 「リード線の色を信用せず、コンタクト位置で極性を測る」手順として組み込んである。

## 4. v2用の基板データ（発注しないこと）

将来のために、2種類の基板を設計してガーバーまで出力してある。

| 基板 | 外形 | 用途 |
|---|---|---|
| `mindclip_sense.kicad_pcb` | 10.0 × 15.6 mm | サテライト基板。VBUS検出＋電池監視だけを載せる最小構成 |
| `mindclip_carrier.kicad_pcb` | 34.2 × 21.5 mm | キャリア基板。XIAOをカステレーション直はんだ |

**発注してよいのは、以下のゲートを全て通過してからである**（`SCHEMATIC.md` §9.4）:

1. v1 を1台組んで、消費電流ゲート（平均 ≤28mA）を通す
2. **ノギスでXIAOスタック総厚を実測**し、`XIAO_STACK_T` を更新
3. XIAO裏面 BAT+/− パッドの座標を実測
4. 802530の実寸・リード出射方向・JSTプラグ極性を確認
5. `gen_pcb.py` を再実行して DRC を通す

### 検証状況（正直に）

- ✅ 独立ジオメトリDRC **エラー0件**。設計途中で見つかった**異ネット衝突41件
  （うち銅箔レベルの直短絡16件）は修正済み**で、独立検証でも0件を確認した
- ❌ **KiCad本体のDRCは一度も走っていない**（この環境にKiCadが無いため）
- ❌ 製造業者のDFMチェックも未実施
- ❌ 逆接続保護FETは MC-CARRIER-A rev.A には**載っていない**

発注前に必ず KiCad で開いて DRC を通すこと（手順は `LAYOUT.md` §9.3）。

## 5. 基板を作るべき条件

以下のどれかに当てはまったら、案B（キャリア基板）に移行する:

1. 実測でXIAOスタック厚が 7.5mm を明確に**下回った**（高さ予算に余裕ができる）
2. **3台以上作る** / 他人に作らせる / 書籍の作例にする
3. **VBUS検出**（充電開始をトリガに自動同期）が必須要件に昇格した
4. 極性ミスによる破損を**設計で排除する**ことが要件になった

3番は全体設計書の「充電ドックに置いたら同期開始」に対応する。
v1 ではこの回路が無いため、**同期のトリガはスライドスイッチOFFのみ**である。
