# AIの判断は、自分の費用を稼げるか ―― 設計の段階で分かったこと（2026-11-23）

所有者の問い：「要人の発言や重要な発表の前には外す、といったプロのような判断をAIにさせて、APIの費用を自分で稼がせられるか。」

結論を先に：**いまの元手（約27万円）では、稼げない。** 完璧に当てるAIがいたとしても、得の上限がAPIの費用に届かない。
しかも、この売買ルールでは「外す」こと自体が高くつく。以下は、その根拠である。

## 何を計算したか

発表の日程は**使っていない**（公式の日程のサイトに、この作業環境から届かなかった）。代わりに「**でたらめな時刻**」で同じことをして、次の2つを出した。

1. 外すこと・待つこと自体のコスト（発表と関係なく、やるだけでどうなるか）
2. 完璧に当てた場合の上限（これ以上は、どんなAIにも出せない）

条件：2015〜2026年のH1のテープ、運用点（残高27.2万円、0.01ロット刻み）、終値方式の再生。再生の基準（SMA2400で年15.1%・最大下落25.8%・219回）は、既知の値と一致する。
でたらめな窓は年40回、長さは6時間と24時間の2通り、それぞれ100通り引いた。

## 1. 外すこと・待つことのコスト

近い長さ9通り（SMA2000〜2800）の平均。かっこの中は、100通りのばらつき（標準偏差）。

| やり方 | 窓 | 年率の変化 | 最大下落の変化 |
|---|---|---|---|
| **A 新しく建てるのを待つ**（窓の間は建てない。過ぎたらルールどおり建てる） | 6時間 | −0.01ポイント（±0.23） | +0.4ポイント |
| | 24時間 | −0.11ポイント（±0.86） | +2.2ポイント |
| **B 外して、建て直す**（窓の間は建玉を閉じ、過ぎたらルールどおり建てる） | 6時間 | **−0.81ポイント**（±2.37） | **+20.8ポイント** |
| | 24時間 | **−1.69ポイント**（±2.87） | **+19.8ポイント** |

本番の設定（SMA2400）だけで見ると、もっとはっきりする。

| やり方 | 窓 | 年率の変化 | 最大下落の変化 | 良くなった割合 |
|---|---|---|---|---|
| B 外して、建て直す | 6時間 | −5.41ポイント（±2.58） | +24.3ポイント | 100通り中1通り |
| | 24時間 | −6.37ポイント（±3.07） | +22.8ポイント | 100通り中4通り |
| **B′ 外して、同じ大きさ・同じ損切りで戻す**（いちばん穏やかな形） | 6時間 | −1.37ポイント（±1.19） | +0.7ポイント | 100通り中11通り |
| | 24時間 | −3.15ポイント（±2.26） | +3.9ポイント | 100通り中13通り |

読み方：

- **「外して建て直す」は、時刻がでたらめでも、成績を大きく悪くする。** 建て直すたびに、建玉の大きさ（1〜5倍）と損切りの位置が決め直されるからである。
  長く持って育った建玉が、大きな倍率・近い損切りの建玉に入れ替わり、最大下落が約20ポイント増える。
- 同じ大きさ・同じ損切りで戻す形でも、年1.4〜3.2ポイント悪くなる。窓の間に相場が進んだぶんを取り逃がすのと、スプレッドのためである。
- だから、発表の前に外して得になるのは、**発表の時間帯が、でたらめな時間帯より、年に1.4ポイント以上はっきり悪い場合だけ**である。その証拠は、いまのところ無い。
- 「新しく建てるのを待つ」は、ほとんど何も変えない。害は小さいが、得も小さい（下の上限）。

## 2. 完璧に当てた場合の上限

- 建てるのは年に約23回。そのうち約9割が負けで、1回あたり平均−0.36%。負けを全部足すと、年に約−7.4ポイント。
- 利益は、少数の長い取引に集中している。9通りの平均で、上位3回の取引の利益が、純利益の全部を上回る（残りの取引は、合わせると赤字）。
- **窓の中に入った負ける建てを、全部・ただで避けられたとして**：6時間の窓で年0.33ポイント（27万円で年約900円）、24時間の窓で年1.10ポイント（年約3,000円）。
- すべての負ける建てを完璧に避けたとしても（そんなことは誰にもできない）、年7.4ポイント（27万円で年約2万円）。

APIの費用と比べる：月300円（年3,600円）のAPI代を払うのに必要な上乗せは、27万円なら年1.33ポイント。
完璧に当てたときの上限（年0.33〜1.10ポイント）が、それに届かない。上限が年3,600円を超える元手は、約33万〜109万円。
上限の3分の1しか取れないとすれば、約100万〜330万円になる。

## 3. 候補を選び直すと、でたらめでも良く見える

候補を3つ試して、いちばん良いものを採ると、でたらめな窓でも、平均で年+0.18ポイント（6時間）、+0.63ポイント（24時間）良く見える。95%点は+0.63、+2.51。
つまり、「3つ試したら1つは良かった」は、証拠にならない。採るには、この水準をはっきり超える必要がある。

## 4. 前向きに試しても、件数が足りない

窓の中に入る建ては、6時間の窓で11年に約11回（年に約1回）、24時間の窓で約39回（年に約3.5回）しかない。
AIを本番の横で1年動かしても、「当たっていたかどうか」を判定できるだけの件数は集まらない。

## 結論

1. **「外す」は、やらない。** この売買ルールでは、外すこと自体が高くつく。
2. **「待つ」は害がないが、得の上限が小さい。** いまの元手では、APIの費用を払えない。規則にできるものは、AIではなく規則で持てば費用は0円である。
3. **AIを前向きに試しても、判定できない。** 件数が足りない。
4. **残っている問いは1つだけ**：本物の発表の日程で、AとB′が、でたらめな時刻よりはっきり良いか。これはAPIを使わずに測れる（`docs/AI_VALUE_PROMPT.md`）。
   元手が上の水準に届くまでは、測っても使い道がない。

## この計算の限界（正直に）

- 設計の段階の計算であり、事前登録した検定ではない。発表の日程は使っていないので、「発表を避けると得か」には答えていない。答えているのは「外すことのコスト」と「得の上限」である。
- スクリプトは、指示書を点検したエージェントが書いた走り書きである（`design/`）。作者が走らせ直して確かめたのは、SMA2400の20通り、B′の100通り、上限と集中度の計算。
  9通り×100通りの表（`design/placebo_nine.csv`）は、点検役の出力をそのまま集計した。その点検は、利用枠の上限で途中で止まり、報告は受け取っていない。
- 終値方式の再生である（本番は確定足方式）。上限の計算は両方式で行い、ほぼ同じだった。
- 上限は「負ける建てが時間に均等に散らばっている」と置いた目安である。発表の前後に2倍集まっているとしても、上限は2倍（年0.65〜2.2ポイント）にとどまる。
