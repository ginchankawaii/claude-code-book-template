2026-11-16 の出来事 ―― 所有者の一次記録の匿名化した抜粋
=====================================================================

出どころ
  所有者が 2026-11-16〜17 に作者との会話に貼った3つの記録：
    (1) MT5 の「操作ログ」(Journal)   … 時刻は PC の時計（日本時間, GMT+9）
    (2) MT5 の「エキスパート」(Experts) … 同上
    (3) `docker compose logs -t fx`      … 時刻は Docker が付けた UTC
  および Windows Update の更新履歴のスクリーンショット（KB5132061 が 2026/11/16 にインストール済み）。
  原文はリポジトリに置いていない（口座番号・IPアドレスなどを含むため）。

伏せたもの
  口座番号 → <acct>、IPアドレス → <ip>、建玉のチケット番号 → <ticket>、
  Windows のユーザー名・MT5 のデータフォルダ名・PC の構成を書いた行 → 削除。
  時刻・イベントの種類・ロット・値段・SEQ は原文のまま。
  同じ形の行の繰り返しは「…（同じ行が N 回）」にまとめた。件数は原文を数えたもの。

読むときの注意
  - (1)(2) と (3) は別々の時計である。秒単位の前後関係には、2つの時計のずれが入る。
  - 01:43:00 から 06:54:41 までの間、(1) に Network の行は1行もない
    （接続の試行も、失敗も、切断も記録されていない）。なぜログインしなかったのかは、この記録からは分からない。
  - EA がログアウト中に `steady_status.csv` へ何を書いたか（残高0・建玉なし、と推定している行）は、
    どの記録にも残っていない。baseline/sre/repro_1116.py はこれを仮定として置いている。
  - PC が再起動した時刻そのものは記録にない（MT5 と脳が 01:43 に起動したことからの推定）。
