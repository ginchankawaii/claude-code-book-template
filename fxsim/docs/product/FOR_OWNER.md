# 所有者の方へ ―― 「製品化」の計画について

（2026-11-23。AIへの指示書 `docs/PRODUCT_PROMPT.md` の、あなた向けの説明です。）

この紙で「こちら」と言うのは、作業をするAIのことです。「教えてください」「連絡」は、AIとの会話に書く、という意味です。
AIは、あなたが書いたときにしか返事ができません。利用枠が切れている間は、返事ができません。
**返事がないときは：何も再起動しない、手で売買しない、そのままにする。** 起きうるのは「安全装置が建玉（いま持っているポジション）を決済する」ところまでで、
損切りの注文は証券会社の側に残っています。

急ぐのは、下のほうにある **「今日から守ってほしいこと」** と **「Windows の更新と年末年始」** の2つだけです。

## ひとことで

「CADやお絵かきソフトを作り直した事例のように、製品として通用する水準へ」というご依頼への答えが、この計画です。
あの事例がうまくいったのは、目標がはっきりしていて、一歩ごとに正しいかどうかを機械で確かめられたからでした。
同じやり方で、fxsim を「作ったAIに正常かどうかを聞かないと分からないもの」から、「自分で異常を知らせ、説明書だけで使えるもの」に作り直していきます。

## 先に、いちばん大事なこと

**儲けは増えません。** 売買のルールは変えません。見込みは今と同じで、ならして年9%前後（27万円なら年2万円台。運しだいで年2〜15%）です。
途中で資産が3割ほど（約8万円）減る時期はふつうにあり、負ける年もあります。この数字も約束ではありません。
良くなるのは「安心して放っておけること」だけです。

## できあがると、あなたに見える変化

【最初の区切り（スマホに知らせが届く）まで】
- 健康診断が、止まっている原因と、やることを日本語で言います。
- 毎朝スマホに1通（正常かどうか。異常があれば、原因と、やること1つ）。建玉や金額をそこに書くかどうかは、あなたが選べます（知らせは外のサービスを通るためです）。
- PCごと止まったときも知らせるには、外の無料サービスへの登録が1つ要ります。使うかどうかは、その時にお聞きします。

【その先まで続けた場合】
- 画面を1つ見れば状況が分かります。AIに「正常？」と聞かなくて済みます。
- 更新は1回の操作で、失敗したら自動で元に戻ります。
- 11/16のように、つながり直した瞬間に健全な建玉が切られることを、MT5側のプログラムを作り直して防ぎます。

## できあがっても、ならないこと

- 儲けが増える、損をしなくなる、ではありません。
- 他人に配ってよい・売ってよい状態、ではありません。品質はそこを目指しますが、配る・売るには法律などの確認が別に要り、それが済むまでは「個人で使うもの」です。
- PC・回線・証券会社の故障そのものは防げません（気づいて知らせるところまでです）。

## かかるもの

- **期間**：半年〜1年の見込みです（確かなことは言えません）。途中の区切りで「ここまでで十分か」をお聞きします。
- **あなたが「続き」と言う回数**：数十回。進める速さはあなたが決めてください。ゆっくり進めたせいで新しく危なくなることはありません（知らせが届くようになる時期が、そのぶん遅くなるだけです）。
- **PCでの作業**：週1回までを目安に、1回10〜30分。全部で30回前後の見込みです。急ぎの安全対策で週1回を超えるときは、理由を先に言います。
- **長い作業**が3回ほど（各1時間前後）：練習用の環境づくり、MT5のチャートに入れてあるプログラム（EA）の入れ替え、止まったときの練習。
  - EAの入れ替えは全体で2回の予定で、相場が閉まっている土日の昼間にお願いし、月曜の朝にもう一度だけ見てもらいます。3回目が要ると分かったら、理由を言って、先に相談します。
  - 止まったときの練習は、練習用の環境だけで行います。いま動いているPCやMT5を、わざと止めることはしません。
- **毎月1回の習慣**：Windows の更新を、月〜木の夜に画面の前で入れる（30分〜1時間）。11/16のような「勝手な再起動」を防ぐためです。下に手順があります。
- **ほかにお願いすること**：デモ口座の申し込み、スマホに通知を受ける準備、取引の履歴を書き出すこと（どれも、その時に手順を渡します）。
- **お金**：かかりません（止めてあるAPIキーは止めたままです。有料のものを勧めるときは、先に言います）。

## いつ届くか（目安）

- 最初の1〜3回は調べるだけで、目に見える変化はありません。
- 最初に役に立つもの（健康診断が、止まっている原因と対処を日本語で言う）は、早くて12月、間に合わなければ年明けです。
- スマホへの知らせは、年明けの見込みです。**年内は、異常をスマホに知らせる仕組みは間に合いません。** 年末年始は、下の「見るだけのお願い」がその代わりです。

## 利用枠について

1回ごとに、ふだんの相談よりずっと多く使います。上限で止まっても記録は残っているので、枠が戻ってから同じ言葉をもう一度送れば、続きから進みます。
止まっている間も、売買は今までどおり動きます。

大事な変更のときに、何人ものAIに同時に確かめさせることができます。確認は厚くなりますが、利用枠を何倍も使い、上限に早く当たります。
使うかどうかは、最初の報告の中でお聞きします。答えがなければ、使いません。

## 今日から守ってほしいこと（3つ）

1. **fxsim（売買プログラム）を更新しない。** こちらが「fxsimを更新してください」と言うまで、PCで `git pull` を打たないでください。
   （作りかけのものがPCに入るのを防ぐためです。今までの説明書に `git pull` と書いてあっても、合図を待ってください。Windows の更新は別の話で、下のとおりにお願いします。）
2. **Windows と MT5 を再起動・終了しない。PCの電源を切らない、スリープさせない。**
   （PCが再起動したあと、MT5が証券会社につながらないまま1時間半ほどたつと、つながった瞬間に建玉が決済されるためです。11/16に実際に起きかけました。）
   - 例外は1つだけ：Windows Update に「再起動が必要です」と出たとき。下の「画面の前での再起動のしかた」のとおりに、月〜木の夜に行ってください。
   - Docker Desktop が「更新があります」と出しても、押さずにそのままにしてください。
   - 健康診断と `docker compose ps`・`docker compose logs` は、いつ使っても大丈夫です。`docker compose restart fx` と `docker compose up -d --build` は、困っていなければ打たないでください
     （打つなら、MT5がつながっている月〜木の夜に）。`docker compose down`（全部止める）は、使う前に相談してください。
3. **デモ口座と、2つ目のMT5は、こちらが手順を渡すまで、申し込まない・入れない。いま動いているMT5で、別の口座にログインしない。**
   （別の口座に入った瞬間に、売買プログラムが「建玉がなくなった」と勘違いし、元の口座に戻ったときに本物の建玉を決済してしまうためです。）

困るのは、続くはずだった建玉が切られ、買い直すときの大きさ（1〜5倍）が、そのときの相場で決め直されることです。

### 画面の前での再起動のしかた

月〜木の夜に（例外は、上の「返事がなく…変えられないとき」だけ）。寝る2時間前までに始めてください。12/24(木) と 12/31(木) の夜は、翌朝から相場が休みなので、行いません。

0. 押す前に、見るだけ：
   - MT5のパスワードが、すぐ出せる場所にある（ここには書かないでください）
   - MT5の右下に数字（通信量）が出ている（「回線不通」ではない）
   - チャートの左上が `brain OK` で、`more min` の前の数字が105以上
   どれか欠けていたら、再起動せず、そのまま教えてください。
1. Windows Update の画面の［今すぐ再起動］を押す。
2. 立ち上がったら、いつもどおりサインインする。MT5 と Docker Desktop が自分で開くのを数分待つ。開かなければ、いつものアイコンから開く。
3. MT5の右下を見る。数字が出ていれば、つながっています。「回線不通」「無効な口座」なら、［ファイル］→［取引口座にログイン］で、いつもの口座にログインし直す（サーバーの欄が、いつもの「Live」の付くものであること）。
4. 再起動から15分以上たったら、チャートの左上を見る。`brain OK` で、数字が105以上なら、終わりです
   （健康診断で確かめるなら、「脳稼働」の行が🟢で「心拍 ○秒前」の数字が660より小さければ合格です。全体の判定が🟡でも、ここが合格なら大丈夫です）。
5. ［今すぐ再起動］を押してから40分たっても3と4が揃わないときは、何も再起動せず、MT5の右下・チャートの左上・健康診断の言葉を、そのまま教えてください。
   健康診断が「〜を再起動」「アルゴ取引をON」と言ってきても、その場では従わないでください（この場面では、原因を取り違えることが分かっています）。
   1時間半を過ぎると、MT5がつながった瞬間に建玉が決済されることがあります。そのときも、手で買い直さないでください。
   （週末に行っていて MT5 がつながらないときは、下の「週末や休みの間にPCが再起動していたら」の2へ。）

※ `brain OK` の数字は、売買プログラムが10分ごとに「あと120分は有効」と書き直す合図の残り時間です。元気なら109〜119の間を行き来します。
売買プログラムが止まっていても、最後の合図から2時間は `brain OK` と出たままなので、**文字ではなく数字を見てください**（プログラムの中身から導いた読み方で、実際の画面では、こちらでは確かめていません）。

### 週末や休みの間にPCが再起動していたら

（サインインの画面に戻っている／MT5の右下が「回線不通」／チャートの左上が `BRAIN SILENT`、または `brain OK` でも数字が100より小さい、のどれかなら、これです）

1. あわてて何も再起動しない。手で決済も買い直しもしない。
2. サインインして、MT5が開いていなければ、いつものアイコンから開く。右下が「回線不通」なら、**気づいたらすぐ**、［ファイル］→［取引口座にログイン］で、いつもの口座にログインし直す
   （パスワードが要ります。サーバーの欄は、いつもの「Live」の付くもの）。
   - 相場が開くのは、月曜の朝7時ごろです。開くまで15分以上あれば、たいてい間に合います。
   - 15分を切っているときや、もう開いているときも、ログインはしてください（つながないままだと、建玉を見張るものがいなくなります）。その瞬間に建玉が決済されることがありますが、
     故障ではなく、もともとの安全装置の動きです。買い直さずに、売買プログラムの次の判断を待ってください。
   - 日曜の夜でログインできないときは、月曜の朝6時半までに、もう一度だけ試してください。
