# 所有者の方へ ―― 「製品化」の計画について

（2026-11-23。AIへの指示書 `docs/PRODUCT_PROMPT.md` の、あなた向けの説明です。）

## ひとことで

「CADやお絵かきソフトを作り直した事例のように、製品として通用する水準へ」というご依頼への答えが、この計画です。
あの事例がうまくいったのは、目標がはっきりしていて、一歩ごとに正しいかどうかを機械で確かめられたからでした。
同じやり方で、fxsim を「作ったAIに正常かどうかを聞かないと分からないもの」から、「自分で異常を知らせ、説明書だけで使えるもの」に作り直していきます。

## 先に、いちばん大事なこと

**儲けは増えません。** 売買のルールは変えません。見込みは今と同じで、ならして年9%前後（27万円なら年2万円台。運しだいで年2〜15%）です。
途中で資産が3割ほど（約8万円）減る時期はふつうにあり、負ける年もあります。この数字も約束ではありません。
良くなるのは「安心して放っておけること」だけです。

## できあがると、あなたに見える変化

- 毎朝スマホに1通（正常かどうか・建玉・損切りの位置）。PCが止まった、MT5がつながっていない、などの異常もスマホに届き、何をすればよいかが1行で書いてあります。
- 画面を1つ見れば状況が分かります。AIに「正常？」と聞かなくて済みます。
- 更新は1回の操作で、失敗したら自動で元に戻ります。
- 11/16のように、気づかないうちに危ない状態になることを減らします。

## できあがっても、ならないこと

- 儲けが増える、損をしなくなる、ではありません。
- 他人に配ってよい・売ってよい状態、ではありません。品質はそこを目指しますが、配る・売るには法律などの確認が別に要り、それが済むまでは「個人で使うもの」です。
- PC・回線・証券会社の故障そのものは防げません（気づいて知らせるところまでです）。

## かかるもの

- **期間**：半年〜1年の見込みです（確かなことは言えません）。途中の区切りで「ここまでで十分か」をお聞きします。
- **あなたが「続き」と言う回数**：数十回。進める速さはあなたが決めてください。週に1回でも月に2回でも、安全さは変わりません（かかる期間が延びるだけです）。
- **PCでの作業**：週1回までを目安に、1回10〜30分。全部で30回前後の見込みです。長いものは3回ほど（練習用の環境づくり、MT5側のプログラムの入れ替え、故障の訓練。各1時間前後）。
  急ぎの安全対策で週1回を超えるときは、理由を先に言います。
- **MT5のチャートに入れてあるプログラム（EA）の入れ替え**：全体で2回の予定です。3回目が要ると分かったら、理由を言って、先に相談します。
- **ほかにお願いすること**：デモ口座の申し込み、スマホに通知を受ける準備、取引の履歴を書き出すこと（どれも、その時に手順を渡します）。
- **お金**：かかりません（止めてあるAPIキーは止めたままです。有料のものを勧めるときは、先に言います）。

## いつ届くか（目安）

- 最初の1〜3回は調べるだけで、目に見える変化はありません。
- 最初に役に立つもの（健康診断が、止まっている原因と対処を日本語で言う）は、早くて12月、間に合わなければ年明けです。
- スマホへの知らせは、年明けの見込みです。

## 利用枠について

1回ごとに、ふだんの相談よりずっと多く使います。上限で止まっても記録は残っているので、枠が戻ってから同じ言葉をもう一度送れば、続きから進みます。
止まっている間も、売買は今までどおり動きます。

「複数のAIを使ってよい」と添えると、何人ものAIが同時に確かめます。確認は厚くなりますが、利用枠を何倍も使い、上限に早く当たります。
最初は添えなくて大丈夫です。要る場面が来たら、こちらからお聞きします。

## 今日から守ってほしいこと（3つ）

理由：PCが再起動したあと、MT5が証券会社につながらないまま1時間半ほどたつと、つながった瞬間に建玉が決済されるためです（11/16に実際に起きかけました）。

1. こちらが「更新してください」と言うまで、PCで `git pull` をしない。（作業の途中のものがPCに入るのを防ぐためです。今までの説明書に `git pull` と書いてあっても、こちらの合図を待ってください。）
2. Windows と MT5 を自分から再起動・終了しない。PCの電源を切らない、スリープさせない。（`docker compose restart fx` など今までのコマンドは、MT5がつながっているときなら、今までどおり使って大丈夫です。）
3. デモ口座と、2つ目のMT5は、こちらが手順を渡すまで、申し込まない・入れない。いま動いているMT5で、別の口座にログインしない。（MT5はその瞬間に口座を切り替え、建玉が決済される原因になります。）

この計画を途中でやめても、売買は今までどおり動き続けます。
