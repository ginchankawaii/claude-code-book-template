# 元手を100万円に増やしてよいか ―― 計算と、コードで確かめたこと（2026-11-23）

所有者の問い：「あと70万円ほど入れて100万円にする。最初から全部入れてよいものか。」

答え（所有者に伝えたもの）：**いま一括では入れない。入れるなら年明けに半分、春に残り。なくなっても生活が変わらないお金に限る。**
分ける理由は相場の当たり外れではなく、いまの版が検証どおりに動いた記録がまだ3週間しかないことである。

## 1. 100万円でも、割合は同じ

再生（`docs/product/ai_value/design/rp.py`。0.01ロット刻み、2015〜2026年のH1、近い長さ9通り）。

| 方式 | 始めの残高 | 年率（9通りの平均） | 最大下落（平均／最悪） | SMA2400 |
|---|---|---|---|---|
| 終値 | 27.2万円 | 9.06% | 28.0% / 31.8% | 15.12% / 25.8% / 219回 |
| 終値 | 100万円 | 9.23% | 29.0% / 33.3% | 15.27% / 26.3% / 219回 |
| 確定足（本番と同じ） | 27.2万円 | 8.95% | 28.2% / 33.2% | 15.12% / 26.6% / 221回 |
| 確定足（本番と同じ） | 100万円 | 9.17% | 29.3% / 34.9% | 15.09% / 27.1% / 221回 |
| 確定足（刻みの影響なし） | 1億円 | 9.29% | 29.7% / 35.4% | 15.23% / 27.4% / 221回 |

27万円では0.01ロットへの切り捨てで建玉が少し小さくなっていた。100万円ではそれが薄れ、年率が約0.2ポイント、最大下落が約1ポイント大きくなる。動き方は変わらない。
建玉は、100万円・1ドル159円前後で、0.06ロット（1倍）〜0.31ロット（5倍）。

## 2. 100万円を入れた日から、1年後・2年後・3年後

確定足方式、100万円、9通りをまとめた分布（始める日を1時間ずつずらした全部）。

| | 元本割れ | 10%を超える損 | 下位1割 | 真ん中 | 上位1割 | 最悪 |
|---|---|---|---|---|---|---|
| 1年後 | 37% | 6.7% | −8.4% | +6.4% | +34.8% | −23.5% |
| 2年後 | 28% | 9.3% | −9.6% | +12.4% | +101.7% | −24.3% |
| 3年後 | 24% | 11.5% | −11.0% | +20.1% | +145.6% | −28.8% |

前の高値を更新できなかった最長の期間は、長さごとに4.5〜7.0年（2015〜21年がほぼ0%だったことの別の言い方）。

限界：11年分しかなく、窓は重なっている（独立な1年は約11個）。規則はこのテープで選んだものなので、楽観側である。
1995〜2014年の日足の試算は年4.0%・最大下落51.5%だった（`docs/RESEARCH.md`）。

**分ける根拠は、この表の外にある**：仕組みが検証どおりに動くかどうかの危険は、バックテストには入っていない。

## 4. 入金したとき、コードは何をするか（読んで確かめた）

- **いまの建玉は変わらない。** 保有中は、建てた時のロット数をそのまま出し続ける（`scripts/run_ai_bridge.py` の `decide_once`：`lots = pos_lots`）。EAは差が0なので何もしない。
- **次に新しく建てる時から、新しい残高で大きさが決まる。** 大きさは `status["balance"]`（EAが書く口座残高）から計算する。
- 脳には「残高が急に変わったら疑う」検査は無い。入金で盲目になったり止まったりはしない。実行の同定（`_find_run`）も残高を使わない。
  （下落ブレーキは既定で切ってある。`FXSIM_DD_BRAKE=1` にしている場合だけ、出金が下落と数えられて建玉が小さくなる。）
- どちらの制約が大きさを決めるかは、残高ではなくATRで決まる（`docs/COVERAGE.md` の「運用点の注意」）。0.10ロットという境目はEAのリサイズ不感帯の話で、
  脳が保有中に出すロット数は建玉と同じなので、この経路は通常は通らない（外から一部を決済したときだけ）。
- **健康診断は入金を知らない（直す必要がある）。** `app/monitor.py` の `equity_stats` は、資産の列の最初と最後を比べるだけである。
  - 見出しの「初期 → 現在（+○%）」に、入金がそのまま利益として出る（70万円で+200%超）。
  - 「リターン」の判定が、常に🟢になる（本当の成績が悪くても見えない）。
  - 「ドローダウン」は、入金した時点が新しい高値になり、そこから測り直しになる。**出金は、下落として数えられる**（大きな出金は🔴の誤報になる）。
  - 直すための材料はDBにある：`equity` の表に残高と資産が判断のたびに記録されている。建玉が閉じていないのに残高が動いたら、それは入出金である。
    だから、入金の後から直しても、さかのぼって正しく計算できる。観測の側（`app/monitor.py`・`scripts/run_monitor.py`）だけの変更で、脳が読み込むファイルには触れない。

## 5. ついでに分かったこと（記録）

本番の脳は shadow では確信度0.6固定なので、リスクの割合は 4%×0.6＝2.4% である。バックテストのハーネスは4%で計算している。
効くのはATRが大きい建てだけで、差は小さい：9通りの平均で年率9.17% → 8.89%、SMA2400で15.09% → 14.69%、最大下落はほぼ同じ。
「年約9%」という見通しは変えないが、本番はこの分だけ控えめである。
