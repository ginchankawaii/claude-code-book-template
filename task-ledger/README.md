# TASK CONTROL — チームタスク管理台帳 v2

複数顧客・複数案件を並行で回すSEチーム向けの、Excel台帳+Outlookダイジェスト配信です。
SaaS不要・ローカル(業務VDI)のExcelとOutlookだけで動き、ファイルはBoxに置いて共有します。
デザインはダークテーマ(黒基調+ネオングリーン/シアンのコンソール風)。

## シート構成

| シート | 役割 |
|---|---|
| **タスク** | 台帳本体。案件(プルダウン)・担当・開始日・期限・状態・進捗%・予定工数hを登録。顧客/アラート/実績工数hは自動 |
| **ガント** | タスクを自動反映した日次ガント(70日分・150行)。予定バー/実績バー/今日線/進捗位置マーカー(赤▶)を表示 |
| **案件サマリ** | 顧客×案件の俯瞰。タスク数・超過・進捗率・予定/実績工数・DELAYED判定を自動集計 |
| **ダッシュボード** | 朝会用。全体KPI+メンバー別状況+今日の工数。運用ルールも記載 |
| **月次工数** | 案件×月の予定工数(入力)/実績(自動)/GAP(自動)+メンバー別実績。12か月分 |
| **工数ログ** | 毎日の作業時間を追記(日付・名前・案件・タスクNo・時間h)。全集計の元データ |
| **案件マスタ** | 顧客・案件の登録(20枠)。プルダウンと各集計に反映 |
| **設定** | メンバー(名前・メール・役割)と配信設定(自動配信ON/OFF・送信モード) |

## ガントの読み方(イナズマ線相当)

- 薄い青緑=予定バー、緑=実績バー(進捗%から算出)、**赤▶=進捗位置**、琥珀色の縦列=今日、グレー=完了
- **赤▶が「今日」の列より左にある行=遅れているタスク**。縦に眺めればイナズマ線と同じ読み方ができます
- 左側の表は、期限超過=赤字、進捗が予定ペースより遅い=琥珀色の字で警告します
- 進捗%はタスクシートで毎夕更新するのが前提(0〜100%で入力)

## 工数管理の流れ

1. タスク登録時に**予定工数h**を入れる
2. 毎日の作業時間を**工数ログ**に追記(1作業1行。タスクNoを入れるとタスク単位でも集計される)
3. 「今日何時間使ったか」→ダッシュボードのKPIとメンバー別「今日の工数h」に自動表示
4. 月の計画は**月次工数**のPLANブロックに案件×月で入力→ACTUALとGAPが自動集計(GAP>0=予定超過で赤字)

> 注意: タスク行を削除するとNoがずれて工数ログとの紐付きが崩れます。タスクは削除せず「完了」にしてください。

## セットアップ(初回のみ・約5分)

1. `タスク管理台帳.xlsx` をローカル(またはBox Drive経由のフォルダ)にコピーしてExcelで開く
2. **Alt+F11** → ファイル → ファイルのインポート で `vba/modDigest.bas` を取り込む
3. 左ツリーの **ThisWorkbook** をダブルクリックし、`vba/ThisWorkbook.txt` の `Private Sub Workbook_Open()` ブロックを貼り付ける
4. **F12 → 「Excel マクロ有効ブック (*.xlsm)」** で保存し、Boxの共有フォルダへ
5. **設定**シートのメンバー、**案件マスタ**の顧客・案件を実際の内容に書き換え、タスク/工数ログの例データを削除

マクロがブロックされる場合: ファイルのプロパティで「許可する」、またはトラストセンターで保存フォルダを「信頼できる場所」に追加(既存のメール送信Excelと同じ設定で動きます)。

> `vba/` 配下は日本語WindowsのVBEでそのままインポートできるよう **Shift-JIS (CP932)** です。GitHubやUTF-8エディタでは化けて見えますが正常です。

## ダイジェストメール

- **手動**: Alt+F8 → `SendDigest`(図形にマクロ登録してボタン化も可)
- **自動**: 設定シートの「自動配信」をONにすると、その日最初にブックを開いた人のOutlookから1日1回送信。うざければOFFに戻すだけ
- **送信モード**「下書き表示」なら送信前にメールが画面に出るので確認してから送れる
- 内容: OVERDUE(超過日数つき)/DUE TODAY/REVIEW/NO DUE を顧客/案件・担当つきテーブルで。送るものがない日は送信されません

## Boxでの共有

`.xlsm` はBoxのブラウザ同時編集ではマクロが動きません。**Box Drive経由でデスクトップ版Excelで開く**運用にしてください。後から開いた人は読み取り専用になるので、小規模チームなら「編集したらすぐ閉じる」で回ります。

## 運用ルール(ダッシュボードにも記載)

1. 振った/振られたタスクは必ず台帳へ(口頭・Webex依頼も受けた側が登録)
2. 期限なし禁止。1〜2日粒度に分割し、開始日と予定工数hも入れる
3. 朝: 今日やるタスクを宣言 / 夕: 結果報告+工数ログ記入+進捗%更新
4. 「完了」への変更はメンターのみ(新人はレビュー待ちまで)
5. 仕掛かりは1人3件まで
6. ガントの赤▶が今日線より左なら朝会で相談
