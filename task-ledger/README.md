# チームタスク管理台帳(Excel + Outlook ダイジェスト配信)

新人・メンター・アカウントメンバーでタスクを共有管理するための Excel 台帳です。
SaaS 不要・ローカル(業務 VDI)の Excel と Outlook だけで動きます。ファイルは Box に置いて共有します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `タスク管理台帳.xlsx` | 台帳本体(タスク表・ダッシュボード・設定)。セットアップ後に `.xlsm` で保存し直す |
| `vba/modDigest.bas` | ダイジェストメール送信マクロ(VBE にインポートする) |
| `vba/ThisWorkbook.txt` | 自動配信用のコード(ThisWorkbook に貼り付ける) |

> **注意**: `vba/` 配下は日本語 Windows でそのままインポートできるよう **Shift-JIS (CP932)** で保存しています。GitHub や UTF-8 前提のエディタ上では日本語が化けて見えますが、Windows の VBE へのインポートは正常に行えます。

## セットアップ(初回のみ・約5分)

1. `タスク管理台帳.xlsx` と `vba/` の2ファイルを VDI のローカル(またはBox Drive経由のフォルダ)にコピーする
2. Excel で `タスク管理台帳.xlsx` を開き、**Alt+F11** で VBE を開く
3. メニュー **ファイル → ファイルのインポート** で `vba/modDigest.bas` を選ぶ(標準モジュール `modDigest` が追加される)
4. 左側ツリーの **ThisWorkbook** をダブルクリックし、`vba/ThisWorkbook.txt` の中身(コメントより下の `Private Sub Workbook_Open()` ブロック)を貼り付ける
5. **F12(名前を付けて保存)→ ファイルの種類「Excel マクロ有効ブック (*.xlsm)」** で保存し、Box の共有フォルダに置く
6. **設定シート**を開き、メンバーの名前・メールアドレス・役割を実際のチームに書き換える(記入例の4行は上書き)
7. **タスクシート**の例3行を消して運用開始

マクロがブロックされる場合: ファイルを右クリック → プロパティ → 「許可する」にチェック、または Excel のオプション → トラストセンターで保存フォルダを「信頼できる場所」に追加してください(既にメール送信マクロ付き Excel が動いている環境なら、同じ設定で動きます)。

### 送信ボタンを置きたい場合(任意)

ダッシュボードシートに 挿入 → 図形 で適当なボタンを描き、右クリック → **マクロの登録 → SendDigest** を選ぶだけです。ボタンなしでも **Alt+F8 → SendDigest** で送れます。

## 使い方

### タスクシート

- 薄黄色の列に入力。**期限は必ず入れる**(空欄だと「⚠ 期限未設定」として毎回ダイジェストに載り続けます)
- 状態: `未着手 → 進行中 → レビュー待ち → 完了`
- **新人が動かせるのは「レビュー待ち」まで。「完了」にするのはメンターだけ**(完了の定義を満たしているか確認してから)
- アラート列は自動計算: 期限超過=行が赤、今日期限=黄、レビュー待ち=青、完了=グレー文字
- 行が増えたら3行目のフィルタで「アラート」列を絞り込むと超過だけ一覧できます(500行まで対応済み)

### ダッシュボードシート

すべて自動計算。朝会(Webex)でこのシートを画面共有して5分で読み合わせるのが基本の運用です。
担当者別の「仕掛かり計」が3件以上になると赤字になります(抱えすぎのサイン)。

### ダイジェストメール

- **手動**: Alt+F8 → `SendDigest`(またはボタン)。超過/今日期限/レビュー待ち/期限未設定をまとめたメールが設定シートの全メンバー宛に作られます
- **自動**: 設定シートの「自動配信」を **ON** にすると、その日最初にブックを開いた人の Outlook から1日1回だけ送信されます。うざくなったら OFF に戻すだけ
- **送信モード**: 「下書き表示」なら送信前にメールが画面に出るので、確認・編集してから送れます。慣れたら「即送信」に
- 送るものが1件もない日は何も送信されません

## Box での共有について

- `.xlsm` は Box のブラウザ同時編集ではマクロが動きません。**Box Drive(またはローカルにコピー)経由でデスクトップ版 Excel で開く**運用にしてください
- 同時に開くと後から開いた人が読み取り専用になります。小規模チームなら「更新は朝夕、編集したらすぐ閉じる」で十分回ります

## 運用ルール(ダッシュボードにも記載)

1. 人に振った/振られたタスクは必ず台帳に載せる(口頭・Webex 依頼も受けた側が登録)
2. 期限なし禁止。1〜2日で終わる粒度まで分割
3. 朝: 今日やるタスクを宣言 / 夕: 結果を報告(朝会で読み合わせ)
4. 「完了」への変更はメンターのみ(完了承認制)
5. 仕掛かりは1人3件まで
