# レース分析の評価軸

**読むタイミング：** ワークフローの Step 1（自分の確率を見積もる）を実行する時。

目的は「勝ち馬を当てる」ことではなく、**各馬に妥当な確率を割り当てる**こと。
「この馬が勝つ」ではなく「この馬の勝率は25%くらい」と言えるようになるのが到達点。
そして市場と比べたときに **なぜ自分の方が正しいと言えるのか** を一文で書けなければ、その馬には賭けない。

---

## 確率を見積もる手順

1. **まず市場を見ずに、明らかに勝ち負けになる馬を3〜5頭に絞る**（オッズを先に見ると、そこに引っ張られる）
2. その中で相対的な優劣をつける
3. 全馬に確率を割り振り、**合計を1.0に正規化する**
4. 残りの馬には「その他」としてまとめて確率を配る。無理に個別評価しない
5. **自信がない馬に無理な数値を付けない。** 「分からない」を数値化した瞬間、期待値計算は嘘になる

見積もりの現実的なアンカー：
JRAの1番人気の勝率は概ね30%強、3番人気で15%前後、単勝10倍前後の馬で5〜8%程度。
**自分が「この馬は50%勝つ」と考えたら、その主張の強さを自覚すること。** 1番人気の平均を大きく超える確信には、それに見合う根拠がいる。

## 評価軸

### 能力・実績
- **同一条件での過去走**（距離・馬場・コース形態）。条件が違えば、その成績の情報量は落ちる
- **相手関係。** 何着だったかより「誰に負けて誰に勝ったか」。低レベル戦の1着より、強い相手への好走の方が情報量が多い
- **上がり3F と そのレースの平均上がり の差。** 着順に埋もれた能力が見えることがある
- **斤量。** 前走からの増減。ハンデ戦では特に

### 展開・ペース
- 出走各馬の脚質（逃げ・先行・差し・追込）を並べ、**逃げ馬が何頭いるか**を数える
  - 逃げ馬多数 → ハイペース → 差し・追込有利
  - 逃げ馬不在 → スローペース → 前有利（後方の馬は届かない）
- **展開は最も予測が外れる要素**でもある。展開読みだけを根拠に賭けないこと。他の根拠と重なった時の補強材料として使う

### 枠順・コース形態
- 距離とコース形態によって内外の有利不利が変わる。特に**スタートから最初のコーナーまでの距離が短いコース**では枠の影響が大きい
- 内枠は距離ロスが少ない一方、包まれるリスクがある。**脚質との組み合わせで評価する**（先行馬の内枠は有利、追込馬の内枠は詰まるリスク）

### 馬場状態
- 良／稍重／重／不良。**道悪適性は血統と過去の道悪実績で見る**
- 開催が進むと内が荒れて外差しが決まりやすくなるなど、**当日・開催週による傾向**がある。当日の前のレースの決まり方は貴重な情報
- 当日情報なので市場が織り込む時間が短く、比較的エッジが残りやすい領域

### 調教・馬体
- 調教タイムそのものより**前走時との比較**。この馬にとって良い動きか
- 馬体重の増減。特に**休み明けの大幅増**、**連戦での大幅減**は注意信号
- 長期休養明けか、叩き2走目か

### 騎手・厩舎
- 乗り替わりは**方向を見る**。有力騎手への乗り替わりは陣営の勝負気配、逆は評価を下げてよい
- コース巧拙（特定コースでの成績）は、サンプル数が少ないと単なるノイズなので過信しない
- 厩舎の仕上げ傾向、遠征を伴うかどうか

### 血統
- 主に**距離適性・馬場適性・成長曲線**の推定に使う
- 初芝・初ダート・初距離など、**過去成績が使えない局面での代替情報**として最も価値が高い
- 逆に、実績が十分にある馬に対して血統を持ち出す必要は薄い

## やりがちな誤り

**前走の着順に引っ張られる。** 着順は要約統計量であって、情報を大量に捨てている。負けた理由（不利・展開・馬場）を確認せずに評価を下げるのは、市場の多数派と同じ行動であり、そこにエッジはない。

**ストーリーを作ってから根拠を集める。** 「この馬で決まりだ」と思った後に探した根拠は、ほぼ確実に確証バイアスの産物。**先に各馬を独立に評価し、後から並べる。**

**細かい条件を切りすぎる。** 「このコースのこの枠のこの脚質は勝率40%」——サンプルが10件なら、それは何も言っていない。条件を細分化すればいくらでも高勝率の枠が見つかる（多重比較の罠）。

**当たった予想を根拠にモデルを強化する。** 1レースの結果はほぼ全部が運。**当たった/外れたではなく、見積もり確率が全体として実績と合っているか（キャリブレーション）で評価する。** これが `ledger.py report` のキャリブレーション表を毎回見る理由。

**好きな馬に賭ける。** 応援と投資は別の口座でやる。混ぜた瞬間に、この文書の全てが無意味になる。
