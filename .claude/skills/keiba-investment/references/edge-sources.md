# エッジはどこにありうるか

**読むタイミング：** 「何を根拠に買うか」という戦略を決める前、または既存の戦略が機能しなくなった時。

競馬で長期的にプラスにするには、控除率（単勝20%〜三連単27.5%）を上回る優位性が必要になる。
「上手く予想する」だけでは足りない。**予想の上手さが控除率を上回るほど市場より優れている**必要がある。
このファイルは、その優位性がありうる場所を、証拠の強さ順に整理したもの。

---

## 大前提：パリミュチュエルであることの帰結

日本の馬券はブックメーカー方式ではなく**パリミュチュエル（総取り分配）方式**である。ここから2つの厳しい帰結が出る。

**1. 自分の賭け金がオッズを動かす。** 賭けた瞬間にその買い目のオッズは下がる。少額なら影響は無視できるが、資金が育つほど「見つけたエッジを自分で潰す」構造になる。単勝の人気薄など**プールが薄い買い目ほど影響が大きい**。資金規模が大きくなったら、想定オッズを保守的に見積もる（例：表示オッズの95%で期待値を計算する）。

**2. 確定オッズで期待値を検証しても意味がない。** 多くのサイトが公開しているのはレース確定後のオッズであり、購入時点で見えていたオッズとは異なる。**「確定オッズで回収率110%だった」という検証結果は、そのままでは再現不可能**である。検証も実運用も、**購入可能だった時点のオッズ**で行う必要がある。ここを混同した検証が、世に出回る「必勝法」の失敗原因の大半を占める。

**3. 対戦相手は市場全体。** 自分より情報も資金も分析力も上の参加者がプールに参加している。「自分が気づいた歪み」は、多くの場合すでに誰かが食っている。**歪みを見つけたと思ったら、まず「なぜこれがまだ残っているのか」を説明できるかを問う。** 説明できないなら、たいていそれは歪みではなく自分の計算ミスである。

## 証拠が比較的しっかりしているもの

### 券種選択（控除率の差）
最も確実で、誰にでも使える唯一の構造的優位。単勝・複勝は払戻率80%、三連単は72.5%。
**同じ予想精度なら、単勝・複勝を主戦場にするだけで期待値が7.5ポイント有利になる。**
高配当券種は「当たれば大きい」が、その夢の代金として控除率を7.5ポイント多く払っている。
夢を買いたいのか資産を増やしたいのか、ここで態度を決める必要がある。

### 本命-大穴バイアス — **日本では期待するな**
欧米のパリミュチュエル市場では、人気薄が過剰に買われ人気馬が過小評価される「本命-大穴バイアス」が古くから知られる。ところが**日本・香港の市場ではこのバイアスが明確には観測されない**という研究結果がある（日本の市場は相対的に効率的だとされる）。
つまり「機械的に1番人気の単勝を買う」といった単純な戦略は、日本では期待値100%付近に張り付き、控除率の分だけ負ける。
**海外の競馬本や記事に載っている「本命を買え」戦略を、そのまま日本に持ち込まないこと。** これは最も多い失敗パターンのひとつ。

### 複数プール間の整合性の破れ
単勝オッズから計算される勝率と、馬連・三連複のオッズが含意する勝率は、理論上は整合しているはずだが、実際にはズレる。ズレはプールの厚み・参加者層の違いから生じる。
**理論的には最も筋の良いエッジの源泉**（自分の予想精度に依存せず、市場内部の矛盾だけで判定できるため）。
ただし、Harville モデル等で複勝・連系の確率を単勝から導く際の近似誤差が大きいことが知られており、「ズレ」がモデルの誤差なのか本物の歪みなのかの切り分けが難しい。**検証には大量の過去データが要る。**

## 仮説段階（検証してから使うもの）

以下は「あるかもしれない」レベル。**自分のデータで検証するまで、実弾を張る根拠にしてはいけない。**

### オッズの時系列変動
締切直前のオッズ変動には、情報を持つ参加者の資金が反映されている可能性がある。
問題は**変動を観測した時点で、その情報はもうオッズに入っている**こと。「動いたから乗る」では遅い。
使うとすれば「事前予想と直前オッズの乖離が大きい馬を除外する」といった**フィルタ**としての用法が現実的。

### 着順に現れない不利
出遅れ、進路のカット、大外を回らされた、極端な不利ペース。
**着順という要約統計量は情報を捨てている。** 着順しか見ない層が多いなら、その捨てられた情報にエッジが残りうる。
これは「レース映像を見る」という手間がそのままコストになるため、**手間を惜しむ層との差**という形で持続しうるのが利点。
検証しやすく、個人が最初に取り組む対象として現実的。

### 条件替わりの評価遅れ
初芝・初ダート、距離延長／短縮、初ブリンカー、乗り替わり、初の右回り／左回り。
過去成績のパターンマッチが効かない局面では、市場の推定も不安定になる。
ただし**不安定＝自分が有利、ではない。** 自分の推定も同じくらい不安定である可能性が高い。

### 馬場状態と展開
馬場の内外の有利不利、当日の傾向、想定ペースと各馬の脚質の噛み合い。
当日の情報なので市場が織り込む時間が短く、理屈上は歪みが残りやすい。
一方で**多くのプロも同じ情報を見ている**ため、差がつきにくい領域でもある。

## ほぼ確実に無駄なもの

- **有料予想の購入。** 情報料を払った分、期待値はさらに下がる。本当に控除率を超える情報なら、売るより自分で賭ける方が儲かる。売られている時点で価値の推定値が出ている。
- **「必勝法」「無敗の◯◯」を謳う商材。** 上と同じ論理。
- **マーチンゲール／逆マーチンゲール等の賭け金操作。** 期待値がマイナスの賭けをどう並べても、賭け金操作で期待値はプラスにならない。破産確率を上げるだけ。
- **確定オッズで検証したバックテスト。** 上述の通り再現不可能。
- **少ないサンプルでの「この条件は回収率150%」。** 条件を細かく切れば必ず高回収率の枠が見つかる。それはデータではなくノイズの切り出し（多重比較の罠）。**条件を思いつく前にサンプル数の下限を決めておくこと。**

## 戦略を採用するかの判定基準

新しいエッジ仮説を実運用に入れる前に、この4つに答えられること。答えられないなら Phase 0 のペーパー運用に留める。

1. **その歪みがなぜ存在するのか、メカニズムを一文で説明できるか。**（説明できない相関はノイズである可能性が高い）
2. **なぜそれがまだ市場に食われずに残っているのか。**（手間・情報コスト・参加者の心理など、持続する理由がいるか）
3. **購入可能だった時点のオッズで検証したか。**（確定オッズでの検証は無効）
4. **サンプル数は十分か。** 回収率のブートストラップ信頼区間の下限が100%を超えているか。100件程度では、まず超えない。
